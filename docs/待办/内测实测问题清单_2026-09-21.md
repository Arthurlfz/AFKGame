# 永夜灵市内测前实测问题清单

> 测试时间：2026-09-21
> 测试账号：test_player001
> 测试范围：登录、主城、战斗、世界地图、市集、宠物资料、进化系统

---

## 🔴 致命问题（必须修了才能开内测）

1. **新手引导卡死**
   - 根因：开场自动弹出的聚光引导弹窗，暗层没有设置`pointer-events: none`，盖住整个屏幕，所有下层按钮都点不动
   - 现象：刚进游戏就被锁死，点什么都没反应，只有引导弹窗自己的按钮能点
   - 影响：新玩家进游戏直接卡死，第一印象直接报废

> ⚠️ 备注：之前误判"背包/孵化弹窗卡死"，实际是自动化截图工具看不到modal内容，游戏本身功能正常。

---

## 🟠 交互问题（影响体验，内测前尽量修）

### 战斗页
1. **没有打击感**：看不到怪物血条、看不到伤害飘字、看不到攻击动画，就两只宠物站着不动
2. **掉落无感**：打了90多场，不知道掉了什么，也没有掉落提示，"掉宝爽点"完全没体验到
3. **战斗信息太少**：看不到怪物等级、怪物血量、下一只怪是什么

### 市集页
4. **购买失败没反馈**：材料不足时点确认购买，没有任何提示，直接没反应，玩家懵
5. **价格货币不明确**：价格用重铸石/增绿石/剥离石这些材料当货币，玩家看不到自己有多少这些材料
6. **品级不明显**：宠物成长8和成长3，从卡片上看不出来哪个好，没有颜色区分
7. **商品刷新太快**：两分钟内商品从87件涨到496件，玩家根本看不过来
8. **右上角任务面板叠在一起**：三个可提交任务挤在右上角，挡着市集内容，按钮小不好点

### 宠物系统
9. **页面加载慢，中间空白**：点宠物资料之后，等两秒才出来，中间一片黑
10. **术语太多**："转生0次"、"一阶选分支"、"血统·猎杀本能"、"无血脉特质"，新玩家根本看不懂
11. **主动技能没说明**：显示"一阶选分支后解锁"，新手不知道怎么解锁，也不知道有什么技能
12. **养成线太长，新手压力大**：进化、合成、涅槃、觉醒四个tab，后面三个新手根本用不了，但一直亮着，点进去都是空的，浪费注意力
13. **合成/涅槃/觉醒门槛太高**：合成就需要多只宠物，涅槃要Lv60+神级宠，觉醒要终阶，新手刚进游戏完全碰不到

### 进化系统
14. **进化方向没区别**：血牙狐和幽火狐，不知道哪个强、有什么技能差异，选哪个都一样
15. **进化按钮被挡住**：页面底部被聊天栏挡住，看不到"进化"按钮，也看不到需要什么材料
16. **任务提交没反馈**：点提交任务，不知道交没交成，也不知道给了什么奖励

---

## 🟡 数值问题（影响留存，内测后慢慢调）

1. **新手节奏太慢**：打了90多场战斗才升了几级，新手期应该快一点，让玩家快速感受到成长
2. **进化收益太低**：进化之后生命只加5，攻击只加3，成长从5.0涨到5.1，太小了，进化的爽点不明显
3. **掉率太低**：打了90多场，一件好装备都没掉，玩家会觉得"这游戏不掉东西啊"
4. **新手买不起东西**：市集最便宜的也要2个材料，玩家刚进来身上没材料，根本体验不到"捡漏"的爽
5. **都是低级货**：市集全是Lv.1的宠物和低级装备，没有高级好东西，捡漏爽点不明显
6. **材料货币太杂**：重铸石、增绿石、剥离石，三种材料当货币，玩家记不住
7. **术语太多看不懂**："成长5.0"、"推荐成长3"、"霸主"、"委托6/200"，新玩家根本看不懂
8. **新手只有一只宠物**：宠物列表就一只血狐，空荡荡的，没有其他宠物可以选，宠物收集感不强

---

## 🟢 做得好的地方（继续保持）

1. **暗黑风UI整体不错**：整体色调、建筑、宠物立绘的风格统一，氛围感很好
2. **市集价格对比提示**："低于市价40%"、"高于市价60%"，绿红颜色区分，很直观
3. **进化分支设计**：血狐可以进化成血牙狐或幽火狐，分支选择的设计不错
4. **进化属性对比**：进化前/后的属性对比很清楚，玩家能看到提升
5. **任务进度条**：右上角的任务进度条很直观，能看到任务完成度

## ✅ 处理结果回填（2026-09-21 晚，逐条对过代码与线上）

**先说取证结论**：本地 HEAD 与 GitHub Pages 线上**完全一致**（0 个未推送提交，关键文件全部入库），
引导修复（09-17）与战斗表现六件套（`js/ui/battle/` + `hit-fx`）**均已部署**。
所以"测的是什么版本"不是问题——下面按真问题/误判两类回填：

### 🔴1 新手引导卡死 —— **未复现，判定为测试环境误判**
- 线上抓取 `ui-onboarding.css` 逐行比对：`.ob-host/.ob-veil/.ob-hole/.ob-float/.ob-hot-*` 全部已是
  `pointer-events:none`（09-02 立"只压暗不拦截"），引擎 JS 也没有任何内联覆盖。
- 结构上暗层**不可能**挡点击（只有气泡卡和按钮可点）。与备注里"背包/孵化弹窗卡死"是同一类
  自动化截图工具误判。
- 防回归：新增守值 `tests/vtest_onboarding_guard.js`（19 条断言：暗层类必须 none、
  引导自身按钮必须 auto、JS 不许内联 pointerEvents）。

### 🟠1~3 战斗页（无打击感/掉落无感/信息少）—— **最新版无代码事实支撑，判测试环境误判**
- 血条/行动条（`battle/index.js` resetBattle/updateBars 常驻显示）、飘字/冲刺/受击形变
  （`battle/act.js`）、命中墨爆（`fx/hit-fx.js`）、怪物悬浮详情（`battle/tip.js`）全部在位且已部署。
- "两只宠物站着不动"与上述全部矛盾，疑似截图环境禁用了动画或时机问题。
- "掉落无感"有**一半是设计**：日常材料（tier1）只有消息中心"掉落"频道一行字 + 飞包动画
  （战斗页前台才飞），横幅只给稀有档/金装/蛋（`battle/loot.js` 顶部注释写明）。若要提升日常材料
  的感知，属于 🟡 数值/表现问题，本批未动。

### 🟠4 市集购买失败没反馈 —— **真问题，已修**
- 根因：`showToast` 不是浮层，它只把消息写进**消息中心**（底部聊天弹窗/内嵌 console），
  而市集页**没有**内嵌 console —— 错误记在玩家看不到的地方 = 感知上"没反应"。
  （同一根因也解释 🟠16"任务提交没反馈"，建议同样就地反馈，本批未动。）
- 修复：购买失败原因**就地写在购买弹窗里**（红色错误行，弹窗本来就开着、失败保留不关），
  覆盖材料不足/已售出/未登录等全部失败分支；消息中心那份保留。
  `ui-market.js` `?v=20260921buyerr`。

### 🟠15 进化按钮被挡 —— **真问题，已修（根因不是聊天栏）**
- 根因：进化页 `.es-main/.es-target` 写死 `min-height:430px`，右列面板必然超一屏，
  确认按钮+材料（`forge-bar`）被排到折叠线下；下半区那条"聊天栏"是宠物页常驻**内嵌消息栏**
  （聊天抽屉早已改到右侧、收起不占位）。pane 其实能滚，但玩家不知道要滚。
- 修复：面板吃满可视高度、三格弹性收缩、**forge-bar 固定在面板底部常驻可见**；
  头像立绘 `flex:none` 不被压扁，极端矮窗口时格子内部滚动。
  已用 Playwright 量真实几何验证（按钮 463~507px 落在面板 85~558px 内、头像 180×180 完整、
  不与消息栏重叠）。`game.css` `?v=20260921evobar`。

### 🟠16 任务提交没反馈 —— **真问题，已修（与 🟠4 同一根因）**
- 三条提交路径（卡片 / 详情 / 顶部引导条）全部加**就地结果行**：成功「已提交 · 奖励：xxx」、
  失败「提交失败：原因」，写在任务面板/任务条里（原来只进消息中心）。
- ⚠️ 实现要点：提交成功后会 `renderQuestPanel()` 整块重绘，**结果行必须在重绘之后再插**，否则被冲掉。
  `ui-quest.js` `?v=20260921qresult` + `game.css` `.quest-result`。

### 🟠6 市集"成长 8 和成长 3 看不出哪个好" —— **已修**
- ⛔ 不引进"品级"（宪法：不学分品级）。做法：成长数字**提亮放大**（比等级显眼）+ 两个相对标签：
  ①「高于同款」= 高于同款（同进化线）在售成长的中位数，样本 <3 不标；
  ②「可搏神级宠」= 成长 ≥ `Config.synthesize.god.minGrowth`（唯一事实源）。
- 与市集已有的"低于市价 40%"是同一套比价语言。`ui-market.js` + `market-cascade.css` `?v=20260921growth`。

### 🟠12 养成 tab 全亮、后三个新手用不了 —— **已修（两层都补了）**
- tab 层：条件不满足时挂「未开启」角标 + 悬停说明（**不置灰、不拦截**，点进去看也无妨）。
- 页面层：合成/涅槃/觉醒点进去不再是空白，而是三段话——**这是什么玩法 / 还差什么 / 现在该干嘛**
  （例：涅槃 = "等级打回 1 换成长永久上涨 + 还差一只 Lv60 神级宠 + 先去合成里搏一只"）。
- 门槛统一由 `ui-pet.js` 的 `UI.petTabGate()` 从 Config 现读（合成 40 / 涅槃 60+神级 / 觉醒 终形态+觉醒石），
  三个页面不再各拼一份条件。`ui-pet*.js` `?v=20260921empty` + `game.css` `.pet-empty`。

### 🟠10 术语太多看不懂 —— **已修（不删术语，改成就地能看懂）**
- 原则：术语是游戏的一部分，不删；但每个都要**就地看懂**。
- 转生 → 「转生 0 次（还没涅槃过）/ 转生 N 次（涅槃重练过 N 次）」+ 悬停解释涅槃是什么。
- 无血脉特质 → 「还没有额外天赋」+ 悬停说清怎么得（孵化自带 / 合成 / 涅槃）。
- 成长 → 悬停写"决定每升一级加多少属性，判断一只宠好不好的第一指标"。
- 宠物卡「血统 · X」→ 把血统说明挂到悬停（以前只有四个字）。`ui-pet.js` `?v=20260922terms`。

### 🟠9 宠物页加载慢、中间空白 —— **已修**
- 根因：切到宠物页时 `ui-shell.js` **只切了显示、没有立刻渲染内容**，内容要等下一次全局刷新才填上
  ⇒ 中间就是一整块空面板（"一片黑"）。
- 修法：与百科/市集/地图页同一套写法 —— 切过去当场渲染（`renderPetPanel` + `renderPetList`）；
  渲染失败只记 console，不影响切页（骨架照常落地）。`ui-shell.js` `?v=20260922petfast`。

### 🟠7 商品刷新太快（两分钟 87 → 496）—— **已修**
- 根因：假卖家 tick **每 30 秒无条件再加 5 件，挂单只增不减** ⇒ 越挂越多、翻不完。
- 修法：给每个池加**上限**（装备 48 / 宠物 20 / 材料 16 / 蛋 12），到顶不补，只有被买走才回补
  ⇒ 市场"一直有货"但不再膨胀，也不会淹没真实玩家的挂单。
  数值在 `Config.marketBot`（`maxActive` 等 4 个新字段），`config.js` + `market_bot.js` `?v=20260922botcap`。

### 🟡 数值问题（1~8）—— 本批未动（按清单约定"内测后慢慢调"）

（action_freeze / bugfix / pet_skill），本次零新红（`vtest_pet_anim` 曾因 game.css 升号短暂红过，
守值断言已同步更新至 `evobar`）。
