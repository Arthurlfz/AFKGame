## 三、贯穿五阶的三条"进化有迹可循"线索（**这是本设定的核心**）

用户要求"进化有迹可循"——所以每一阶都不是重新设计，而是**同三样东西在长大**：

### 线索 ①：菌盖（**最关键**，一眼看出在第几阶）
```
苞（闭合小菌盖）→ 半开 → 全开大伞（带纹）→ 硬化成盔/肩甲 → 摘下来变成【面具】
```
⭐ 这条线本身就是"它怎么成神"的解释：**最后那个面具，就是它的菌盖**。

### 线索 ②：孢子（浓度即阶位）
```
几乎没有 → 少量飘散 → 云雾状孢子云 → 凝成甲片与飘带 → 化为光尘/花瓣落下
```

### 线索 ③：冥花（从阶 3 出现，位置逐阶"升高"）
```
无 → 无 → 背脊开出第一朵 → 肩/胸一整朵 → 开在头顶与手中（＝花冠）
```
⭐ "花往上走 = 它在成神"：背脊 → 肩胸 → 头顶，全程只升不降。

## 四、逐阶设定细节

### 阶 1 · 孢子团（Lv1 · 可爱）
- **形态**：一个**手掌大的白色菌球**，底下两截短到看不出的腿，滚/蹦着移动；
  菌盖是**没撑开的苞**（像一颗小蒜头），两只小眼是两道墨点，**没有嘴**（饿了会抖）。
- **记忆点**：苞（闭合菌盖）、**一点病绿**从苞缝透出来（像里面在发光的孢子）。
- **配色**：95% 墨/灰白 + 5% 病绿微光。
- **禁止**：不要眼睛结构照搬、不要毛、不要爪牙。
- **出图骨架**：`a tiny round pale mushroom spore ball creature, closed bud-like cap, two dot eyes, hidden legs, faint sickly-green glow leaking from the cap seam, cute but slightly eerie, sumi-e ink wash, transparent background`

### 阶 2 · 菌兽（Lv10 · 可爱）
- **形态**：**圆滚四足幼兽**（头身比 1:1，短腿跑得快、身子低）；菌盖**半开**成宽檐帽扣在头上，
  盖缘有**点状纹**（后面每阶都会扩展这圈纹）。
- **记忆点**：宽檐菌帽 + **四只小短腿** + 背后一小团飘散的孢子。
- **配色**：88% 墨/灰白 + 8% 病绿 + 4% 月白（盖内亮部）。
- **出图骨架**：`a chubby four-legged little mushroom beast, half-open wide mushroom cap like a floppy hat with dotted rim pattern, short legs, small puff of spores behind, cute monster vibe, ink wash`

### 阶 3 · 菌王（Lv25 · **飒**）
- **形态**：**低伏四足猎兽**（体长拉满、腿细长、伏击体格，肩比腰高）；菌盖**全开成大伞**，
  盖面出现**放射状纹路**（＝阶 4 盔甲分片的伏笔），伞骨末端垂**孢子絮**；**背脊开出第一朵冥花**（淡青/淡紫微光）。
- **记忆点**：全开大伞 + 放射纹 + 背脊第一朵发光花 + 身后拖着的孢子云。
- **配色**：80% 墨 + 10% 病绿（孢子云）+ 6% 月白 + 4% 淡紫（冥花）。
- **禁止**：獠牙/真实动物面部结构；它的"凶"要来自**低伏姿态与体量**，不是牙齿。
- **出图骨架**：`a large low-lunging four-legged mushroom beast, fully opened broad mushroom cap with radial gill lines hanging spore threads, first glowing pale-violet underworld flower blooming on its spine, trailing spore cloud, menacing but not toothy, ink wash`

### 阶 4 · 菌将（Lv60 · **帅气**）
- **形态**：**半直立**（双足站立、前肢化手可持物，但仍可辨认是兽：腿仍反关节、体前倾，**不是**人）；
  菌盖**硬化**成**盔甲/肩甲**形状（放射纹变成甲片分割线），孢子**凝成披风与飘带**；冥花长到**肩/胸**一整朵。
- **记忆点**：菌甲 + 孢子披风 + 胸口冥花 + 手中开始成型的**花枝**（＝阶 5 的法器伏笔）。
- **配色**：65% 墨 + 15% 月白 + 10% 病绿 + 7% 淡紫 + 3% 淡金（金第一次出现，只做微光）。
- **禁止**：别画成人形（那是阶 5）；这一阶的关键是"**甲**"和"**量**"，不是脸。
- **出图骨架**：`a huge half-upright mushroom general beast standing on two legs with digitigrade legs, hardened mushroom cap turned into dark armor plates on shoulders, spores condensed into a cape and streamers, a large pale-violet underworld flower on its chest, a budding flower-branch held in one claw, imposing, ink wash`

### 阶 5 · 冥花神（神级 · **庄严·神秘**）
- **形态**：**完全拟人**，身形修长、站姿笔直近乎不动；
  **面具 = 摘下来的菌盖**（盖形面具，放射纹变面纹，眼位是两条**垂目**的细缝，不露五官）；
  头顶**花冠**（冥花在头顶盛开）+ 身后**月白/淡金的光环**（不是天使羽翼）；
  披帛**由孢子凝成**、向下流散；底座是**云台/菌簇**（不用西式莲台）。
- **记忆点**：**菌盖面具**（＝它一路长过来的那个盖子）+ 垂目 + 花冠 + 孢子披帛。
- **配色**：55% 墨 + 20% 月白 + 10% 淡金（庄严） + 8% 病绿 + 7% 淡紫。
- **⚠️ 庄严怎么落**：走**东方神像的通用语汇**（面具、垂目、花冠、披帛、云台），
  **不指向任何具体宗教造像**（不画佛像/菩萨像本身），也不画西式天使翅膀 —— 这样"神圣"与"水墨暗黑"能同时成立。
- **出图骨架**：`a tall serene humanoid deity in ink-wash style, face fully covered by a mushroom-cap mask with radial pattern and downcast narrow eye slits, a crown of glowing pale-violet underworld flowers on its head, faint pale-gold halo ring behind, spore-dust stole and robes flowing down, standing on a cloud platform, solemn and mysterious, oriental divine imagery, ink wash`

## 五、配色与画法（水墨规矩）

- **主色**：墨黑 / 灰白（占 6~9 成，随阶降低）。
- **点缀**：**月白**（神圣亮部）、**病绿**（孢子微光）、**淡紫/淡青**（冥花光）、**淡金**（仅阶 4~5，微光不做亮金）。
- **肌理一律用笔法表现**：墨块、飞白、干笔、点苔 —— ⛔ **不要**真实毛皮/肉质/骨骼质感（这条是"不要现实世界那种"的落地方式）。
- ⛔ 全程禁止：血腥露骨、脓疮溃烂特写（那是现有 8 只写实线的语言，新线要区分开）。

## 六、出图顺序与规格（省钱纪律）

- **一次生成只出一张**（`count:1`），一阶一张，共 5 张。
- **顺序**：**先出阶 1 定画风** → 你点头 → 出阶 2/3/4（可一次 3 张） → 最后出阶 5。
  （跑偏最多只亏已出的那几张，不会 5 张全废。）
- **规格**：**512×512 透明底**、角色占画面 **70~80%**、四周留白 **10~15%**、全身在框内、**统一朝左**。
- **落盘**（守档，不动现有素材）：`docs/assets/pets/ref/minghua/阶段N-<名字>.png`，源图留档 `_源-*.png`。

## 七之二、⛔ 怪物化硬约束（**用户收尾口径，2026-09-21**）

用户原话：「**最好是做成怪物**」。这条是**长期口径**——这条线（以及照它推的后续原创宠）必须是**怪物**，
⛔ 不许滑成**现实动物**（狐/狼/犬/猫）、⛔ 也不许滑成**植物精**（树叶/藤/羽状）。落地成五条硬约束写进每次 prompt：

1. **头 = 菌盖本身**：`the head IS the mushroom cap`；⛔ `no animal muzzle, no snout, no fox/wolf/dog shape`
2. **眼睛是菌盖上的发光点**（阶 1~3），阶 4 起才允许"盖檐阴影下两点亮眼"；⛔ 不许动物式的脸
3. **腿 = 柱状（像菌柄）**：`stocky cylindrical stalk-like legs`；⛔ 不许细长犬腿 / 蹄 / 尖爪
4. **尾 = 菌丝束/孢子流**（不是蓬松尾巴）；⛔ 不许毛茸茸的兽尾
5. **质感 = 干净水墨**：⛔ 不许腐坏、霉斑、树皮、苔藓、滴落黏液、露骨——那些会同时踩"恐怖"和"现实"两条线

> 这套约束同时解决两个问题：**"不像现实动物"**（用户最早的要求）与**"别太恐怖"**（阶 3/4 返工的原因）。
