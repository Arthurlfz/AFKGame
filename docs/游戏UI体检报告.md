## 二、严重问题（error，建议尽快修）

### 1. 字体过小（15 处）— 最影响可读性

背包格子里的小字是重灾区，8\~11px 在 1080p 下几乎看不清：



| 位置                                   | 字号       | 内容                    |
| ------------------------------------ | -------- | --------------------- |
| `ui-polish.css:172`                  | **8px**  | 背包格子角标（数量 / 品质角标）     |
| `ui-polish.css:105`                  | **9px**  | 背包格子物品名               |
| `ui-polish.css:171`                  | **10px** | 背包物品名                 |
| `game.css:2357`                      | **10px** | 背包格角标                 |
| `game.css:147 / 2356 / 1411`         | **11px** | 提示角标 / 背包物品名 / 敌人类型标签 |
| `game.css:1107 / 1416`               | **12px** | 出战列表等级 / 敌名小标         |
| `game.css:1403 / 1410 / 2005 / 2367` | **13px** | 敌名 / 提示 / 菜单图标 / 占位文字 |

**后果**：玩家在正常距离看不清楚装备名和数量，放大窗口或未来上电视 / 手机更糟。

**修复**：按 game-ui-design 标准 —— 正文最低 14px，重要信息 16\~18px，关键数字（血条数值、等级）24px+。背包格子建议：物品名 ≥14px、角标 ≥12px。

### 2. 触控 / 选中目标过小（6 处）



| 位置                  | 尺寸      | 元素                 |
| ------------------- | ------- | ------------------ |
| `ui-polish.css:126` | 22px 高  | 背包小按钮 `.btn-sm`    |
| `ui-polish.css:373` | 38px 高  | 装备槽条目 `.slot-item` |
| `ui-polish.css:374` | 28×28px | 装备槽图标              |
| `ui-polish.css:225` | 34×34px | 世界地图标记（可点击）        |
| `ui-polish.css:223` | 16×16px | 地图小圆点              |
| `game.css:2354`     | 30×30px | 背包格图标              |

**后果**：鼠标下尚可用；但手柄 / 触屏 / Steam Deck 场景会很难选中，误点率高。

**修复**：可视元素小没关系，**扩大点击热区**—— 用 `padding` 或 `::after` 把命中区域撑到 44\~48px，视觉尺寸不变。

## 三、建议修（warning）

### 3. 键盘 / 手柄焦点不可见（10 处）

`outline:none` 出现在 `game.css:57/653/735/872/1963/1982`、`design-tokens.css:166`、`app.css:49`、`ui-polish.css:39`、`market-refresh.css:88`。多数用了 `:focus` 换边框 / 光晕兜底，但**没有&#x20;**`:focus-visible`，Tab 键或手柄移动焦点时提示很弱。

**修复**：加一条全局规则即可 ——



```
:focus-visible { outline: 2px solid var(--action-gold); outline-offset: 2px; }
```

### 4. 稀有度纯颜色传达（4 处）

白 / 蓝 / 金三档品质主要靠颜色区分：`game.css:1421-1423`（rarity-white/blue/gold）、`app.css:192`、`ui-polish.css:176/369-370`。

**后果**：约 8% 的男性玩家是红绿色弱，可能分不清白装和蓝装。

**修复**：装备名里带品质字眼（如 "稀有"" 传奇 "—— 请确认渲染的 item name 是否已含）、金装有 `font-weight:700` 已加分；建议蓝装也加字重或图标，不纯靠颜色。

### 5. 屏幕震动无独立开关（2 处）

`game.css:401`（`@keyframes shake`）、`game.css:1586`（`stage-shake`）。虽然有全局 `prefers-reduced-motion` 兜底，但**玩家在游戏内无法单独关闭震动**。

**修复**：设置面板加 "屏幕震动：开 / 低 / 关" 选项；震动只作用于战斗画面，不作用于 UI。

## 四、可选优化（info）

### 6. tooltip 即时显示（1 处）

`ui-common.js:122` 用全局 `mouseover` 事件委托即时弹 tooltip，无延迟。鼠标扫过装备行时会闪一下。

**修复**：加 300\~500ms 的 `setTimeout` 延迟再显示，移出即取消。

### 7. 固定像素尺寸（低优先级）

`game.css:452/976/937` 等有 380\~1148px 的固定宽，但都配了 `max-width:94vw / calc(100vw-220px)` 响应式兜底，**问题不大**，暂不用改。

## 五、HTML 层额外发现（功能性问题，非样式规则）



1. **宠物 tab 注释与实际不符**：HTML 注释写 "资料 / 装备 / 融合 / 进化 / 宠物蛋"，实际只渲染了 **资料 / 进化 / 合成 / 涅槃 4 个 tab**——**宠物蛋 tab 缺失**（对应你 plan.md 里 "复活 renderEggPanel 打通 t7 孵化"）、"装备"tab 已挪到背包浮窗、注释是旧的。建议同步注释，避免后续改错。

2. **涅槃空状态引导不足**：截图里涅槃页右侧流程区只有 "+" 占位，新玩家不知道涅槃的意义、副宠从哪来。建议空状态加一句引导（如 "去野外挂机刷副宠，或去市集买一只"）。
