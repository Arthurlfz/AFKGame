# Forge of Souls：资源试炼与新手引导交接

> 交给下一位 agent 的执行上下文。当前目标是让“普通地图挂机 → 处理装备 → 定向补资源 → 再打造/培养”的循环可玩、可验证；不要继续扩大系统范围。

## 1. 当前结论

- 项目已经不是 MVP 设计阶段，现阶段优先验证“玩起来是否有决策和反馈”，而不是继续添加通天塔、更多地图或更多货币。
- 成长值、进化、涅槃、合成暂时不是唯一战力来源；玩家可以慢速挂机，但不能被卡死。
- 普通地图继续承担稳定挂机、经验、装备和区域材料；资源试炼承担“今天想定向刷哪类资源”的选择。
- 资源试炼当前是**本地 MVP**，适合试玩和验证循环，不可视为正式经济系统或服务端权威副本。

## 2. 已完成改动

### 新手引导 N1～N6

文件：

- `docs/js/core/config.js`
- `docs/js/core/quest.js`
- `docs/js/core/tutorial_mode.js`
- `docs/js/ui/ui-quest.js`
- `docs/js/equipment/equipment_craft.js`
- `docs/js/ui/ui-common.js`

当前链路：

1. N1：选择出战宠物并挂机 3 场。
2. N2：从两件不同底材装备中选一件并穿戴。
3. N3：使用 1 次重铸石，明确展示随机性和装备等级限制。
4. N4：宠物达到 Lv10 后完成第一次进化。
5. N5：另一件装备必须“上架或分解”，然后击败第一个地图 Boss。
6. N6：在“继续刷图”和“尝试资源试炼”之间做一次明确选择。

关键边界：

- 奖励由任务 key 驱动并做幂等账本记录，不能因为重复上报重复发放。
- 新手不直接发放完整毕业套、涅槃高级材料或高级打造通货。
- N6 选择资源试炼后会打开资源试炼面板。

### 资源试炼 MVP

文件：

- `docs/js/core/resource-trial.js`
- `docs/js/ui/ui-resource-trial.js`
- `docs/tests/vtest_resource_trial.js`
- `docs/css/ui-polish.css`
- `docs/游戏.html`

规则：

- 三条路线：蜕变、涅槃、淬炼。
- 每次消耗 1 张“资源试炼门票”。
- 每次最多 5 场短战斗。
- 蜕变：按宠物等级给进化素材。
- 涅槃：给涅槃相关材料，最低 Lv25。
- 淬炼：给重铸/增缀/剥离相关打造通货。
- 失败不回退门票，给少量区域材料补偿。
- 不新增货币，不修改普通地图战斗公式。
- 入口位于世界地图标题栏，面板使用现有 UI token 和移动端单列布局。

## 4. Supabase 边界

`supabase/gen_server_config.js` 目前只把战斗结算需要的白名单字段写入：

- `supabase/functions/_shared/config-server.mjs`
- `supabase/functions/_shared/enemy-data-server.mjs`

`Config.resourceTrials` 不参与当前服务端战斗结算，因此本轮**不需要**重新生成 `config-server.mjs`，也不要为了“看起来同步”把 UI/副本字段加入服务端快照。

正式化资源试炼时，才需要新增服务端权威链路，至少包括：

1. 服务端校验门票余额并原子扣除。
2. 服务端校验宠物、路线、等级和副本轮数。
3. 服务端决定成功/失败结果，客户端不能自行伪造奖励。
4. 服务端原子发放奖励并防重复结算。
5. 增加针对 RPC/Edge Function 的窄测试和失败重试边界。

## 5. 下一位 agent 的优先任务

按顺序做，不要同时改所有系统：

### P0：真实试玩反馈

- 用新账号完成 N1～N6，记录每一步是否知道“为什么做”和“做完得到什么”。
- 重点观察 N3 随机重铸、N5 上架/分解、N6 资源试炼选择是否有明确反馈。
- 记录资源试炼的实际完成时间、失败率、门票消耗感受和三条路线的差异。

### P1：只修阻塞体验的问题

- 如果按钮状态、奖励提示、面板刷新或移动端布局有问题，做最小修复。
- 如果玩家看不出普通地图与资源试炼的区别，优先补文案/结果反馈，不要先调全局怪物数值。
- 如果资源试炼成功率过高或过低，只改 `Config.resourceTrials` 的局部参数，并补对应测试。

### P2：再决定是否正式化

- 只有本地循环被真实试玩验证后，才设计 Supabase 权威结算。
- 只有资源试炼和装备打造的收益关系稳定后，才评估通天塔。
