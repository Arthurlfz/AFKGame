## 子代理 A：装备数据层（config.js / equipment.js / salvage.js）

**现状**：
- `config.equipment.baseValues`：武器atk[5,9] / 防具def[3,6]+hp[20,40] / 饰品spd[2,4]+atk[2,5]
- `config.equipment.rarities`：白(1条)/蓝(1~2)/金(2~3)
- `config.equipment.affixTiers`：T1~T5百分比区间（T1=25~30）
- `equipment.js`：SLOTS=['武器','防具','饰品']；词缀池 AFFIX_POOL 8条；generateEquipment 按稀有度定条数；词缀已是{prefix,suffix}分桶上限各3

**改成**：

**1. 12 部位 + 基底固定值**（宠物居中方阵四边）：

| 类别 | 部位 | 基底属性 | 基底基准(1档) |
|---|---|---|---|
| 顶·输出 | 武器 | 攻击 | 30 |
| 顶·输出 | 戒指 | 攻击+暴击率 | 15+2% |
| 顶·输出 | 项链 | 攻击+暴击伤害 | 15+8% |
| 左·防御 | 头盔 | 防御 | 15 |
| 左·防御 | 护甲 | 生命+防御 | 80+8 |
| 左·防御 | 盾牌 | 防御+闪避 | 15+5 |
| 右·机动 | 靴子 | 速度(固定) | 8 |
| 右·机动 | 腰带 | 生命+速度 | 60+5 |
| 右·机动 | 斗篷 | 闪避+生命 | 10+50 |
| 底·通用 | 饰品 | 攻击+命中 | 12+5 |
| 底·通用 | 护符 | 吸血+生命 | 4%+50 |
| 底·通用 | 徽章 | 暴击率+暴击伤害 | 3%+10% |

**2. 基底 = 档次数值 × 底材T阶系数**
- 6 档（按掉落图1~图6，每档放大）
- 底材T阶系数：T1×1.5 / T2×1.3 / T3×1.0 / T4×0.8 / T5×0.6
- 词缀% 乘「放大后的基底」（非原始基底）

**3. 词缀结构**
- 基础词缀 1 条（部位必带，保底暴击+2% / 命中+5%）
- 前缀池（≤3，百分比）：攻击/生命/防御
- 后缀池（≤3）：暴击率/暴击伤害/命中/闪避/吸血/掉落数量/稀有度/材料掉率
- 命中/闪避/速度的词缀给**固定数值**（不给百分比）
- 速度单独一套固定数值T阶表

**4. 稀有度随词缀条数（活的）**
- 仅基础=白 / 2~3条=蓝 / 4+条=金
- 增缀石加条→升稀有度；剥离石减条→降稀有度

**5. 新增资源词缀作用**：掉落数量/稀有度/材料掉率走乘法叠+边际稀释（只限资源类）

**测试**：vtest_affix / vtest_bag 全绿，新增 12 部位生成 + 稀有度随条数断言

## 子代理 B：属性公式 + 战斗判定（pet.js / battle.js）

**现状**：
- `pet.js getStats`：base 含成长，词缀%乘base(含成长)，`s.x = base + flat + floor(base*pct/100)`
- `pet.js baseStats`：hp/atk/def/spd + profile机制(critRate/dodge/hit/lifesteal)
- `pet.js createPet`：equipment 3槽
- `battle.js calcDamage:230`：`hitChance = max(0.2,min(0.95,hit-dodge))` 减法

**改成**：

**1. 宠物本体**：只剩 hp/atk/def/spd + 成长。删掉机制属性（暴击率/暴击伤害/命中/闪避/吸血全挪到装备，本体清0，靠装备基础词缀保底）

**2. 公式拆两块**（彻底脱钩）：
```
宠物本体 = base + lv×growth×coeff   （纯养成线）
装备贡献 = Σ[ 该装备基底(放大后) × (1 + 该装备词缀%和) ]   （每件自算，装备间不相乘）
总属性 = 宠物本体 + 装备贡献   （相加，不相乘成长）
```

**3. 命中判定改比值**：
```
命中率 = 攻击方命中 ÷ (攻击方命中 + 防御方闪避)
```
命中/闪避都是固定数值（弃百分比）。保留保底/封顶（如 5%~95%）

**测试**：vtest_ui / vtest_deep 全绿，新增比值命中断言
