## 1. 一句话定位

> **暗黑水墨风的挂机养宠 + 宠物/装备真实交易**：刷怪掉宝 → 鉴装换装 → 养成决策（合成/进化/涅槃）→ 把产出放进一个"有人、有货、可捡漏"的交易市场。

玩家记住的三爽点（按用户排序，任何新玩法先问是否服务这三条）：

1. **掉宝 / 鉴定** —— "捡到好东西 + 揭晓词缀那一刻"是全游戏第一 G 点；
2. **市场捡漏** —— 逛市场发现别人挂漏的好货、比 AI 更懂价、低买高卖；
3. **成长跳变** —— 平时慢，关键节点"哇"一下（进化换形态 / 合成大涨 / 涅槃蜕变）。

不靠：充值页、战力排行榜、强制在线、PvP、build 深度构筑。

## 2. 玩家在玩什么：三条循环（一图流）

```
┌─ 分钟级：挂机刷怪 ── 单池一场一抽 ──► 掉 材料 / 未鉴定装 / 蛋 / 空气
│                                         │
│                                  白装分解 → 低阶通货
│                                  蓝金装 → 鉴定石揭晓 → 比身上好？穿 / 上架 / 分解
│                                         │
│                                         ▼
│                                  材料囤积 → 打造 / 喂宠 / 卖
│                                         │
└─ 天级：宠物养成决策 ── 进化(换形态) / 合成(融成长) / 涅槃(60级重生涨成长)
          → 更强 → 刷更深的图 → 掉更好的货 ──────────►

                    市场（随时可中断挂机来操作）
    上架装备/宠物/材料 → AI 与玩家来买 → 收到材料当钱花 → 偶尔捡漏 / 被捡漏
```

- **等级爬升（1→60）** = 走一遍主城/地图/背包/宠物/装备/市场所有功能，同时解锁进化与技能。
- **毕业后** = 图 10（60 级毕业图）当农场：满级经验自动凝**凝魂晶石** → 喂涅槃 / 当交易硬通货；好装备挂市场博弈；宠物往高成长涅槃养。
- **终极目标**（对玩家来说）＝养出一只成长接近上限的宠物 + 一身满意的毕业词缀装；对市场来说＝玩家在"识货、定价、倒卖"上和整个模拟市场长期过招。

## 4. 系统逐个讲

### 4.1 地图 · 挂机 · 战斗

**规则**（✅ 已落地）：
- 17 张野外图连续推进，每图有：怪等级段、**推荐成长值**、专属掉落。图名/等级：枯荣之地[1-6] → 泣腐泥沼[7-12] → 白骨旷野[13-18] → 幽影迷境[19-24] → 血潮裂谷[25-30] → 回响崖[31-36] → 腐沼泽[37-42] → 余烬渊[43-48] → 魂渊[49-54] → **腐变之源[55-60]（当前毕业图）** → 腐变裂隙…腐变本源[97-100] 🔒。
- **世界地图 = 选图界面**：不进图也能看到这张图"掉什么"（专属材料 / 进化素材档位 / 金装概率 / 推荐成长）——掉落预览挂节点上，但**绝不显示"这图掉哪种蛋"**（怕暴露蛋=基础宠机制，也避免玩家觉得基础宠蛋没意思，拍板）。
- **战斗全自动**：双方行动条按速度累积，满了出手（攻/守/暴击/闪避/技能），血低于 30% 自动停战 → 回城回满 → 回来继续。速度差直接体现为出手频率差。
- **服务器托管挂机（battle-settle）**：最小化/关页也照挂——服务端每 30 秒结算下发真值，本地只"放电影"（演出伤害用与服务器同一套公式算，结果仍以服务端战报为准）。URL 加 `?noidle=1` 可退回纯本地模式（旧退路）。✅
- 野怪分普通 / 进化型 / **变异型**三档，图 6 起见变异怪；数值表定死，不引动态难度。

**设计意图**：这是"挂机"，不是"放那不管"——玩家**选图就是策略**（要材料去 A 图、要进化素材去 B 图、要高阶底材去深图），掉落预览把"去这图值不值"摊在桌面上。

### 4.2 宠物养成（游戏最重的系统）

#### 起点：蛋 → 8 大血统
掉落/市场获得**宠物蛋**，孵化出 8 系基础宠之一：**腐噜兽 / 血狐 / 瘟熊 / 疫毛兽 / 骨狼 / 毒沼蛙 / 尸犬 / 幽影兔**，随机成长值（婴儿 3~8）+ 随机特质。每系天生 5 围成长系数不同（肉盾/输出/速度定位差异）+ 专属**血统被动**。

#### 成长值 growth（宠物的"品级"）
- 数值 3~8 起步，软上限 **100**。
- 宠物战力基本由「成长值 × 等级」决定，全图怪按成长推荐（图 1 要成长 3 → 图 10 要成长 21）。

#### 三条养成路径（决策核心）
| 系统 | 门槛 | 干什么 | 设计意图 |
|---|---|---|---|
| **进化** | Lv10/35/60 形态节点 + 素材，最多 10 次 | 沿进化树换形态（8 系各有分叉，Lv60 到终形态）；形态到顶可"继续进化"只涨成长；**素材按次数升档**：第 1-3 次普通 / 4-6 精粹 / 7-10 传说；成长每次 +0.1~0.2（象征性，10 次最多约 +2） | 进化价值 = 换形态/新立绘/解锁技能，成长质变交给合成/涅槃。⚠️ 09-04 拍板过"淬体成长表 + 技能 I/II/III 档"重构，代码侧被回滚吞掉**未落地**，待重做 |
| **合成** | 双宠 Lv40 + 合成之石 | 主宠 60% + 副宠 40% 成长融合成新宠（主宠血脉保留）；**概率变异**出「·异变」宠（+成长，另有立绘） | 中期主要成长来源，"赌一把变不变异" |
| **涅槃** | 双宠 Lv60 + 涅磐兽 | 主宠吸副宠 50% 成长，副宠消失，**主宠重置回 1 级**再练；成长≥60 后吸收减半（防膨胀），软上限 100；可投凝魂晶石加吸收 | 毕业循环发动机：满级溢出经验 → 凝魂晶石 → 涅槃加吸收 → 重新练级 |

#### 特质 / 觉醒 / 魂铸（性格与传承层）
- **8 种特质**（疾风/嗜血/狂暴/战意/精准/坚韧/铁壁/灵巧），各 T1~T3 三档（**T1 最强最稀有**）。**铁律：特质一律不含攻击%，只做暴击/暴伤/吸血/命中/闪避/速度/生命%/防御%等机制与生存属性**。
- 特质来源：蛋孵化随机带 → **合成继承（主 70%/副 40%）→ 涅槃可植入**；变异宠孵化更高档特质。
- **觉醒**：Lv60 终形态解锁觉醒槽——血统专属加成 + 技能强化（每系一档，数值见 config awakenBonus）。
- **魂铸**：把宠物"灵魂"铸进装备（普通/精锐/传承三档，按宠物等级+成长+是否觉醒区分）→ 装备获得 1 条**永久魂铸词缀**。门槛式（够了才给），不是"宠物越强魂铸越强"的放大式。

#### 主动技能（Lv60 毕业奖励）
每系进化树两条分支的**终形态各自带 1 个专属主动技**（共 16 个），Lv60 学会，战斗中冷却 3 回合，可自动挂机按触发概率施放、也可手动点按钮（配置全在 config activeSkills）。平衡铁律：**全技能期望提升压在同一量级、不许任何一系超模**（触发概率×倍率都在 config 里写死并对齐）。变异宠继承本体技能。

**对齐链（重要，全系统门槛是锁死的）**：进化三节点 10/35/60 = 合成 40 < 涅槃/技能/觉醒/毕业图 60。60 = 等级上限 = 涅槃门槛 = 毕业图顶点，改动任何一处都要复查全链（config.js 注释里反复强调）。

### 4.3 掉落与材料经济

**掉落（✅ 单池·一场一抽，2026-08-31 改版）**：每场只摇 1 次，四种结果互斥——无掉落 ≈76% / 材料 ≈21% / 装备 ≈1.5% / 蛋 ≈1.5%。一场最多 1 件，杜绝背包刷屏、好东西被"又平又乱"埋掉。装备/蛋是低概率"惊喜档"。

**材料是钱**（本游戏没有金币，交易全以物易物）：
- **区域专属材料**：17 张图各掉 1 种，推动"换图刷材料"；
- **进化素材**三档：普通 → 精粹 → 传说（按进化次数升档，见 4.2）；
- **通货类**：鉴定石（揭晓词缀）、重铸石/增缀石/剥离石/神圣石（打造，见 4.4）、合成之石、涅磐兽（合成/涅槃门票）、锁定石（图 16/17，当前锁死）；
- **凝魂晶石**：满级宠物溢出经验每 12000 自动凝 1 颗（账号级、云端）——**满级挂机 = 凝魂晶石农场**，晶石可加涅槃吸收、可当交易筹码。

**设计意图**：材料按"用途 + 稀有度 + 图档"分层，玩家自己决定卖还是囤；"掉落那一刻"用金装扫光、稀有材料弹窗做出冲击感（这条还在持续打磨）。

### 4.4 装备与打造（第二重核心）

**产出链**：刷图掉**未鉴定装备**（只有部位和底材可见）→ 用**鉴定石**揭晓 → 才知道稀有度/词缀 → 这就是"鉴定 G 点"。

**结构**：
- **12 部位**：武器/戒指/项链/头盔/护甲/盾牌/腰带/靴子/斗篷/饰品/护符/徽章；
- **稀有度 = 词缀条数唯一决定**：1 条白 / 2 条蓝 / 3 条金（颜色不造假）；
- **颜色按图档抽**：图 1 几乎全白 → 图 17 近 8 成金；总出装率不变（≈1.5%），深度只改"出装时是啥颜色"——这就是"刷深图赌金装"的来源（掉落预览里的金装概率即此）；
- **底材 T1~T5**（随图档）：决定白字基础值上限；
- **词缀 T1~T5** + 数值分档：词缀类型按部位权重出（武器爱出攻击系、盾牌爱防御系…），有"图档门"（低级图掉不出高级词缀）；
- 属性口径：攻击/生命/防御/速度 + 暴击/暴伤/命中/闪避/吸血/穿透/增伤/减伤。

**打造台 5 通货**（随机性的"后悔药"，各管一层）：
| 通货 | 效果 |
|---|---|
| 重铸石 | 全部词缀重洗（类型/T/数值全随机，高风险） |
| 剥离石 | 随机删 1 条词缀 |
| 神圣石 | 只重 Roll 数值、类型与 T 不变（洗出高 Roll） |
| 增缀石 | 加 1 条新词缀（满 3 条不可用） |
| 锁定石 | 锁 1 条词缀：重铸/神圣跳过它，但之后每次重铸多耗 1 颗（持续消耗防毕业太快） |

**分解**：白装分解出低阶通货，蓝金分解出对应打造石——保证"刷出来的垃圾不完全是垃圾"，也是打造石的稳定来源。
**魂铸词缀**：宠物魂铸的产物，每件装备**上限 1 条、永久**（不能被剥离/重铸/神圣洗掉），总词缀上限 = 前 3 + 后 3 + 魂 1 = 7 条。

**伤害公式取向**：百分比词缀只放大「基础值 + 等级系数」底座，成长增量与固定值不参与乘算（防百分比叠出二次方爆炸）。

### 4.5 市场与 AI 经济（毕业后的对手戏）

**形态**：真·交易市场——玩家互相买，另有 **20 个 AI persona（不标"AI"，以昵称/等级呈现）** 填充供给与需求。✅ 前端沙箱版已落地（每个浏览器各自市场）；🔒→📐 服务端共享市场（所有人看到同一个）未做。

**AI persona 设计**（📐 方案已拍板，阶段 1 已落地大半）：
- 20 人分 **等级档**（40% 新手图1-4 / 45% 中坚图5-10 / 15% 毕业图11-17）与 **流派**（55% 输出 / 25% 坦克 / 20% 速度，各带血统偏好 + 词缀口味）；
- AI 按自己流派"真玩"：产出真货（复用真实掉落）、缺什么买什么、买走 **80% 直接消耗离场（sink）**，绝不回流 → **AI 群体不印钱**；
- **AI 会犯错**（博弈空间来源）：挂漏 ~5%、买贵 ~3%、对特定血统/词缀组合有"识货盲区" = 玩家比 AI 更懂价能赢钱；
- AI 之间**互不交易**（防对倒洗单）；AI 只买不高于价值模型上限的单。

**双层价格锚（"尺是死的，价是活的"）**：
- **魂值（公允价）**：策划维护的抽象成本表 = 地板，不随供需动、**不挂在任何会贬值的材料上**；
- **市场价**：成交移动平均价，随供需/抄底/短缺波动；
- 玩家靠**动态比价标签**读市场（"比均价低 30%" = 漏 / "较公允价 +40%" = 溢价，可炒可等回落）📐 标签 UI 为待做；
- **红线**：消耗端必须存在（AI 买走的东西必须离场）；AI 只收合理价。

**材料 = 像钱（稳）**，装备/宠物 = 像商品（随需求浮）。交易抽成沿用"每满 8 收 1"。

**为什么需要 AI**：魂值设不出"哪件装备值钱"——需求结构只能由"有人在玩 DPS/坦克/速度"长出来。AI 提供持续、真实的需求与供给；策划的杠杆是调 persona 流派分布，而不是写死物价。

### 4.6 任务与新手引导（引导 = 任务链）

- **任务五类**：新手引导链 / 主线（跟图档解锁）/ 日常 / 成就 / 宠物日常。界面顶栏有**引导条（quest-tracker）**常驻提示"下一步该干嘛"。
- **新手引导 = 一环套一环的任务链**（新手链做到"第一次涅槃"为止）：上一个任务的完成即接续下一个，不留断层；引导步玩家**必定能立即完成**——前置资源在任务奖励里给足（如先送装备再要求穿、先发素材再要求进化），禁止"去进化但没素材"的死循环。
- **教程是可选**：进游戏先问"要不要教程"；**跳过 = 不发新手礼包**（礼包是完成教程的报酬）。教程期内自动开**加速模式**（经验/掉率/战斗提速等 blessing），完成全链发新手礼包（经验道具 + 一套蓝装 + 一只成长 8 副宠设出战）✅。
- 日常/成就是中后期在线理由，主城任务中心领交。

### 4.7 账号 · 云端 · 托管挂机

- 注册制（邀请码 + 邮箱密码），宠物/材料/装备/市场单/钱包全云端（Supabase），换设备可续。材料增扣、AI 买入走服务端 RPC（含限流/日上限/账号年龄守卫）。
- **服务端托管挂机**（见 4.1）：服务端每 30s 结算并下发战报，本地演出不造假。
- ⚠️ **技术债**：掉落/打造/进化等"规则"仍在客户端算（客户端权威），DevTools 能改；RLS+RPC 只防外人直连、防不了玩家改前端后合法提交。**服务端权威 = 上线前必做**（详见宪法）。

### 4.8 付费（当前不开放）

- **不做个人收款码**（易举报违规，已拍板废止）。正式收款需官方支付 SDK + 企业/个体主体 + 版号 + ICP。
- 代码侧预留完整结构但**总开关关闭**（`Config.shop.enabled=false`）：魔石（1 元=10）→ 商店购道具；服务端定价（products 表）；卡密兑换；订单表。自测用 `grant_gems` 发币。
- **氪金三原则**（拍板）：天花板不变、只许加速不许加高；皮肤不加数值；功能只做经济向不碰战斗数值。

### 4.9 美术风格（已定调）

- **古典水墨山水 + 羊皮纸做旧**；墨黑/灰白为主，暗紫（腐化）、锈红/血红（血潮）、病绿（瘟疫）少量点缀，**几乎不用亮金/油画质感**。
- 图标：内置文生图水墨风 → 白底"墨画贴片"，CSS 圆角嵌入；材料/通货/血统已接入。
- 宠物显示**铁律**：一律走立绘/头像，**不回退 emoji**（缺图宁空）。进化树 8 系 × 多形态 + 变异宠立绘覆盖约 6 成，变异/地图背景等有缺口（见 §7 待办）。

## 6. 已拍板"不做"清单（避免讨论跑偏，全部有日期）

1. 不做 build 深度构筑（词缀不做系列化 build）。
2. 不做"盘"系统（拍卖/盘口玩法）。
3. 不做掉落保底（挂机游戏不需要）。
4. 不做"成长值越高 → 被动越强"的放大式曲线；成长只做门槛（魂铸/图档/淬体口径一致，注：淬体成长表重构未落地，见 4.2）。
5. 不做氪金分层 / 品级系统 / 五行种族值（对 8 宠拉平是破坏）。
6. 不做"同怪只计最先接任务的限时计数"式反体验设计。
7. 无个人收款码；商店入口默认全关。
8. 蛋/蛋池信息不对外展示（防暴露"蛋=基础宠"机制）。
9. 大地图 = 选图导航层，不做大地图上的行走/探索玩法（像宝可梦/暗黑节点世界，点图即进，进去还是挂机）。
