# 新手引导 · 奖励闭环设计 v1（2026-09-08）

## 一、目标与三条原则

玩家在引导期只需要明白一件事：**做完这步 → 拿到东西 → 这东西正好是下一步要用的**。

1. **奖励即钥匙**：第 N 关的奖励 = 第 N+1 关的准入资源，一物一用，不留"孤立奖励"。
2. **奖励看得见**：接任务时就知道"做完给什么、给谁用"，不是做完才知道。
3. **钥匙来得有因果**：钥匙在**上一关完成的瞬间**发，不在开局一次性塞进背包。

## 二、现状问题（必须先修的 5 处）

| # | 问题 | 影响 |
|---|---|---|
| 1 | 钥匙走 `supplyBox` 开局整箱发 | 玩家一进游戏背包就躺满东西，感知不到"上一关给的"，因果链断 |
| 2 | G5 奖励剥离石 → G6 要孵蛋；G7 奖励涅磐兽 → G8 要上架；G8 奖励重铸石/增缀石 → G9 要进化 | 三处奖励与下一关无关，是"顺手塞的"，不符合闭环 |
| 3 | **G10 魂铸需 `凝魂晶石×10`**（`soulCast.materialCount`），G9 只给 2 + 毕业包 5 = 7 | **必卡死**，玩家拿不到 3 个 |
| 4 | G5"化废为宝"分解的是白装，`salvage.white = {}`，**零产出** | 教学正反馈为空，玩家以为坏了 |
| 5 | 奖励只在任务页显示"名字 ×数量"，没有用途指向；完成只有一个 toast | "清晰可见"不达标 |

## 三、新流程（G1~G10 全链闭环）

> 钥匙 = 进入本关必须有的东西；**上一关完成的瞬间发放**。
> G1 无上一关，钥匙在引导开始时发。

| 关 | 任务 | 玩家动作 | 钥匙（哪来的） | 完成可得（给下一关的） |
|---|---|---|---|---|
| **G1** 引路人的馈赠 | 出战宠到 Lv10 | 背包用初阶经验包 | 初阶经验包×1（引导开始发） | **进化素材×1** → G2 进化 |
| **G2** 初次蜕变 | 进化 1 次 | 宠物页·进化 | 进化素材×1（G1 给） | **蓝装×1** → G3 穿 |
| **G3** 披甲上阵 | 穿 1 件装备 | 宠物页·装备 | 蓝装×1（G2 给） | **重铸石×1 + 白装×1** → G4 打造 |
| **G4** 亲手淬炼 | 重铸 1 次 | 打造页重铸那件白装 | 重铸石×1 + 白装×1（G3 给） | **白装×1** → G5 分解 |
| **G5** 化废为宝 | 分解 1 件 | 打造页一键分解 | 白装×1（G4 给） | **腐噜兽蛋×1** → G6 孵化 |
| **G6** 孵化新生命 | 孵化 1 颗 | 宠物页·宠物蛋 | 蛋×1（G5 给） | **合成之石×1 + 中阶经验包×1** → G7 合成 |
| **G7** 融合之力 | 合成 1 次 | 宠物页·合成（主宠吃副宠） | 合成之石×1 + 中阶经验包×1（G6 给，双宠顶 Lv40） | **白装×1（可上架）** → G8 市集 |
| **G8** 初入市集 | 上架 1 件 | 市集上架那件白装 | 白装×1（G7 给） | **精粹进化素材×1 + 传说进化素材×5 + 终阶经验包×1** → G9 |
| **G9** 登临终阶 | 累计进化 4 次 | 宠物页·连点三次进化（Lv25/40/60） | 精粹1+传说5+终阶经验包（G8 给） | **凝魂晶石×10 + 毕业礼包** → G10 |
| **G10** 魂铸传承 | 魂铸 1 次 | 打造页把血统特质铸进装备 | 凝魂晶石×10（G9 给） | 神圣石×2（长线打造资源） |

**闭环核对**
- G9 进化 4 次总耗：进化素材1（G2 已用）+ 精粹1 + 传说1（四阶）+ 传说4（终阶 extra）= **精粹1 + 传说5** ← 正好是 G8 奖励。
- G7 合成：`合成之石×1` + 双宠 Lv40（中阶经验包 cap40 名下全顶）← 正好是 G6 奖励。
- G10 魂铸：`凝魂晶石×10` ← 正好是 G9 奖励（现状 7，必须补到 10）。

## 四、奖励展示规格（三处，缺一不可）

**1. 顶部引导条（当前关）** —— 三行：
```
披甲上阵                          [进度 0/1]
把蓝装穿到出战魂兽身上
完成可得：🧥 蓝装已给 · 用完给 🔨重铸石×1（下一步「亲手淬炼」要用）  [去穿装备 →]
```
- 已发的钥匙显示"已给"，未发的奖励显示"完成后给"。
- **每个物品后面挂用途标签**（绿字小标）：`→ G4 打造用`。

**2. 任务页卡片 / 详情**：奖励行改成图标 + 名称 + 数量 + **用途标签**。
```
🎁 重铸石 ×1   用于「亲手淬炼」
```

**3. 领取瞬间弹窗（新做，替代 toast）** —— 这是"看得见"的关键：
```
        ✦ 任务达成 · 披甲上阵 ✦
   [重铸石图标]  重铸石 ×1
   [白装图标]    白装 ×1
   「这两样是下一步『亲手淬炼』要用的」
              [ 去用掉它 → ]
```
按钮直接跳到下一关的目标页/页签。

> 数据来源零新字段：下一关的钥匙 = `supplyBox.items.filter(it => it.taskIds.includes(nextId))`，
> UI 直接反查现有 `taskIds` 就能显示"给谁用"。

## 六、机制改动（3 处，都是小改）

1. **发放时机**：`openSupplyBox`（整箱）→ `grantKeysFor(taskId)`（按关发）。
   - 引导开始：发 `taskIds=['g1']`。
   - `completeQuest(Gn)` 成功后：发 `taskIds=[Gn+1]`，账本 keyId = `keys:{taskId}`（只发一次，防刷不变）。
   - 现有 `missingKeysFor / reissueKeys`（引导条补钥匙，每关每种限 1 次）**保留**作自愈。
2. **新增 type `exppack`**：`grantBoxItem` 支持发经验包（复用 `expPacks` 三档 + `useExpPack`），让"经验包"也变成看得见的钥匙。
3. **新增校验测试** `docs/tests/vtest_guide_chain.js`：
   - requires 链连续（g1→g10 无断口）；
   - 每关钥匙的 `taskIds` 唯一且不重复覆盖；
   - 数量守恒：G8 给的材料 ≥ G9 进化 4 次总需求；G9 给的凝魂晶石 ≥ `soulCast.materialCount`。

## 七、拍板结果（2026-09-08 用户确认）

1. **G5 分解白装零产出** → **保持零产出，靠"送蛋"给正反馈**（方案 A，不动经济）。
2. **G10 魂铸 `minGrowth:10`** → **实测没问题，不动**（既不保底顶成长，也不降门槛）。
3. **打造页能否选已穿戴装备** → **已经能用了，不用改代码。**
   查证：`ui-pet.js` 装备槽 `onclick → UI.renderBagEqDetail(eq)` → `renderEqDetailInto` 里
   `body.style.display='flex'` + `renderCraftInto('.eq-detail-craft', eq)` —— 宠物页·装备栏点身上
   那件，右栏**就是**打造面板。打造页（背包页）的列表只走 `getInventory()` 所以才选不到。
   → **G4 直接淬炼身上那件蓝装**，钥匙表去掉 g4 那件白装（少发一件、少一步找装备的操作）。
