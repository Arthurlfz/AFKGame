## 一、A 推图主线：首通 + 进度标记

- **首通** = 首次击败该图 Boss（接 B）
- **首通奖励（一次性）**：该图专属材料 ×20 + 打造石 ×3 + 进化素材包 ×3（进化素材包 = 该图档位素材，图1-2 普通 / 图3-4 精粹 / 图5+ 传说）
- **地图标记**：已首通 ✓ 金色 / 未首通 灰色
- 效果：图 1→10 是一条看得见的推图主线，配合循环任务：
  **进图 → 挂材料（循环任务）→ 遇 Boss → 首通 → 拿奖励 → 推下一图**

## 二、B 图内 Boss（先做图 1-10，11-17 玩家到不了不做）

- **出现规则**：每场 1/1600 随机（期望 1600 场 ≈ 图10 挂机 2 小时），连续 2400 场未出必出（保底），出后 200 场内不再出（冷却）；跨结算段累计（全局场数 + last_boss_fight 锚点）
- **生成方式（运行时，不改数据文件）**：取该图怪池最强怪，数值放大（血 ×5、攻 ×1.5），名字前缀「霸主·」（如"霸主·毒沼王"），标记 `isBoss`
  - ⚠️ 关键：Boss 是**模拟逻辑**不是新数据——只改 battle-sim，**不用给服务器加 enemy 数据**，config-server 快照零改动
  - ⚠️ 随机判定用独立随机流（seed 盐化），不污染战斗伤害随机序列 → 同 seed 前后端结果仍一致（server_sim 回归已验证）
- **Boss 掉落**：必掉 金装 ×1 + 区域材料 ×5（drop.js 读 isBoss 分支）
- **首通判定**：quest 统计"已击败 Boss 次数"，首次 ≥1 触发首通奖励
