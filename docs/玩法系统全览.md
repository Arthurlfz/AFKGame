# 第一部分 · 玩法系统盘点（2026-09-06 盘点）

## 一、游戏定位（一句话）

**暗黑水墨风的挂机养宠 + 宠物/装备真实交易**：刷怪掉宝 → 鉴装换装 → 养成决策（合成/进化/涅槃）→ 把产出放进一个"有人、有货、可捡漏"的交易市场。

玩家三爽点（任何新玩法先问是否服务这三条）：
1. 掉宝 / 鉴定（揭晓词缀那一刻）
2. 市场捡漏（比 AI 更懂价、低买高卖）
3. 成长跳变（进化换形态 / 合成大涨 / 涅槃蜕变）

---

## 二、核心循环（三条）

| 循环 | 内容 | 状态 |
|---|---|---|
| 分钟级 · 挂机刷怪 | 单池一场一抽 → 材料 / 未鉴定装 / 蛋 / 空气 → 白装分解换通货、蓝金装鉴定后穿/上架/分解 | ✅ |
| 天级 · 宠物养成决策 | 进化（换形态）/ 合成（融成长）/ 涅槃（60 级重生涨成长）→ 更强 → 刷更深图 → 掉更好货 | ✅ |
| 毕业 · 市场博弈 | 满级经验凝凝魂晶石 → 喂涅槃 / 当硬通货；好装备挂市场 → 与 20 个 AI persona 识货、定价、倒卖长期过招 | ✅（AI 阶段1） |

## 四、已拍板"不做"清单（避免跑偏）

2. 不做"盘"系统（拍卖/盘口）
3. 不做掉落保底
4. 不做"成长越高→被动越强"的放大式曲线（成长只做门槛）
5. 不做氪金分层 / 品级系统 / 五行种族值（对 8 宠拉平是破坏）
6. 不做"同怪只计最先接任务的限时计数"式反体验
7. 无个人收款码；商店入口默认全关
8. 蛋/蛋池信息不对外展示（防暴露"蛋=基础宠"机制）
9. 大地图 = 选图导航层，不做行走/探索玩法
