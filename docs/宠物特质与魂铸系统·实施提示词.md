## 1. 设计铁律（不可违反，违反即返工）

1. **特质一律不含攻击%**：全部是机制/生存属性（暴击/暴伤/吸血/命中/闪避/速度/生命%/防御%），防止与成长叠乘重回"单轴 runaway"。
2. **T 阶口径：T1 最强最稀有**（与现有装备词缀 T1~T5 惯例完全一致）。特质只用 T1/T2/T3 三档，T1 数值最高、概率最低。
3. **魂铸词缀：每件装备最多 1 条、永久**，不可被剥离/重铸/神圣石洗掉；装备总词缀上限 = 前缀 3 + 后缀 3 + 魂铸 1 = 7 条。
4. **成长 hook 是"门槛式"，不是"放大式"**：成长只做解锁条件（≥10 / ≥40 / ≥60），**禁止**"成长越高 → 铸魂/继承越强"的线性加成。
5. **继承强度先松后紧**：合成继承 主 70% / 副 40% 起步。
6. **氪金宠三原则**（本期只埋 `source` 字段，不做氪金宠内容）：① 天花板不变，只许加速不许加高；② 皮肤不加数值；③ 功能只做经济向，不碰战斗数值。
7. **评分（scoreOf）**：不展示给玩家、不参与市场排序；保留内部仅用于批量分解参考。
8. **精准特质**：保留（后期图会加高闪避怪让它有价值，本期不额外处理）。

## 2. 数据层（数值唯一源 = config.js；旧"数据地图"已废弃）

在 `js/core/config.js` 新增（数值以设计稿 §1/§2/§3/§4 为准）：

- **PET_TRAITS（8 条 × T1/T2/T3）**：
  | 特质 | 类型 | T1 | T2 | T3 |
  |---|---|---|---|---|
  | 嗜血 | +吸血 | +8% | +5% | +3% |
  | 狂暴 | +暴伤 | +25% | +15% | +8% |
  | 战意 | +暴击率 | +6% | +4% | +2% |
  | 精准 | +命中 | +12 | +8 | +5 |
  | 疾风 | +速度 | +8 | +5 | +3 |
  | 铁壁 | +防御% | +12% | +8% | +5% |
  | 坚韧 | +生命% | +12% | +8% | +5% |
  | 灵巧 | +闪避 | +8 | +5 | +3 |
- **孵化特质概率**：0/1/2/3 条 = 40% / 45% / 13% / 2%；单条 T 阶 = T1 10% / T2 30% / T3 60%。
- **变异宠（·异变）**：保底 1 条；T 阶整体抬升（T1 概率 10%→20%，保底不低于 T2）；3 条概率 2%→8%。
- **觉醒特质（16 个终形态各 1 条）**：= 对应主动技能伤害 +20% + 血统定位加成（血狐系暴伤+10%、瘟熊系防御+8%、疫毛/幽影系速度+4、骨狼/尸犬系吸血+3%、腐噜/毒沼系生命+5%）。实现：直接挂在 `activeSkills` 同表加 `awaken` 字段。
- **合成继承规则**：主宠特质每条保留 70%；副宠每条继承 40%；继承时 20% 概率向 T1 升一阶（封顶 T1）、10% 概率向 T3 降一阶（最低 T3）；变异成功额外追 1 条随机新特质（总条数上限 3）；里程碑：主宠成长≥60 时继承概率整体 +10%（一档封顶）。
- **涅槃植入**：主宠特质全保留；副宠每条 30% 概率植入主宠（同类型取高 T，不叠加）。
- **魂铸档位**：
  | 档位 | 解锁 | 可铸 | 铸出词缀 |
  |---|---|---|---|
  | 普通 | 宠 Lv40+ / 成长≥10 | 血脉特质（自选 1 条） | T = 原 T 阶 |
  | 精锐 | 宠 Lv40+ / 成长≥40 | 血脉特质 | T 向 T1 升一阶（封顶 T1） |
  | 传承 | 宠 Lv60 终形态 / 成长≥60 | 觉醒特质 | 固定 T1 |
  - 消耗：装备 + 宠物（消失）+ **10 颗凝魂晶石**。
- **来源字段 `source`**：默认 `'normal'`，预留 `'gacha' / 'activity' / 'first_charge'`（本期只加字段，不做氪金内容）。

## 4. 代码实现顺序

1. **config.js（唯一数值源）**：按 §2 加全部数值与规则配置。
2. **pet.js**：宠物加 `traits / awaken_trait / source` 字段；`getStats` 结算特质加成（暴击/暴伤/吸血/命中/闪避/速度走 flat，生命/防御走 pct）；孵化/变异时 roll 特质。
3. **pet_merge.js**：合成继承逻辑 + 涅槃植入逻辑（**成长公式一律不动**）。
4. **equipment_craft.js**：新增"魂铸"动作 + 魂铸词缀规则（永久、每件 1 条上限、上架后不可再打造）。
5. **UI（js/ui/*）**：
   - 宠物卡片显示血脉特质（T 阶色）+ 觉醒特质（终形态）；
   - 孵化弹窗显示特质结果；
   - 合成/涅槃面板预览继承/植入概率；
   - 铁匠铺新增"魂铸"tab（选装备 → 选宠 → 选特质 → 确认）；
   - 市场：宠物行显示特质、装备行显示魂铸词缀；新增筛选（特质类型 / 有魂铸词缀）；
   - 图鉴/百科：特质图鉴（8 条 × T1~T3 + 16 觉醒）。
6. **市场（market.js / market_bot.js）**：
   - listing 快照带 `traits`（宠物）与 `soul_affix`（装备）；
   - 假买家（流浪商人）估价参考"成长 + 特质 T 阶"；
   - **移除综合分排序**，改为结构化筛选（稀有度 / 词缀数 / 部位 / 是否带魂铸 / 特质类型）。
7. **测试**：在 `tests/` 补 vtest——特质 roll 分布、继承概率、涅槃植入、魂铸档位、存档兼容回归；跑通现有全部 vtest。
