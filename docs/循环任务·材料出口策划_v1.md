# 循环任务 · 材料出口策划 v1.2

> 生成：2026-09-05｜v1.2：收集数量 5→50（实测单场 4.3~7.5s 后重定），打造石按新体量重配
> 用途：给 17 种区域材料装"消费出口"，让掉落有期待、挂图有目标。
> 一句话：**每图 1 个可重复的收集任务，交 50 个材料换 打造石 + 经验。**
>
> 数值来源：`docs/js/core/config.js`（areas / drop.pool / materialWeightsByTier / exp / craft）
> 场速来源：`battle-sim.mjs` 真实模拟（无装备·推荐成长·血狐基准：图1 每场 7.5s / 图5 5.5s / 图10+ 4.3s）

---

## 一、为什么做（实证）

grep 全项目代码结果：**17 种区域材料（枯荣种荚…本源腐核）只出现在 config 定义 + 掉落逻辑里，零配方 / 零任务 / 零兑换消耗**。
对比：凝魂晶石 20 处用途引用、涅磐兽 50 处——那俩才是"有用的材料"。

叠加 `drop.pool = { none: 760, material: 210, equipment: 15, egg: 15 }`（76% 空气）：
玩家掉的每 10 件东西里，约 7 件空气、2 件是不知道干嘛的区域材料 → **"掉落没期待" = 实证**。

循环任务把"区域材料"变成"任务进度"，三个洞一起补：
- 材料有出口（交任务消耗）
- 掉落有期待（掉到任务材料 = 进度 +1）
- 挂图有目标（"还差 13 个种荚交一单"）

---

## 二、规则（大白话）

1. **每张图 1 个循环任务**：收集 50 个该图区域材料。
2. **交任务** → 领奖励（打造石 + 经验）→ **自动再接同一个**，无限循环。
3. **解锁**：打过该图即解锁该图循环任务（跟随主线进度）。
4. 数量与奖励全部走 config 配置，一行一个任务。

循环：**挂图 → 掉该图材料 → 交任务 → 得打造石/经验 → 变强 → 挂更高图**

### 数值验证（可复算）

- **收集时长**（battle-sim 实测，无装备·推荐成长基准）：
  - 区域材料掉率 ≈ 6.5%/场（材料 21% × 区域材料权重占比 ~31%）
  - 50 个 ≈ 770 场 × 4.3~7.5s ≈ **55~96 分钟一单** ✅（图 11-17 越级图会偏久，实际以玩家装备为准）
- **经验**：图10 一单 3450 ≈ 0.8 级/单（未满级玩家 bonus；满级后经验转凝魂晶石池，打造石为主奖励）
- **打造石供给**：一单 5-8 个 → 一晚 8 小时挂机约 5-8 单 → 25-40 个/晚 → **足够玩家做 25-40 次装备操作**，激活装备系统；数字落地后挂机实测校准

## 五、边界（不碰的东西）

- 不改掉落概率（drop.pool 保持原样，减空气是后续单独项）
- 不加新 UI 页面（复用任务列表）
- 不做兑换台 / 材料商店（避免"收集囤积"感）
- 不动宪法：不碰成长上限、不做保底、不加品级
