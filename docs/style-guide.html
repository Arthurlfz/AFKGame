8 · 使用禁则

· 禁灰蓝（所有底色 RGB 暖调或中性，R ≥ G ≥ B）
· 禁铜锈 / 塑料感（暗金必须亮，用熔岩金 #f0a92e 系；金属色一律暖灰）
· 禁后台 / 文档风（无白色大面板、无大圆角堆叠、无彩色标签轰炸）
· 禁紫色渐变 / 玻璃拟态（背景只允许纯色 + 皮革颗粒纹理，不做毛玻璃）
· 禁 emoji（图标用文字符号 / 矢量 / 程序化图形）
· 禁粒子特效与大动画（动画仅限状态反馈：hover 加热、按下凹陷、低血量脉动）
· 信息密度优先：基础字号 12px，圆角 ≤4px，分隔用 1px 弱线
· 强调色只有熔岩金；危险操作走血晶红；幽蓝仅限魔力与蓝装，不参与按钮主色
