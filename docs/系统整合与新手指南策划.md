### 三条铁律（写教程时必须守）

1. **没有「第一幕 / 第二幕」概念**——就是一条 **17 图连续进度**（图1-17 覆盖 1-100 级）。本文件只用图档 / 等级段表述。
2. **任务链一环套一环**——上一个任务的尾巴 = 下一个任务的头，完成即接续，不留断层。
3. **新手引导不许卡手**——引导步骤玩家必须能立刻做完；前置资源（装备 / 素材 / 宠物）在任务奖励里给足，禁止「去穿装备但背包空」「去进化但没素材」这种死循环。每个教程步骤都标了「前置资源保障」栏。

## 1. 系统全景整合

### 1.1 一句话核心循环

> **挂机刷怪 → 掉东西 → 养成宠物 + 攒装备 → 打更深的图 → 把多余的挂市场卖掉换材料 → 继续养成。**

玩家真正做的操作只有一件：**选一张图挂机**。其余系统都是"让挂机产出有去处"。

### 1.5 玩家旅程时间轴（1 → 100 级）

> 基准：360 场 / 小时（约 10 秒一场，项目既定口径）。
> 每升一级所需场数约等于 `5.5 × 等级^0.3`（Lv1 约 5 场、Lv10 约 11 场、Lv30 约 15 场、Lv60 约 19 场）。
> 下表的场数是**理论下限**（假设怪物等级始终跟得上宠物等级）。实战中怪物等级被**钳进地图等级段**（图1 只到 6 级），必须换图才能持续拿满经验，实际耗时会比下表长。

| 阶段 | 等级段 | 图 | 解锁什么 | 累计场数（理论） | 累计耗时（理论） |
|---|---|---|---|---|---|
| 起步 | 1-6 | 图1 枯荣之地 | 挂机、掉落、任务、穿装备 | 约 30 场 | 约 5 分钟 |
| 首次进化 | 10 | 图1-2 | **第一次进化**（换形态） | 约 83 场 | 约 14 分钟 |
| 二段进化 | 35 | 图6 回响崖 | 第二次进化 | 约 370 场 | 约 1 小时 |
| 合成开启 | 40 | 图7 腐沼泽 | **合成变异**（出·异变宠） | 约 490 场 | 约 1.4 小时 |
| 毕业 | 60 | 图10 腐变之源 | **终形态 + 主动技能 + 觉醒 + 涅槃** 同点解锁 | 约 840 场 | 约 2.3 小时 |
| 深潜 | 61-100 | 图11-17 | 反复涅槃叠成长、魂铸、凝魂晶石 | 约 1660 场 | 约 4.6 小时 |
| 满级之后 | 100 | 任意图 | 溢出经验 → 凝魂晶石（晶石农场） | — | 无限 |

**关键节点提示**：
- **Lv60 是第一个大高潮**：终形态 + 学会主动技能 + 解锁觉醒 + 解锁涅槃，四件事同时发生。
- **涅槃会重置等级回 Lv1**，但成长留着——这是"主动倒退换长期变强"的设计，也是玩家最容易懵的地方，**教程必须讲清楚**。
- 满级 100 之后继续挂机不浪费：溢出经验凝成凝魂晶石，可给涅槃加成、魂铸、或拿去卖。

## 2. 30 分钟教程总设计

### 2.1 设计目标

> **玩家从进入游戏到亲手玩完所有核心系统，约 30 分钟**（目标值，允许 ±5 分钟浮动，不是硬指标）。

四条要求（用户拍板）：

1. **加速 · 真玩**：教程期走加速模式（经验倍率 / 战斗速度 / 掉率 / 门槛临时放宽），玩家**亲手操作**每个系统，不是看演示动画。
2. **全流程覆盖**：从选宠一路玩到深图（图11-17），包括合成变异、涅槃、觉醒、主动技能、魂铸。
3. **零卡手**：任何一步玩家都必须能立刻做完，前置资源一定给足。
4. **教程可选 · 跳过无奖励**：进游戏前先问玩家要不要教程；**跳过的玩家拿不到新手礼包**——礼包是完成教程的报酬，不是注册福利。

### 2.2 教程 mode 加速方案

**为什么必须加速**：正常节奏下 1→60 级约需 840 场 ≈ 2.3 小时，而 30 分钟只有约 180 场（按 10 秒/场）。不加速连进化都摸不到，更别说涅槃。

**加速三件套 + 门槛放宽**：

| 参数 | 正常值 | 教程期建议值 | 作用 |
|---|---|---|---|
| 经验倍率 `exp.rate` | 1.0 | **6.0** | 每级所需场数降到 1/6 |
| 战斗速度（每场耗时） | 约 10 秒 | **约 3 秒** | 同样时间打 3 倍场次（缩短行动条 / 场间隔） |
| 装备掉率 | 1.5% | **8%** | 保证稳定掉到装备（穿装 / 鉴定 / 打造 / 分解都要用） |
| 宠物蛋掉率 | 1.5% | **6%** | 保证能体验孵化 |
| 合成门槛 `synthesize.minLevel` | Lv40 | **Lv20**（教程期） | 否则来不及练到 40 |
| 涅槃门槛 `nirvana.minLevel` | Lv60 | **Lv30**（教程期） | 否则来不及练到 60 |
| 进化门槛 | Lv10 / 35 / 60 | **保持真实值** | 进化是核心体验，靠经验加速自然达成，不改门槛 |

**场次推算（校验 30 分钟够不够）**：

- 每级所需场数 ≈ `5.5 × 等级^0.3`，经验 ×6 后变为 `0.92 × 等级^0.3`
- 战斗加速到 3 秒/场

| 目标等级 | 正常累计场数 | 加速后累计场数 | 加速后挂机耗时 |
|---|---|---|---|
| Lv10（首次进化） | 约 83 场 | 约 14 场 | 约 0.7 分钟 |
| Lv35（二段进化） | 约 370 场 | 约 62 场 | 约 3.1 分钟 |
| Lv60（终形态/觉醒/技能） | 约 840 场 | 约 140 场 | 约 7.0 分钟 |

**结论**：纯挂机到 Lv60 只需约 7 分钟。30 分钟里留 10~12 分钟挂机、其余时间做操作与讲解，节奏宽裕，不会赶。

**门槛放宽的注意事项**（✅ 用户已拍板"可以放宽"）：
- 教程期降低合成 / 涅槃门槛，是为了让玩家在 30 分钟内摸到；**必须明确告知真实门槛**（合成 Lv40、涅槃 Lv60），否则玩家出了教程会困惑。
- 教程的合成 / 涅槃步骤里必须加一行小字：`教学加速：真实门槛为 Lv40 / Lv60`（第 9 章、第 11 章弹窗已写）。

### 2.3 30 分钟时间轴切分

| 章 | 标题 | 教什么 | 预算 | 累计 |
|---|---|---|---|---|
| 1 | 选一只伙伴 | 8 选 1，看懂定位标签 | 1.5 分钟 | 1.5 |
| 2 | 第一次挂机 | 选图、开始挂机、看战斗 | 2.5 分钟 | 4 |
| 3 | 掉东西了 | 掉落、材料进背包、爽感反馈 | 2 分钟 | 6 |
| 4 | 第一次进化 | 练到 Lv10，选分支进化 | 3.5 分钟 | 9.5 |
| 5 | 穿上装备 | 穿装备、看属性变化 | 3 分钟 | 12.5 |
| 6 | 鉴定与打造 | 鉴定石开箱、4 种打造石、分解 | 4 分钟 | 16.5 |
| 7 | 新生命 | 孵蛋、得到第二只宠 | 2 分钟 | 18.5 |
| 8 | 做生意 | 上架、购买、理解材料计价 | 3 分钟 | 21.5 |
| 9 | 合成变异 | 两只宠合成，赌·异变 | 2.5 分钟 | 24 |
| 10 | 觉醒与技能 | 冲 Lv60 终形态（**挂机并行**，操作只占 1.5 分钟） | 1.5 分钟 | 25.5 |
| 11 | 涅槃 | 吸成长、等级重置（重点讲解，最容易劝退） | 2.5 分钟 | 28 |
| 12 | 魂铸 | 宠物 → 装备词缀 | 1.5 分钟 | 29.5 |
| 13 | 毕业 | 重置 + 发新手礼包 | 0.5 分钟 | 30 |

> **时间轴是预算不是硬限制。** 两条缓冲设计：
> 1. **挂机与操作并行**——玩家在做装备 / 打造 / 市场教学时，宠物在后台继续打。冲 Lv60 所需的约 7 分钟挂机藏在操作时间里，不额外占时间。
> 2. **每章都能跳过**——玩家读得慢就跳过，教程不该变成牢笼（见 2.4）。

> **顺序说明**：涅槃放在觉醒之后，是因为**涅槃会把等级重置回 Lv1**。若先涅槃再冲觉醒，玩家要练两次 60 级；先觉醒（吃掉 Lv60 的收益）再涅槃，节奏最省。

### 2.4 教程 UI 交互规范

**形态**：遮罩高亮目标区域 + 步骤弹窗（一章一节，教完解锁自由操作）。

**必须有的四件事**（UI/UX 规范硬要求）：

| 要求 | 规范 | 为什么 |
|---|---|---|
| **进度可见** | 每章顶部显示「第 X 章 / 共 13 章」+ 章内「步骤 2 / 4」进度条 | 多步流程不给进度，用户会以为卡住了 |
| **能跳过** | 每章右上角常驻「跳过教程」；章内有「上一步 / 下一步」 | 强制线性不可跳过的引导是反面模式 |
| **遮罩只高亮一处** | 同一时刻只高亮一个目标元素，其余压暗 | 高亮多处等于没引导 |
| **点高亮区即推进** | 高亮区域可点击，点中 = 完成这一步（同时弹窗按钮也能推进） | 引导要和真实操作一致，不是"看动画" |

**视觉与动效**（贴合项目 v3 水墨暗黑风 `design-tokens.css`）：

| 元素 | 规范 |
|---|---|
| 遮罩层 | 半透明深色压暗全屏（`rgb(var(--ink-rgb) / .72)` 一类，沿用项目 CSS 变量，不写死十六进制） |
| 高亮区 | 目标元素四周 2px 熔岩金描边 + 外发光，元素本身提到遮罩之上（`z-index` 高于遮罩） |
| 弹窗出现 | 淡入 + 上移 12px，300~400ms，`power1.out`（幅度要小，读作"淡入"而非"滑入"） |
| 遮罩切换 | 400~600ms，`power2.inOut`；**只用 transform / opacity 动画**，不要动 width / height / top / left（会掉帧） |
| 步骤列表 | 若一次性展开多个步骤，stagger 间隔 0.08s、**元素不超过 8 个**（超过会显得拖沓） |
| 触控目标 | 按钮最小 44×44px，间距 ≥8px |
| 无障碍 | 对比度 ≥4.5:1；不移除焦点环；图标按钮带 `aria-label`；尊重 `prefers-reduced-motion` |

### 2.5 零卡手保障：教学补给机制

**问题**：加速只解决"练级慢"，解决不了"手上没东西"。比如教「穿装备」时玩家背包是空的、教「涅槃」时没有第二只 Lv60 宠——引导就会卡死。

**方案**：教程期按章节节点**直接发放教学补给**，保证每一步都有东西可用。

| 章节 | 需要的东西 | 教学补给（教程期直接给） | 真实的获取途径（教程里要说明） |
|---|---|---|---|
| 5 穿装备 | 1 件装备 | 完成第 4 章时**直接发 1 件蓝装** | 挂机掉落（图越深金装概率越高） |
| 6 鉴定 | 未鉴定装备 + 鉴定石 | 发 2 件未鉴定装备 + 3 个鉴定石 | 鉴定石前期好掉，后期稀缺 |
| 6 打造 | 4 种打造石 | 各发 2 个（重铸/剥离/神圣/增缀） | 分解装备 / 掉落 / 市场买 |
| 6 分解 | 1 件废品 | 发 2 件白装（分解无产出，正好教"白装没用"） | 挂机掉落 |
| 7 孵化 | 1 颗宠物蛋 | 发 1 颗蛋 | 掉落（1.5%）/ 市场买 |
| 8 市场 | 可上架的东西 | 用第 5~7 章拿到的多余装备 | 挂机掉落 |
| 9 合成 | 2 只 Lv20 宠 + 1 合成之石 | 主宠自己练 + **发 1 只 Lv20 副宠** + 1 合成之石 | 副宠靠孵化练级；合成之石图7 起掉 |
| 10 涅槃 | 主宠 Lv30 + 副宠 Lv30 + 1 涅磐兽 | 发 **1 只 Lv30 教学副宠** + 1 涅磐兽 | 涅磐兽图10 起掉 |
| 12 魂铸 | 装备 + 有特质的宠 + 10 凝魂晶石 | 发 **10 凝魂晶石** + 1 只有特质的 Lv40 宠 | 满级经验池产出 / 市场买 |

**规则**：
- 教学补给**只在教程期存在**，教程结束时随重置一起清掉（不留在正式存档里）。
- 补给数量**刚好够用**：不要多给，否则玩家出了教程发现"材料来得没那么容易"，落差太大。
- 每一步的弹窗里都要写清「这东西正常从哪来」，教程不只是教操作，还要教**产出路径**。

### 2.6 教程结束与重置

**结束时发生什么**（用户拍板：教程期东西不保留，发新手礼包）：

```mermaid
flowchart LR
    A["13 章全部完成"] --> B["全屏毕业演出<br/>回顾玩家这一路：进化形态 · 合成宠 · 涅槃成长"]
    B --> C["重置：清空教程期全部进度<br/>等级 · 宠物 · 装备 · 材料 · 任务记录"]
    C --> D["发放新手礼包"]
    D --> E["回到正式开局<br/>重新选宠 · 正式数值 · 正式门槛"]
```

**重置清单**（教程期获得的，一律清空）：

| 类别 | 处理 |
|---|---|
| 宠物（含合成的变异宠、孵化的宠） | 全部清空 |
| 等级 / 经验 / 成长 | 清空 |
| 装备（掉落、教学补给、打造产物） | 全部清空 |
| 材料（掉落、任务奖励、教学补给） | 全部清空 |
| 任务进度（新手链） | 标记完成，正式流程不再出现 |
| 市场挂单 / 交易记录 | 清空 |
| **账号 / 登录状态** | **保留**（不重新注册） |

**为什么要重置**：教程期是 6 倍经验 + 放宽门槛的"作弊模式"，这些进度带进正式游戏会破坏真实节奏（玩家一开局就 Lv60 + 一堆材料）。重置后玩家带着礼包从 Lv1 正常开始，但已经懂了所有系统。

### 2.7 教程入口：先问一句「要不要教程」（✅ 用户已拍板）

> **规则**：进入游戏之前，先弹一个询问框让玩家自己选。
> **关键**：**跳过教程 = 拿不到新手礼包**。礼包是完成教程的报酬，不是注册福利。

```mermaid
flowchart TD
    A["玩家登录 / 进入游戏"] --> B{"弹询问框<br/>要不要新手教程？"}
    B -->|"要（推荐）"| C["进入分章教程<br/>13 章 · 约 30 分钟"]
    B -->|"跳过"| D["直接进正式游戏<br/>无新手礼包"]
    C --> E["全部完成"] --> F["重置 + 发新手礼包"] --> D2["正式游戏"]
    C -->|"中途退出"| D
```

**询问框文案建议**：

| 元素 | 内容 |
|---|---|
| 标题 | 「要先来一遍新手教程吗？」 |
| 说明 | 「约 30 分钟，带你亲手玩完全部玩法：进化、合成、涅槃、觉醒、打造、市场、魂铸。」 |
| 主按钮 | 「开始教程（推荐）」——副标题小字：`完成后送新手礼包` |
| 次按钮 | 「跳过，直接开始」——副标题小字：`跳过没有新手礼包` |

**设计要点**：

| 点 | 说明 |
|---|---|
| **老存档不特殊处理** | 用户拍板：老玩家（已有存档）**一样弹这个框**，不做"有宠物就跳过"的特殊判定——统一问一句最省事，玩家自己决定 |
| **跳过不给礼包** | 明确写在按钮副标题上，避免玩家跳过后才发现没礼包而觉得被坑 |
| **中途退出** | 也算跳过，不发礼包（避免"打到第 12 章退出白嫖礼包"） |
| **可重来** | 跳过的玩家之后想做教程，可在设置里重新开启（做完仍给礼包） |
| **只问一次** | 选过之后不再弹（记录在本地 + 服务端） |

## 5. 教程结束与新手礼包

### 5.1 礼包定位

> **不是补偿，是起跑助推**：教程把进度清零了，礼包负责让玩家"从 Lv1 重新开始时，比第一次玩快得多"。

三条设计原则：

1. **省时间，不省玩法**：礼包让玩家跳过前期枯燥，但进化 / 合成 / 涅槃这些节点玩家仍要自己走。
2. **全部绑定**：不可交易、不可上架、不可赠送（保护市场经济，见 5.3）。
3. **一次性**：只在完成教程时发一次，不能重复领取。

### 5.2 礼包内容清单

| 物品 | 数量 | 作用 | 相当于省下 |
|---|---|---|---|
| **经验包·小** | 5 个（各 +1000 经验） | 直接给宠物加经验 | — |
| **经验包·中** | 3 个（各 +3000 经验） | 同上 | — |
| **经验包·大** | 1 个（+5000 经验） | 同上 | — |
| **经验合计** | **19000 经验** | 约可把一只宠顶到 Lv27 上下 | 约 1 小时挂机（正常节奏约 350~475 场） |
| **新手蓝装三件套** | 武器 / 头盔 / 护甲 各 1 件（图1 底材） | 起步装备，前期不再裸奔 | 约 15 分钟刷装备 |
| **鉴定石** | 5 个 | 鉴定前期未鉴定装备 | — |
| **打造石（4 种各 3 个）** | 重铸 / 剥离 / 神圣 / 增缀 各 3 | 起步就能玩打造 | — |
| **进化素材** | 5 个 | 够走完前两次进化 | — |
| **高成长副宠** | 1 只（成长 8，Lv1，随机品种） | 未来的合成 / 涅槃肥料（正常孵化 3~8 随机，8 是顶格） | 大量刷蛋时间 |
| **涅磐兽** | 1 个 | 够做第一次涅槃 | 需打到图10 才掉 |
| **合成之石** | 1 个 | 够做第一次合成 | 需打到图7 才掉 |
| **凝魂晶石** | 10 个 | 魂铸 / 涅槃加成用 | 满级后才产出的资源 |

**为什么给「高成长副宠」而不是直接加成长**：直接送成长点数会破坏"成长靠养成"的核心；送一只顶格成长（8）的副宠，玩家仍要把它练到 Lv60 才能涅槃吸成长——**玩法没省，只是省了刷蛋的运气**。

**经验包数值校验**：
- 累计需求：`Σ 22×lv^1.3 (lv=1..26)` ≈ 19000 经验 → 礼包约可顶到 **Lv27**（不是 Lv25，原估偏保守）
- 正常挂机产出：每场 `4 × 怪等级`，图1-5 平均约 40~60 经验/场 → 19000 经验约需 **350~475 场 ≈ 1 小时**（不是 40 分钟）
- 结论：礼包省约 **1 小时**，**没有直接跳过任何系统门槛**（Lv27 远低于 Lv40 合成 / Lv60 涅槃，玩家仍得自己练到）

> **关于礼包里的 10 颗凝魂晶石**：凝魂晶石在正式流程里是**满级后**才产出的资源（满级经验池每 12000 经验凝 1 颗）。礼包提前给 10 颗，是为了让玩家早期就能体验魂铸。因为**全部绑定、不可交易、仅账号自用**，不会进入市场流通，**对供需和物价无影响**——只是把"体验魂铸"的门槛提前了。

### 5.3 绑定规则（✅ 用户已拍板）

> **已确认**：项目此前明确"不做可存储交易的经验包道具（会碰真实交易经济）"；本次礼包的经验包为**绑定版**，与既有决策不冲突。用户已拍板：**不可交易**。

| 属性 | 设定 | 理由 |
|---|---|---|
| 可交易 | ❌ 否 **（已拍板）** | 礼包是完成教程的报酬，不是商品 |
| 可上架市场 | ❌ 否 **（已拍板）** | 防止小号刷礼包倒卖，冲击真实玩家的市场 |
| 可赠送 | ❌ 否 **（已拍板）** | 同上 |
| 可丢弃 | ✅ 是 | 背包不能被塞死 |
| 过期 | ❌ 不过期 | 新手不该有紧迫感 |
| 经验包可否囤积 | ✅ **可以囤积（已拍板）** | 玩家自己决定什么时候吃，比如留给第二只宠；**用了才扣**，不用一直躺在背包里 |

### 5.4 发放与展示

| 环节 | 设计 |
|---|---|
| **发放条件** | **必须完整走完 13 章教程**（✅ 已拍板：跳过 / 中途退出 → **不发礼包**） |
| 时机 | 第 13 章毕业演出结束后，重置完成的瞬间 |
| 展示 | 全屏礼包开启演出（一排物品依次亮出），最后汇总 |
| 领取 | 自动入背包，不需要二次点击 |
| 提醒 | 顶部引导条换文案：「🎁 新手礼包已到账，打开背包看看」 |
| 防重复 | 服务端记录 `starter_pack_claimed`，只发一次 |

### 5.5 礼包之后的玩家路线

礼包给完，玩家回到正式开局。此时引导条的职责从"教操作"变成"指方向"：

| 阶段 | 引导条文案 | 指向 |

### 6.2 教程章节 × 新手链任务（一环套一环的绑定）

> **双层结构**：分章教程是"引导层"（教怎么操作），新手链任务是"任务层"（给奖励和进度）。两者一一绑定，**章节推进 = 任务完成**，这样"一环套一环"就落到了实处。

| 教程章 | 绑定的新手链任务 | 任务类型 | 完成条件 | 奖励 |
|---|---|---|---|---|
| 第 1 章 选宠 | —（无任务，选宠即开局） | — | 选定初始宠 | 初始宠 |
| 第 2 章 挂机 | t1 初醒 | kill ×1 | 打赢 1 场 | 重铸石 ×1 |
| 第 3 章 掉落 | t2 熟悉腐土 | kill ×10 | 累计打赢 10 场 | 进化素材 ×1 + **蓝装 ×1** |
| 第 5 章 穿装备 | t3 披上残甲 | equip ×1 | 穿上 1 件装备 | 重铸石 ×1 |
| 第 4 章（并行） | t11 腐土巡守 / t12 腐土猎手 | kill ×30 / ×80 | 挂机累计 | 重铸石 ×2 / 进化素材 ×1 |
| 第 4 章 进化 | t4 第一次进化 | evolve ×1 | 完成 1 次进化 | 进化素材 ×2 |
| 第 6 章 打造 | t5 初次淬炼 | craft ×1 | 用 1 次打造石 | 神圣石 ×1 |
| 第 6 章 分解 | t6 拆解废品 | salvage ×1 | 分解 1 件 | 增缀石 ×1 |
| 第 7 章 孵化 | t7 新的生命 | hatch ×1 | 孵化 1 颗蛋 | 宠物蛋 ×1 |

| 第 9 章 合成 | t9 深入腐变（调整） | synth ×1 | 完成 1 次合成 | 精粹进化素材 ×1 |
| 第 11 章 涅槃 | t10 脱胎换骨 | nirvana ×1 | 完成 1 次涅槃 | 涅磐兽 ×1 + 合成之石 ×1 |

**需要的改动（两处）**：
1. **t9 的 type 从 `kill` 改成 `synth`**：原 t9「深入腐变」是去图2 打 20 只怪，但教程第 9 章教的是合成，对不上。改成"完成 1 次合成"，名字可改为「初次融合」。
2. **新增 t13 魂铸任务**：现有新手链到 t10 涅槃就结束了，魂铸是后来加的系统，教程要教就得补一条。

**衔接保证**：新手链的 `requires` 前置依赖天然形成线性链（t1→t2→t3→t11→t12→t4→t5→t6→t7→t8→t9→t10→t13），**上一个任务的完成 = 下一个任务的解锁**——这就是"一环套一环"在代码层面的落点。

### 6.3 教程 mode 的配置设计（实现时的形状）

建议在 `config.js` 加一个 `tutorialMode` 段，**集中所有教程期参数**，与正式数值物理隔离：

```js
tutorialMode: {
  enabled: true,
  expRate: 6.0,            // 经验倍率（正式 1.0）
  fightSpeedMult: 3.3,     // 战斗提速（正式 1.0，约 10 秒/场 → 3 秒/场）
  dropBoost: { equipment: 8, egg: 6 },  // 掉率提升后的权重（正式 15 / 15）
  levelGate: { synthesize: 20, nirvana: 30 },  // 门槛放宽（正式 40 / 60）
  grants: { /* 各章教学补给清单 */ },
  starterPack: { /* 新手礼包清单 */ }
}
```

**为什么集中配置**：教程调参是高频试错（30 分钟能不能跑完，全靠调这几个数），集中在一处改起来快，且绝不会误改正式数值。

### 6.4 数据隔离（教程期 vs 正式区）

| 数据 | 教程期 | 正式区 |
|---|---|---|
| 宠物 / 等级 / 成长 | 独立副本，结束时清空 | 从选宠重新开始 |
| 装备 / 材料 | 独立副本，结束时清空 | 只有新手礼包的内容 |
| 任务进度 | 新手链正常记录，完成即标记 | 新手链已完成，不再出现 |
| 市场挂单 | 教程期挂单随重置清空 | 正式开始 |
| 账号 / 登录 | **共享**（不重新注册） | 同账号 |

**简化建议**：如果"独立副本"实现成本高，**更省事的做法是教程期直接走正常存档**，最后统一清空（重置时把 pets / items / materials / quest_progress 全部清掉，只保留账号）。教程总共 30 分钟，不会有多少真实数据。

### 7.2 关键技术点（只提示方向，不写代码）

| 点 | 建议 |
|---|---|
| **遮罩高亮** | 用 `position: fixed` 全屏遮罩 + 目标元素"挖洞"。优先用 `box-shadow: 0 0 0 9999px rgba(...)` 撑出遮罩（比克隆元素更轻）；目标元素临时提 `z-index` 到遮罩之上 |
| **高亮定位** | 目标元素用 `getBoundingClientRect()` 取位置；页面滚动 / resize 时要重算（监听 + 节流） |
| **动效** | 只用 `transform` / `opacity`；禁止动 `width` / `height` / `top` / `left`（会掉帧）。遮罩切换 400-600ms `power2.inOut`，弹窗 300-400ms `power1.out` + 上移 12px |
| **教程状态持久化** | 存 `localStorage`（章节进度）+ 服务端（`tutorial_completed` 标记，防止换设备重来一遍） |
| **与挂机并存** | 教程弹窗不能阻塞战斗循环；玩家切页时挂机继续（现有页面是常驻 DOM，天然支持） |
| **跳过处理** | 跳过 = 直接把整条新手链标记完成 + 发礼包 + 进入正式流程（复用现有 `Quest.skipGuide()`） |
| **旧存档兼容** | 老玩家（已有宠物的账号）**不应被强制进教程**。判定：有宠物 = 老玩家，直接进正式流程，只给一次性礼包补偿 |

### 7.3 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| **30 分钟跑不完**（玩家读得慢 / 挂机没并行） | 教程体验断裂 | ① 每章可跳过；② 挂机与操作并行（已在第 4 章设计）；③ 真机计时后回调 `expRate`（6.0 不够就加到 8~10） |
| **玩家看不懂就乱点** | 教程白做 | 高亮区可点击即推进（点击 = 真实操作），不做"下一步"纯翻页 |
| **教学补给让玩家误以为资源来得容易** | 出了教程落差大 | 每步弹窗必写"这东西正常从哪来"（已在 2.5 设计） |
| **门槛放宽造成认知偏差** | 玩家以为合成是 Lv20 | 合成 / 涅槃步骤弹窗标注"教学加速：真实门槛 Lv40 / Lv60" |
| **新手礼包冲击市场** | 经济失衡 | 礼包**全部绑定不可交易**（需用户确认）；数量克制，不跳过任何系统门槛 |
| **玩家被强制教程 / 跳过后发现没礼包** | 流失、被坑感 | ① 进游戏前先问（2.7），玩家自己选；② 「跳过」按钮副标题直接写明 `跳过没有新手礼包`；③ 老存档不特殊判定，统一问一句 |
| **中途退出教程白嫖礼包** | 礼包泛滥 | 中途退出 = 未完成，不发礼包；设置里可重开，做完再给 |
| **经验包与既有决策冲突** | 设计反复 | 项目此前反对"可交易经验包"；本次礼包为**绑定版**，与其不冲突——仍需用户最终确认 |
| **教程期数据没清干净** | 玩家带着作弊进度进正式游戏 | 重置清单（2.6）逐项核对；加一条测试：教程完成后 material/pet/item 全为空 |
