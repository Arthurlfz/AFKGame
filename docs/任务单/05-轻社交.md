## 六、结果

**已做（数据库）**：单子里没给表结构，我按"最小能跑"设计并建了两张表（都带 `if not exists`，可重跑）：
- `follows`（follower_id / seller_id / created_at，unique(follower_id,seller_id)）—— 关注**是单向的、不需要对方同意**，
  所以没复用 07 的 `friendships`（那个是双向+待同意，语义不同）。
  RLS：只能看/增/删**自己**的关注。
- `board_messages`（seller_id / author_id / body / created_at）+ `board_messages_seller_idx (seller_id,created_at desc)`
  —— 卖家留言板。RLS：**登录即可读**（公开），只能以自己身份发；作者或卖家本人可删。
已回查 `information_schema` 确认两张表都在。
