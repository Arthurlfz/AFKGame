## 三、要出图的话怎么出

- 尺寸建议：**正方形 PNG**，按用途 **48×48**（行内小图标：奖牌/反馈/关闭）～ **64×64**（在线/滑杆/箭头）都够；
  与现有 `ic_*.png` **同一套水墨风格**（对照 `ic_mat_remnant.png` 之类似观感）。
- 出图通道：见 `绘图skill`（中转站画布 + `tools/canvas-cli.js`）；**一次 `count:1` 一张**、**抠底用 colorkey**（有描边的图标）。
- 合计缺口：**约 11~12 张**（奖牌 3 + 反馈 3 + 关闭 1 + 箭头 2 + 在线/滑杆 2 + toast 可选项）。
- ⭐ 出完落 `docs/assets/ui/`，改引用时**逐个升 `?v=`**（改 JS/CSS/HTML 都要），并跑 `cd docs && npm run check`。
