## 二、玩法系统完整清单（按代码模块）

### ① 战斗系统（`core/battle.js` + `core/idle-bridge.js` + `config.battle`）✅

| 系统 | 源码事实 |
|---|---|
| 挂机战斗 | 一场接一场自动打，行动条自动回合制（速度决定行动条填充，先满先动） |
| 伤害公式 | 攻击−防御（最低 1）；暴击率 10%、暴击伤害 1.5 倍 |

| 怪物等级 | `clamp(宠物等级, 图等级段下限, 上限)` —— 图定范围、宠物定值 |
| 血统被动跨场状态 | 骨狼"嗜血追击"击杀 buff 跨场传递、毒沼蛙"腐蚀毒液"层数 |

| 系统 | 源码事实 |

| 稀有度 | = 词缀条数唯一决定（白 1 / 蓝 2 / 金 3+，`syncRarity` 统一四者口径） |
| 词缀池 | 15 种：前缀 4（攻击/生命/防御/吸血）+ 后缀 11（速度/暴击率/暴伤/命中/闪避/穿透/伤害加成/受伤减免/掉落数量/掉落稀有度/材料掉率）；POE 式权重（基础词缀 100、资源词缀 10~15） |
| 词缀结构 | 前缀 ≤3 + 后缀 ≤3（共 ≤6），历史扁平数组自动归一化（向后兼容） |
| 词缀数值 | 每属性独立 T1~T5 表（攻击/生命/防御走通用表；速度/吸血/暴击/暴伤/穿透/增伤/减免走专属表） |
| 打造 | 重铸石（全重roll）/ 剥离石（删1条，剩1条不可用）/ 神圣石（重roll数值）/ 增缀石（+1条，满3条不可用）；每次耗 1 石，云端原子扣减，在售禁打造 |
| 锁定系统 | 锁定石：锁定前缀/后缀（二选一），重铸时锁定侧整组保留、另一侧重roll，**每条锁定词缀额外耗 1 锁定石**；重铸生效后锁定自动失效 |
| 分解 | 锁定/在售不可分解；一键分解：**白装无产出 / 蓝装→增缀石 / 金装→重铸石**（`config.salvage`） |
| 鉴定 | 未鉴定装备（`eq.identified===false`，封印卷轴图标）→ 消耗 1 鉴定石揭晓（手持鉴定模式可连点） |
| 云端存档 | `equip_items` 表；词缀 JSON 内嵌 `_ilvl/_lockPrefix/_lockSuffix` 持久化；`items.js` 负责写入/读取/批量删除 |
