## 任务奖励规则（写在 `Config.drop.quests` 上方注释，测试守）

1. 循环任务（`repeat`/`repeatable`）只发打造通货 + 经验 + 门票 → 禁止进化和涅槃材料。
2. 传说进化素材只出现在 `unlockLevel` 31~48（= 图 6~8）的任务里；图 9~10（`≥49`）一律改发该阶段打造通货。
3. 单条任务给传说 ≤ 2（一只宠终阶总共只要 2，2026-09-11 取消终阶额外×3 后；任务只补当前缺口）。

### 装备生成规则重做（2026-09-11 用户拍板，按 PoE 词缀模式，资源矩阵的装备口径随之变更）

一切由**装备等级(ilvl)**决定，颜色只是结果 —— 旧的两张按图 roll 的权重表（`materialTierWeights` / `rarityWeightsByTier`）已作废不再被读取：

| ilvl | 词缀条数（含基础 1 条） | 颜色 | 词缀 T 阶池（按权重抽） | 底材 T 阶池 |
|---|---|---|---|---|
| ≥70 | 4~5 | 金 | T1 5% / T2 15% / T3 30% / T4 25% / T5 25% | 同左 |
| 60~69 | 3~4 | 金 | T2 15% / T3 30% / T4 25% / T5 25%（**T1 不入池**） | 同左 |
| 25~59 | 2~3 | 蓝~金 | T3 30% / T4 25% / T5 25% + T4/T5 加权 | 同左 |
| 1~24 | 1~2 | 白/蓝 | T4 / T5 | 同左 |

- **PoE 模式**：每个 tier 有自己的门槛（`affixIlvlGates`：T1=70/T2=60/T3=25/T4=1/T5=1）+ 自己的权重
  （`affixTierWeights`：5/15/30/25/25）；掉落时「门槛 ≤ ilvl」的 tier 全部进池按权重抽 —— **T1 可以出现但稀有**。
- ilvl = 掉落它的怪等级：野图最高图 10（怪 55）→ 最高 T3；**通天塔怪 Lv60→120，10 层后 T1 入池** —— 塔产出全面压过野图。
- 每条词缀独立 roll（同一件金装可以 T1/T3 混排）；数值随机保留（每条 min~max）；底材 T 与词缀 T 同池同机制。
- 重铸/增缀沿用装备出生 ilvl —— 低图装备洗不出高档词缀。
- 「掉落稀有度」词缀的加成落点 = **多 1 条词缀**（颜色自然升档）。
- 守护测试：`vtest_tier_rarity.js` 按 PoE 模式重写（门槛池 / T1 ≈5% / 条数→颜色 / 底材同池 / 统一入口）。
4. **（2026-09-10 补）任务只发现阶段有消耗口的资源** —— 已退役/无消耗口的道具不得进奖励表（涅磐兽即因此出局，见下）。
5. **（2026-09-10 补）收集类日常的解锁等级 = 该材料所在图的等级下限**：原先 12 条日常都没有 `unlockLevel`，Lv1 就会看到「腐变之心 ×20」（图 10 材料），列表里躺着永远做不完的条目。现已按图对齐（`d3`→1 / `d4`→7 / `d5`→13 / `d6`→19 / `d7`→25 / `d8`→55）。

### 兑换任务规则（2026-09-10 新增一级分类 `exchange`，`vtest_quest.js` 守）

背景：用户报「很多东西不好拿到了」。参考口袋精灵2 的【物资兑换】（提交富余物 → 换需要的东西）落地本作。
它同时解掉了 **通天塔重置卡断链**（商店关闭后唯一非付费来源）。

三条自制规矩（比铁律 1 更严，改之前先读）：

1. **必须有硬上限**：`kind:'exchange'` + `reset:'daily'|'weekly'`，**绝不允许 `repeatable`**（测试直接断言）。
2. **每日只换低/中价值物**（鉴定石 / 强化丹A / 门票 / 凝魂晶石 / 涅槃丹 / **传说进化素材**）；
   **受控高价值物一律每周 1 次**（强化丹B / 天仙玉露 / 锁定石 / 越龙之石 / 重置卡 / 至尊神石），
   产出量压到远低于正常来源 —— 免得把「打淬炼 / 打塔 / 打守关 Boss」架空。
   **唯一例外**：`ex_day_legend`「传说补遗」每日 ×2（2026-09-10 用户点名传说是大头）。
   敢放每日的理由：传说已经有**四条**来源（图 6~8 / 图 9~10 低权重 / 试炼·蜕变 / 一次性任务），
   兑换只是第五条保底，2 个/天 远低于挂机 4.3~13.3 个/小时，不可能变成最优解。
3. **不能拿稀缺物换稀缺物**：消耗物必须是真富余的（基础打造通货、腐印、百变魔石）。

> ⚠️ 这是对原「唯一主来源」原则的**有意放开**，放开的前提就是上面三条。
> 任何一条被破坏（把某条改成 `repeatable`、或把每周的挪到每日），
> 那条资源立刻变成新的最优解，地图与副本的循环会被打断。
>
> 换出的 **通天塔重置卡 / 凝魂晶石** 刻意不在 `Config.trade.materials` 里 → 天然账号绑定，不给 RMT 开门。
>
> ⚠️ **批判者回合补的一条红线（2026-09-10）**：兑换消耗的必须是**真富余物**（基础打造通货），且比值不许亏到 10 倍以上 ——
> 「卵石相易」就是亏 17 倍才删掉的。另：**兑换会和交易行抢生意**（官方固定价 vs 市场发现价），
> 所以它的定位只能是"最后兜底"，凡是能直接挂机刷到的资源，比值必须明显差于挂机（涅槃丹 / 传说现在亏 3~6 倍），
> 刷不到的（神圣石 / 锁定石 / 重置卡 / 强化丹B / 天仙玉露）才允许接近持平。
