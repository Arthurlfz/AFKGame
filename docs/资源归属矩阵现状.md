## 任务奖励规则（写在 `Config.drop.quests` 上方注释，测试守）

1. 循环任务（`repeat`/`repeatable`）只发打造通货 + 经验 + 门票 → 禁止进化和涅槃材料。
2. 传说进化素材只出现在 `unlockLevel` 31~48（= 图 6~8）的任务里；图 9~10（`≥49`）一律改发该阶段打造通货。
3. 单条任务给传说 ≤ 2（一只宠终阶总共只要 5；任务只补当前缺口）。
