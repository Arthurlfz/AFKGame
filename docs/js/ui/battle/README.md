# js/ui/battle/ —— 战斗页（一个文件一件事）

战斗页同一时刻**只有一个驱动者**（野图挂机 / 托管演出 / 副本 / 塔），占用权在 `js/core/battle-session.js`。

| 文件 | 这一件事 |
|---|---|
| `index.js` | 战斗页主入口：血条 / 行动条 / 战斗结算 / 出战快照 / 状态徽章 / 战斗按钮 / 技能按钮 |
| `act.js` | 出手与命中演出：节奏表 `PACE` / 冲刺距离 / 受击形变 / 飘字 / 命中特效触发 |
| `loot.js` | 掉落播报 + 掉落演出（自己往 `UI` 挂 `showLoot` / `lootTierOf`） |
| `tip.js` | 敌方悬浮提示（悬停立绘弹出数值浮层，`window.BattleTip`） |
| `roster.js` | 出战宠物竖列（头像 + 悬停详情 + 进化/合成/装备快捷入口） |
| `summary.js` | 挂机结算汇总弹窗（切回前台时摊开这段时间的收益） |
| `stage-fx.js` | 舞台原语：横幅 / 舞台闪光 / 屏幕脉冲（掉落、Boss、升级共用） |

## 改这里的规矩（详见 `AGENTS.md` 第九节）

- **新功能新文件**；这些文件只准改**它自己那件事**。
- 对外 API 一律**自己挂到 `UI`** 上（`UI.xxx = ...`），调用方（`battle.js` / `idle-bridge.js` / `main.js`）零改动。
- 跨模块只走**公开 API**，不要伸手去拿别的模块的内部函数。
- 引用别的模块一律**用时取**：`const X = () => window.X`，别在加载时存成 `const`（测试清单顺序不保证）。
- 迁代码时**血泪注释一起搬**——注释比代码更不能丢。

## 不在这里的东西

- **素材特效的播放器**（命中墨爆等）在 `js/fx/`，样式在 `css/fx.css`；本目录只管"什么时机播"。
- **战斗逻辑与数值**在 `js/core/battle.js` / `js/core/config.js` / `js/core/battle-sim.global.js`——展示层不动它们。
