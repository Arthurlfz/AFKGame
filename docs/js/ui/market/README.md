# `js/ui/market/` —— 市集一族（说明书）

> 改这一页之前先读这 30 行。**别在这一族里找"顺手的地方"塞新东西。**

## 页面长什么样

```
┌──────────────┬───────────────────────────┬────────────────┐
│ 筛选 facets   │ 结果 cards                 │ 详情 detail     │
│ 级联单选      │ 列表 / 网格 两种版式        │ 选中项的详情     │
│ 搜索 / 价格   │ 分区 + 分页 + 关注星标       │ 同类低价         │
│              │ 批量勾选 → 结账批量 batch    │ 购买 / 取回      │
└──────────────┴───────────────────────────┴────────────────┘
       下方横跨整行：交易信息（材料 / 税收 / 交易记录 records）
```

「我的上架」是**同一页的另一个视图**（`sell.js` 注入结果区），不是第二个页面。

## 一文件一职责

| 文件 | 它负责的那一件事 |
|---|---|
| `index.js` | **编排层**：三栏接线、视图切换（全部在售／我的上架）、工具条、下单分发。**细节不许写在这里。** |
| `facets.js` | 左侧级联筛选栏：状态 + 渲染 + 命中判定 + 排序 |
| `cards.js` | 结果区渲染：四类商品的展示模型 → 列表行 / 网格卡、分区、分页、卖家名牌 |
| `detail.js` | 右侧常驻详情栏：选中项详情 + 同类低价 + 购买入口 |
| `watch.js` | 关注/收藏（四类）+ **降价高亮** |
| `batch.js` | 多件一起买：勾选、按材料分组合计、最便宜先行逐笔结账 |
| `pricing.js` | **口径与比价**（无 DOM）：挂单识别、搜索文本、参考价中位数、捡漏标签、挂单时长 |
| `sell.js` | 上架工作台 + 上架定价弹窗（含查价与税后到手） |
| `records.js` | 交易记录面板（卖出 / 买入 / 汇总） |
| `notify.js` | 离线成交汇总通知 |
| `pulse.js` | 市集顶部"活人感"条（在线人数 + 最近成交轮播） |

**样式**：`css/market-cascade.css`（本页版式：三栏 / 列表 / 详情 / 结账条）、
`css/market-refresh.css`（卡片等既有细部）、`css/design-tokens.css`（颜色字体唯一源）。
⛔ 不给 `.tab-page` 写 `display`（项目红线：ID 选择器会碾压 `.tab-page{display:none}`）。

## 🔴 加载顺序（`游戏.html` 里这一族必须按序）

```
pricing → watch → facets → cards → detail → batch → index
```

`pricing.js` 提供口径与比价，其余几个在**加载时**就从 `window.MarketCalc` 取引用；
`index.js` 是编排层，必须最后（它调用前面所有模块）。
**往这一族加文件 = 同时改三处**：`游戏.html` 的加载标签（含 `?v=`）、
`tests/vtest_files.js` 走的自动清单（解析 `游戏.html`，自动生效）、
以及 `vtest_cascade_market.js` / `vtest_market_enhance.js` / `vtest_market_ui_v2.js` 里的 `MARKET_MODULES` 常量。

## 本目录的改法规矩

1. **新功能 = 新文件**。想加"求购""拍卖行"这类，开新文件 + 在 `index.js` 里接一行，别塞进 `cards.js`。
2. **逻辑按本游戏真实逻辑**，别照抄别人的交易行：
   - 标价是**收款材料数量**（不是魔石）；魔石是充值货币，只在魔石商店用。
   - 税 = 每满 `Config.trade.taxPer` 收 `Config.trade.taxAmount`，**卖家承担**，买家按标价付。
   - 只有**宠物/装备**走确认弹窗再成交；**蛋/材料**沿用老手感"点了就成交"。
   - 没有收款物字段的**旧版挂单不可购买**（`legacy`）。
3. **跨材料不可比**：`10 重铸石 ≠ 10 神圣石`。比价、参考价、降价判定都必须**同收款材料**才算。
4. **卖家昵称不在挂单里**（只有 `seller_id`）：本地绝不"造"名字，名牌由 `cards.js` 的
   `paintSellerTags()` 渲染后异步补，失败就只显示原名。
5. **不可逆操作要如实报告**：批量结账中途失败**必须停下并说明"已买到 N 件、第 N+1 件为什么失败"**，
   已成交的不退。⛔ 不许吞掉失败假装成功。
6. **下单只有一个入口**：`MarketPage.onBuyClick(listing, btn)` / `buyListing(listing)`。
   卡片、右栏、批量三处都必须走它，否则迟早出现"某个入口漏了某个分支"。
7. 改完跑：`cd docs && npm run check`。市集相关的守值是
   `vtest_cascade_market.js`（级联筛选 + 视图合并）、`vtest_market_enhance.js`（交易行补强）、
   `vtest_market_ui_v2.js`（三栏 / 版式 / 关注降价 / 批量结账 / **反闪烁**）。

8. 🔴 **这一页会被每秒调一次，别让"重画"变成默认行为**（2026-09-23 实测踩过）：
   `main.js:810` 的回血时钟每 1 秒 `renderAll()` → `UI.renderMarket()`。
   所以：
   - **`index.js` 有整页签名守门**（`visibleSignature`）：数据没变就一个节点都不重建。
     ⛔ 往这一页加"会变的状态"时**必须同步加进签名**，否则界面停在旧样子。
     ⛔ **玩家自己的东西（背包材料 / 宠物等级）不许进签名** —— 挂机时它们一直在变，
       一进签名就变成"每秒重画整页"。
   - **`facets.js` 有左栏签名守门**：级联入场动画只在**结构**变了时才播；
     只换一个选项值不该重播动画（否则整栏看起来一直在闪）。
   - **实时数字走单独的口子**：右栏"我持有多少材料"用 `MarketDetail.refreshNumbers()`
     就地改文本，不重建 DOM。以后要加别的"玩家身上的数字"也走这条路。
   - **「我的上架」视图不跳过**（上架工作台看的是玩家自己的实时数据，且它没有入场动画）。
