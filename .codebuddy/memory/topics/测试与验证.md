## 数值类改动怎么验（数值体检的配方）
⭐ **免 UI 的塔难度模拟**：`docs/tests/sim_tower_balance.js`（官方校准器，**保留、别改**）——
真造金装 + `TowerEngine.mobEnemyStats(f,m,null)` 造怪（与线上引擎同源）+ `battle-sim.mjs` 逐层模拟。
⚠️ **塔怪数值注入方式（最容易卡住的一步）**：`battle-sim.simulateFight` **不读 `enemyData` 的血攻防**，
它是从 `Config.battle.areaEnemyStats[area.id]` × `levelRange` 中点缩放算出来的 → 必须**逐场**写
`areaEnemyStats['<tmp_id>'] = {hp,atk,def}` 并传 `area = {id:'<tmp_id>', levelRange:[en.level,en.level], difficulty:1, enemyMult:1}`（此时 ratio 恒为 1 = 直通）。
⭐ **最干净的隔离手法**：`simulateFight` 直接用传入的 `stats` → 直接 `stats = {...petStats(pet,cfg), lifesteal: 0}` 就能把某项归零，
其余一字不动（不必去改装备对象）。只有 `simulateSession`（野图）内部自己算 stats、不接受注入 → 那里才需要「从装备套里抹掉某项」
（要**同时清 `baseStats` / `affixes.prefix+suffix` / `soulAffix` 三处**，漏一处等于没摘）。
- 种子：每个 `(run, 层, 第几只)` 用固定 `lcg(...)` → 各组消耗同一串随机数，差异只来自被改的那个变量。
- 每档 24~30 局取中位 / 平均；两组比较用 `z = |Δmean| / √(se_a²+se_b²)`，**z≥1.96 才算数**（否则别写进结论）。
- ⚠️ 踩过的坑：想对照「吸血 0% vs 28%」，却给两组都传了同一套带 10.8% 吸血的装备 → 实际测的是 10.8% vs 28%。
  ⇒ **做对照前先打印两组的 stats 核对**。
