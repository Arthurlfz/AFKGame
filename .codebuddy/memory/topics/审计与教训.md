# 审计沉淀 / 可复用教训

> 入口：`MEMORY.md`｜**审计、动资产、写不可逆逻辑、写迁移之前先读本文件。**
> 本文件按需读取，不占每轮注入预算 —— 有新教训直接往下加。

## ⭐ 两个系统性病因（本项目头号病因）
1. **「注释说 A、代码做 B」** → 拿注释 / 文档当**意图源**反查代码，是性价比最高的审计手法。
2. **「同一逻辑复制两三遍、只有一份对」** → 发现第二份就合并，别想着"保持同步"。

## ⭐ 发布：本地好好的 ≠ 线上没问题
- **引用只在 HTML 里查是不够的**：`app.css` 的 `url()` 同样是「页面引用的资源」
  （2026-09-17 抓到第二例：登录背景图在磁盘、从没入库 → 线上 404；第一例是 `ui-onboarding.css`）。
  ⚠️ CSS 里相对路径的基准是 **CSS 文件自己所在目录**（`../assets/x.jpg` 相对 `docs/css/`），不是 `docs/`。
  现在由 `docs/tests/vtest_assets_tracked.js` 一起守（游戏.html + 14 个 css，353 个引用）。
- **`.gitignore` 里指向某个文件的规则，一旦该文件入库或被搬走，规则必须跟着删** ——
  留着的旧条目只会静默坑人（同一剧本会重演；09-17 顺手删掉了 `docs/AI假人经济系统策划_v1.md` 那条）。

## RLS / 权限
- ⭐ **RLS 只控行归属、不控列 / 值**。已收 `materials` / `profiles`，**未收** `pets` / `equip_items` / `pet_egg`
  —— 施工图见宪法 §三 #8 与 `docs/待办/资产表收口调研_2026-09-13.md`，**别重摸**（现在 revoke 会挂掉打造 / 进化 / 涅槃 / 穿戴 / 掉蛋）。
- ⭐ **PostgREST 只认【表级】权限** → 保护某列**绝不能**靠"收表级写权限"，必须用独立表 / 触发器 / RLS with-check。
- ⭐ 判定事实搬服务端后，**本地那份副本就成了"显示状态"**，必须有回灌通道，否则玩家「看得见点不动」。

## ⭐ 资产安全：顺序就是一切
- **不可逆操作排最后**（nirvana 血泪）：快照（traits **深拷贝**）→ 更新主宠（可逆）→ 成功才删副宠。
- **先付费后给货**：扣费排在「确认能发货」**之后**；容易退的先扣；扣不动 → 整单放弃 + 退回已扣，
  **绝不「只 log 继续」**；记账成功但发货失败 → 必须有**玩家可见提示**。
- 🔴 **确认云端建档成功之前，不许删素材宠 / 扣素材**；删素材宠必须**先删云端成功，再删本地**。
- ⭐ `Materials.gain` 只入队（4 秒后上报）→ 发奖 / 退款后要自己 `flushMaterials()`。

## 测试四戒
输入按被测函数**真实收到的结构**造；新护栏**必做变异测试**验证它会红；极端状态同节复原；用**绝对值**断言。

## 迁移脚本
- 🔴 **迁移脚本不许重放**：同一函数被多个 `migrate_*.sql` 重复 `create or replace` 过，**谁后跑谁生效**
  —— 所以"迁移幂等、可重复跑"这句话是**假的**（已从事实源表格里划掉）。
- **安全守卫类函数的唯一定义在 `supabase/migrate_security_reapply.sql`**（幂等）。改函数请**新建文件**，
  别回头改已执行过的文件；确实要重放旧文件，跑完必须再跑一次 `migrate_security_reapply.sql`。
