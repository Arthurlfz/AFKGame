## 进化 / 涅槃
- `evolve_times = evolveStage − 1`；进化上限**只认 `nextStageOf` 返回 null**；进化**不改等级**；终阶只收传说 ×1。
- 涅槃清 `evolveTimes` / `cultivateUsed`、等级回 1、**保留形态**。

## 技能
- 技能 = **16 个主动自动技**（期望提升 +13~18%）；变异宠剥「·异变」继承本体技能，涅槃不退档。

## 稀有度 / 打造 / 掉落
- 稀有度 = 词缀条数（1 白 / 2 蓝 / 3+ 金）；锁定石**只保一次打造**；掉落**单池一场一抽**。
- ⭐ **`speedScale=18` 是战斗节奏总闸**（一次出手 ≈ 10×18/速度 秒）—— 想调快慢只动它。
- ⭐ `generateEquipment(rarity, areaTier, materialTier, ilvl)` 自 2026-09-11 起**只认 `ilvl`**：
  `rarity` / `materialTier` 参数**已被忽略**（旧调用方的签名还在，别以为传了就生效）。
  词缀条数、词缀 T 阶、底材 T 阶、颜色**全部由 `ilvl` 决定**。

## ⭐ 装备战力与吸血（2026-09-14 实测，报告见 `docs/数值体检_吸血与装备属性_2026-09-14.md`、宪法 §二·H）
- 实测 12 件满级金装总收益 **+6.84 层**（通天塔），其中 **吸血独占 51%**（3.46 层）、速度 18%（1.25 层）、
  暴击 11% / 暴伤 10% / 闪避 10% / 减伤 5%；而**攻击 / 生命 / 防御 / 命中 = 0 层**（满装比裸装只多 267 攻 / 545 血 / 127 防）。
- 吸血还**白送**：**护符「基底」100% 出吸血**（不是词缀），中位贡献 13.0%，占整套吸血量 **63.4%**；
  12 件合计中位 18.8%，词缀只占 7.0%；达 28% 的套约 4%（p99 32.5% / 上限 32.9%）。
  根因：护符基底写死 4 点，却跟着**图档 ×3.25 × 底材档(0.6~1.5)** 一起被放大 → 7.8%~19.5%（吸血是百分比属性，被乘一次就是双重成长）。
- ⭐⭐ **最根本的一条：吸血的价值由「塔整局不给回血」这个规则放大，不是吸血数值本身超模。**
  同一套装备 —— 塔里占装备收益 **51%**；**野图挂机 1 小时只差 1~3 场（0.1%）**（野图每秒免费回 20% 血，吸血被淹没）。
- 吸血还是**滚雪球**（`heal = 伤害 × 吸血率`）：攻击 ×1.5 时吸血值 6.50 层，攻击 ×0.6 时只值 5.00 层（**+30%**）。
- 曲线是**阶梯**：0%→3% 一步就 +1.6 层（全程最陡）；0→6% 已吃掉「0→50% 总收益」的 34%。
  **换算**：10.8% 吸血 ≈ 攻/血/防全 ×1.6；**28% 吸血 ≈ ×2.5**。
- ⚠️ 装备战力**大头是机制属性**，校准一律 `Equipment.generateEquipment` **真造取中位、禁用代理点数**（中位真值见 `fos-balance`）。
- ⚠️ **待核实**：塔的难度校准是 2026-09-10 做的，而装备生成在 **2026-09-11 重做过**（见上「只认 ilvl」）。
  本次测出 12 金装中位吸血 **18.8%** vs 校准记录 **16.8%** ⇒ **动数值前先重跑一次塔校准**（`docs/tests/sim_tower_balance.js`）。

## ⭐⭐ 塔只考「吸血」是**结构必然**，不是配平失误（2026-09-14 体检第二期实测）

- 塔是「长期累计掉血」的考试 → 能对抗它的只有**按伤害比例持续回复**（吸血）。
  减伤 / 闪避是「按次减免」（有上限），血池是「固定基数」，速度是「出手频率」→ **全是固定削减**；
  而塔怪强度是**每层 ×1.124 的指数** → 指数面前，固定削减必然被淹没。
- 实测（基准 = 满装摘吸血 6.42 层；目标 = 满装含吸血 9.88 层，即 +3.46 层）：

  | 投入 | 换来层数 | 等效吸血% |
  |---|---|---|
  | 受伤减免 +30 点 | +0.67 | 1.3% |
  | 闪避 +150 | +1.00 | 1.9% |
  | 血池 ×3.0 | +2.33 | 5.3% |
  | 速度 ×1.8 | +0.54 | 1.0% |
  | **吸血 +10%** | **+3.33** | 10% |

  ⇒ **没有任何属性追得上吸血**（差一个数量级，且它们各自都有天花板：dr 上限 90、命中率下限 5%）。
- **层间回血也救不了**（what-if 实测）：塔每层回 30% 血，吸血仍值 **+2.04 层**（从 3.46 只降 41%）——
  因为吸血是**战斗中持续回**，层间回血是**每层补一次**（一层 5 只怪，怪打你几十刀）。
- ⇒ **想让塔不只考一道题，要动的是「怪强度怎么涨」或「输出能不能换成续航」，不是调属性数值。**
  ⚠️ 且用户 2026-09-14 已拍板「塔不给回血是刻意设计」→ 问题①接受为设计。

## ⚠️ 装备「加法位置」的爆炸风险 = 我误判了（2026-09-14 纠正）
- 曾担心「让装备 % 也乘成长值 → 高成长宠爆炸」→ **实测不会**：装备给的是**固定百分比**（这套 +41% 攻），
  相对收益**恒等于该百分比**（成长 30 → ×1.38，成长 350 → ×1.41，成长 800 → ×1.41，几乎不变）。
- **真代价在别处**：会让**现有玩家战力当场 +42%**（攻 14712 → 20566）→ 塔难度全废、掉落与经济全受影响。
  **这是「全民变强 40%」，不是微调。**改动前必须按这个量级评估老装备变值的影响。
- 🔴 **2026-09-14 追认：用户早在 2026-09-01 就为这件事装过刹车，我上面那条"实测不爆炸"只说明「当前量级不炸」，
  不能证明「这个方向不失控」。** 完整记录见宪法 §二·H-6，**"让 % 乘成长值"已撤回、不得再提**。
  用户当年担心的正是「**装备的百分比 × 宠物成长值**」——现状是两条**互不相干的加法线**，
  一旦让 % 乘成长值就变成「**成长 × 装备**」的**乘法耦合**，而成长线无上限（神级涅槃）→
  **再往后每加一个新系统都是一个新乘区 = 乘区相乘 = 数值失控的标准剧本。**
  ⚠️ 别拿"有硬顶"当解法：装备 `攻击%` 硬顶 = 12 部位 ×（同类型词缀每部位只出 1 条）× T1 8% = **+96%**，
  单看有界（有效战力 ×1.96 封顶），**但那是通道里的闸，不是把通道关掉。**

## 🔴🔴 命中 / 闪避的根本结构问题（2026-09-14 用户点破「等级不会影响命中和闪避？」→ **核实成立**）

**用户猜对了：宠物等级、怪物等级，都不影响命中 / 闪避。**

| 谁 | 命中从哪来 | 闪避从哪来 | 随等级/层数变吗 |
|---|---|---|---|
| **宠物** | `config.pet.petProfiles[lineId].hit`（固定 90~95）+ 装备 `flat.hit` + 血统被动 | 同上，固定 `dodge`（2~8）+ 装备 + 血统 | ❌ **不变**（`battle-sim.mjs:274-275,301-302`；`getStatCoeff` 只给 hp/atk/def） |
| **塔怪** | `tower-engine.js` 写死 **`hit: guardianHit = 160`**（**杂兵和守卫都是 160，30 层全是这个数**） | 字段没有 → 走默认：**normal 5 / evolved 8** | ❌ **不变**（而血/攻/防每层 ×1.124 **指数涨**） |

（神级宠也一样：命中/闪避取「根源基宠」的固定档，见 `statNameOf`。）

### ⭐⭐ 所以「命中没用」的真正原因不是"怪的闪避太低"，而是：
> **命中 / 闪避的对手是一个【不变的常量】，而游戏里其他所有东西（怪血/攻/防、宠物成长值）都在指数涨。**
> ⇒ **这两个属性天生是「一次性达标」属性：堆够就永远够，再堆一格都是浪费。**

- 这解释了为什么 **命中拉满 12 件仍 +0.0 层**（对固定闪避 5 的怪，命中 90 已顶 95% 上限）。
- 也解释了为什么 **闪避（拉满 +1.4 层）比命中强**：塔怪命中固定 160 这个数**不算小**，
  玩家闪避 13 → 182 时命中率 **87% → 47%**，区间够大；而命中这边对手只有 5，还有 95% clamp 封顶。
- ⚠️ **野图怪同理**：`dodge` 默认 normal 5 / evolved 8 / mutant 12、`hit` 默认 90 —— **也不随等级涨**。
  ⇒ **整个游戏里，命中/闪避都没有"会成长的对手"**，所以它们在后期必然变废。这是结构问题，不是数值问题。

### 修法（主 agent 推荐"只给几层加"，而非全面改）
| 方案 | 做法 | 代价 |
|---|---|---|
| **A（推荐，最便宜）** | **只给塔后半段某几层放高闪避怪**（如闪避 100+）→ 命中变成"打这几层的钥匙" | **几乎不动塔的整体难度**（只有几层变）；评审 agent 也独立提了这条 |
| **B** | 让塔怪的命中/闪避**随层数一起涨** → 命中/闪避变成"要一直追"的属性 | ⚠️ **塔整体难度会上移**（玩家命中要一直追、闪避装同时失效）→ **必须重跑难度校准**；且玩家命中来源只有装备（上限约 90 + 12×8 + 12×22 ≈ 458），要么够要么不够 |
| **C** | 改机制：命中 → 门槛式破防；闪避 → 百分比减伤 | 最贵：改战斗公式 + **前后端两份战核同步** + 全部数值重定标 |

## ⭐ 命中 / 闪避「反直觉」的根因（2026-09-14 用户提出）**不是数字小，是它无法自证价值**

用户原话：「命中和闪避有些反直觉，其他都是上千万的」。
**根因不是量级，是「价值依赖对手」**：
- 速度也是两位数（80），用户不觉得反直觉——因为速度能**自己算**（一次出手 = `100×speedScale/速度` 秒），不依赖对手。
- **命中 90 对闪避 5 的怪 = 95%，对闪避 200 的怪 = 31%。同一个 90，两种命运** → 玩家看面板**根本判断不出好坏**。
- 同理闪避：能挡多少，取决于**怪的命中**（塔守卫固定 160）。
- ⇒ **攻/血/防/暴击/吸血 这些不依赖对手，所以能一眼看懂；命中/闪避依赖对手，所以"反直觉"。**

⭐ **这同时解释了"命中拉满只值 +0.0 层"**：因为现在**所有怪的闪避都只有 5~12**（塔守卫命中 160 也是固定值）
⇒ **命中这个属性根本没有对手** ⇒ 它再好也是废的。**所以要救命中，必须给部分怪加高闪避（配置改动），而不是调命中数值。**

### 两条解法（主 agent 推荐 A）
- **A（推荐，便宜）**：**面板直接显示实际效果** ——「命中 128 → 对同级怪命中率 96%」「闪避 58 → 躲掉 27%」。
  **不动公式、不动任何数值**，只改 UI 呈现。零风险解决"看不懂"。
- **B（彻底，贵）**：把命中/闪避改成**百分比**（「命中 +30%」「闪避 +15%」），和暴击/吸血/减伤统一量纲。
  **代价**：改战斗公式 + 重定标全部命中/闪避数值（底材/词缀/8 宠 profile/塔守卫 160）+ 前后端两份战核同步（`vtest_sim_sync` 守）+ 重跑全部平衡。
  ⇒ **额外收益不足以付这个代价**（量纲问题主要是"看不懂"，不是"算错"）。

⚠️ 注意：**无论选哪条，"给部分怪加闪避"都得做** —— 否则命中永远是假属性。

## ⭐ 「词缀校准要不要改公式」的定论（2026-09-14）：**公式一条都不用改，只有穿透那一行**

| 公式 | 改不改 | 原因 |
|---|---|---|
| 属性合成 `底座×(1+%)+成长+固定值` | ❌ **不改** | 它确实是「攻击+8% 只加 13 点」的根源，**但改它 = 拆用户 2026-09-01 的决定**（防四轴连乘指数爆炸）。**词缀校准可以绕开它**（把攻/血/防词缀删掉或改固定值） |
| 伤害 `攻击²/(攻击+防御)` | ❌ **不改** | 形态本身是对的（递减对抗、永远挡不完） |
| **穿透算法** | ✅ **改一处** | `有效防御 = 防御 − 穿透点数` → `防御 × (1 − 穿透%)`。**点数制在这条公式下天生失效**（削防御的相对收益 ∝ `1/(攻击+防御)`，而攻击+防御随层数暴涨）。按公式手算：20% 破甲在第 10 层约 +4% 伤害、**第 20 层约 +11.5%**（越深越强，符合"克制高防怪"定位）。⚠️ 手算非模拟，要落地前用模拟复核 |
| 命中 `命中/(命中+闪避)` + clamp 5~95% | ❌ **不改** | **问题不在公式，在怪的闪避太低（5~12）** → 玩家基础命中 90 就顶到 95% 上限 → 命中完全无效。**给部分怪加高闪避即可**（纯配置改动，最便宜） |
| 吸血 `回血 = 伤害 × 吸血率` | ❌ 不改 | 塔的核心机制，用户拍板保留 |
| 出手间隔 `(100×speedScale/速度)×100ms + 620ms` | ❌ 不改 | `speedScale=18` 是节奏总闸，动它高风险 |

### ⭐ 所以"词缀校准"要用户先决定的只有两件事
1. **攻 / 血 / 防**：**删掉**，还是**改成固定值**？（删掉 = 装备专管机制属性；改固定值 = 保留"武器给攻击"的直觉）
2. **命中 / 穿透**：**删掉**，还是**改机制**？
   主 agent 建议：**命中走"高闪避怪的钥匙"（配置改动，最便宜）；穿透改百分比（收益中等但要动前后端两份战核 + 重做完平衡）**。

### ⭐ 优先级（按收益/成本）
**必做**：把 `dr` 的供给给足（拉满 +3.0 层、排第 2，而套里只有 14/上限 60）→ **这是"让塔不只考吸血"最便宜的解法，不用新增元素抗性**。
**必做**：给部分怪加高闪避（让命中活）。
**可选**：穿透改百分比；野图溢杀奖励。

   ⇒ **「某属性没用」的结论一律要加一句"在当前 roll 下"，或直接给"拉满值"。别用单套样本下死刑。**
2. **减伤 `dr` 是天然的"第二续航轴"**（拉满 +3.0 层，排第 2），只是**供给太少**（套里只有 14，上限 60）。
   ⇒ ⭐ **"让塔不只考一道题"的最便宜解法 = 把 dr 的供给给足，不需要新增任何"元素抗性"类系统。**
   （用户问过"要不要加流放之路那种元素抗性" → **答：不要，`dr` 就是你的抗性**。）
3. **穿透不是"数值给太小"，是"结构性低效"** —— 拉满 480 也只 **+0.1 层**。
   **根因**：伤害 = `atk²/(atk+def)`，削 defens 的相对收益 ∝ `1/(atk+def)` → **atk+def 随层数暴涨，穿透越后期越没用**。
   ⇒ 点数制穿透在这条公式下**天生无效**；要救只能**改成百分比破甲**（评审的建议成立），**调数值救不了**。

### ⭐ 这解释了用户的"我没从根本做好这个平衡"
同是 T1 词缀，**拉满后的价值从 +0.0 到 +4.0 层，差 40 倍以上** ⇒
**「装备词缀」这一层的价值从未被整体校准过。这是真实缺口，不是错觉。**
但它的范围是**词缀池（取舍 + 数值 + 命中/穿透机制）**，**不是**属性公式 / 成长值 / 塔规则。

### ⚠️ 测量坑
`simulateSession`（野图）**内部自算 stats、不接受注入口径** → 想测"野图拉满"必须**合成装备套**，不能传 override
（传了会得到"裸装+速度121"的假数据，本探针第一版就踩了）。塔侧用 `simulateFight` + stats 覆盖**可以**。

## ⭐⭐ 外部评审交叉验证（2026-09-14，评审 agent 的回复已核，结论如下）

> 完整评审见对话记录；外发用的交接文档在 `docs/数值体系讨论_交接文档_2026-09-14.md`。

### ④ 战斗核心的四个「门闩」——**源码直接答案**（省得以后再猜）
| 门闩 | 答案 | 出处 |
|---|---|---|
| 受伤减免是固定点数还是百分比 | **百分比点数**：`dmg = floor(dmg × (100 − dr) / 100)`，且 `dr` 被 **clamp 0~90** | `battle-sim.mjs` calcDamage |
| **溢杀是否吸血** | **照样全额吸**：`heal = floor(dmg × 吸血率)`，取「算出的伤害」而非「怪剩余血」→ 怪只剩 100 血也按全额 1000 伤害回血 | 同上 |
| 暴击有无上限 | **无上限**：`isCrit = rnd() < rate`，rate 不 clamp（**只有命中率**被 clamp 5%~95%） | 同上 |
| 速度有无地板 | **有**：出手间隔 = `(100 × speedScale / 速度) × 100ms + 固定冻结 620ms`（`hitAt 320 + backMs 300`） | `battle-sim.mjs` step/doTurn |

### ⭐ 吸血占装备收益：**现状 50.6%，护符基底脱钩后 31.9%**
实测（同一套装备，只把**护符基底**的吸血去掉、词缀一字不动）：
- 套A（现状）：吸血 10.8%（护符基底 7.8 + 词缀 3.0）→ 满装 9.88 层、摘吸血 6.42 → Δ3.46；装备总收益 6.83 → **吸血占 50.6%**
- 套B（基底脱钩）：吸血 3.0%（护符基底 0 + 词缀 3.0）→ 满装 8.00 层、摘吸血 6.42 → Δ1.58；装备总收益 4.96 → **吸血占 31.9%**

⇒ ⭐ **「吸血占 51%」这个数一半是护符基底事故撑起来的**（评审推的"降到 40% 以下"方向正确、幅度更大）。
**「吸血是塔的第一属性」成立且不变；但引用份额时必须说清是哪个状态。**

### ⭐ 速度也有天花板：**理论 ×4.63，实测 spd 1000 只到 ×2.10**
速度 80/121/200/400/1000 → 野图 1343/1529/1881/2249/2816 场每 60 分。间隔 = 2250ms(spd80) → 800ms(spd1000)，
逼近固定冻结 620ms 地板。⇒ 速度仍是野图第一属性，但**它也会饱和**。

### ⭐ OAT（单变量摘除）会漏交互项 —— 成立，但要用**攻击**去测、不是暴击
- 用「暴击 × 吸血」做 2×2 析因：交互仅 **+0.04 层**（占暴击自身效应 0.71 层的 5.9%）—— **弱检验**，因为暴击本身效应太小。
- **强检验用攻击**：攻击 ×0.6 → ×1.5 时，吸血的贡献 5.00 → 6.50 层（**+30%**）。
⇒ **12 项摘除表要按"有交互"打折看**；引用单变量贡献时说明这是 OAT 口径。

### 🔴 设计红线（评审提出，主 agent 认可）：**数值阻尼必须键控在「宠物状态」上，不能键控在玩家/账号上**
本项目有 **P2P 交易宠物** → 阻尼若按玩家/账号算（如"账号每周吸收额度"），**买一只高成长宠即可绕过全部限制**。
必须键控在「**吸收方宠物的当前成长值**」（口袋精灵2 原文「主宠 cc 越高」正是状态键控），
让市场交易的是「已经付过阻尼税的价值」。**在一个以交易为爽点的经济里，这是工程需求，不是优化项。**

### ⭐ 其他被认可的评审意见（已收下）
- **词缀供给不对称**：实测 攻击% +41 / 生命% +11 / 防御% +26 —— **最该成为塔里第二续航轴的 hp%，供给反而最稀缺**。
- **`%` 词缀重定价幅度 ≈ 86 倍**（基数从 core 的 1.15% 变到 100%）→ 固定值词缀会相对崩盘，需迁移/补偿方案。
- **「白干」感**：阻尼三段累积 ≈ ×0.20，头部玩家边际收益蒸发 80% → 缓解 = **只阻尼重复 grind 来源，里程碑/跳变来源全额发放**（保爽点3）。
- **阻尼阈值应从"内容更新节奏"倒推，别照抄口袋精灵2 的 14w/20w/25w**（那是别人家内容速度的产物）。
- **试炼与塔是同一张考卷**（都是「跨层累计血量 + 不回血」）→ 三场景实际只有两种题型；
  **塔的不回血受用户拍板保护，但试炼不受** ⇒ 这是"不用推翻拍板就能加题型"的杠杆。**性价比最高的内容改动。**
- **野图根因不是"怪太弱"，是"收益函数只认时间"**（产出 = 场数/时，TTK 饱和后战斗退化成计时器）
  → 解法「**溢杀伤害 → 掉落/鉴定品质**（对数封顶）」复活攻/暴/暴伤/穿透/伤害加成 5 项，且直连第一爽点。
  ⚠️ 但注意门闩：**溢杀已经全额吸血**，再挂掉落 = 对同一件事双重奖励（设计时要意识到，不是不能做）。
- **未测缺口（评审列的 8 条，主 agent 全认）**：OAT 非响应面 / 单功率点 / 试炼没测 / **经济层零覆盖** /
  均值掩盖分布 / 敌人类型特异性被平均吃掉 / 门闩公式 / **毕业后世界零数据**。
  ⭐ 其中最好的一条建议：**交易行挂价 = 玩家的「显示偏好价值表」，可与模拟结果互验** —— 若速度装/吸血装无溢价，
  要么玩家没发现，要么我们漏了什么。**这是一个独立证据源，别浪费。**

### ⭐⭐ 野图专项发现（"后期空虚"的一个具体来源）

  **所有伤害类属性（攻/暴击/暴伤/穿透/伤害加成）怎么涨都不改变刀数 = 零收益**；野图唯一能省时间的是**出手更快（速度）**。
- ⇒ **毕业玩家的图10 已被"一刀秒"** ⇒ 野图对毕业玩家不再构成挑战，**后期实际只剩塔**；而塔只考吸血。
  **「后期空虚」= 野图失效 + 塔只考一道题，这两条叠加。**

### ⚠️ 测量坑（复现时必须注意）
**面板字段名 ≠ 词缀 `type`**：暴击率的词缀 type 是 **`crit`**，面板字段才是 `critRate`。
按 `critRate` 去摘装备词缀 → **一条都删不掉** → 会得出"暴击率贡献 0"的**假结论**（本探针第一轮就踩了）。

## （⚠️ 已修正）装备攻血防为什么会被成长值淹

> **本节是初版结论，其中"6 项空属性"与"命中完全无效"已被上一节推翻，只保留"攻血防为什么被淹"的机制解释。**
> 以**上一节的双场景价值表**为准：真正名存实亡的是 **穿透 / 伤害加成 / 攻击 / 生命 / 防御**（**5 项**）；
> **命中不在其中**（它在野图值 −1.9%，只是塔里被 95% 上限吃掉）。
- 攻血防：装备的 % 只放大「底座」（core 165 / 404 / 72 vs 成长增量 14280 / 29400 / 6120，差 **73~87 倍**）→ 只贡献 1.8%。
- 命中：玩家基础命中已 ≥98，对 dodge 5~12 的怪**命中率已顶到 95% 上限** → 完全无效。
- 穿透：只削 72 点防御，对塔怪 def 3060~66903 是杯水车薪。
- 它们**占了词缀池、占了装备评分、占了玩家的期待，却一点用没有** ⇒「掉到一件高攻武器没手感」的真凶。
- ⭐ 最小改动、零平衡风险的方向 = **让装备名实相符**（装备专管机制属性；攻血防要么给足量、要么从词缀池去掉）。
  **不动任何公式、不动塔、不动经济。**

## 易错写法
- ⭐ **`String(v || '')` 会吞 0**（`0 || ''` → `''`）：显示计数 / 层数 / 腐蚀度处，0 会渲染成空白（「持有 0」→「持有 」）。
  一律用 `v != null ? v : ''`。`tower/ui-tower-settle.js` 与 `ui-tower-battle.js` 同款未修（暂未咬人）。
- ⭐ **浮层 / 徽章不许绝对定位"贴角"**：`.tw-affix-flag` 压住同角「持有 N」（实测 rect 相交）。
  同一角落要塞两个信息 → 改成同一行常规流（允许换行）。
