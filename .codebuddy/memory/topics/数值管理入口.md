> 入口：`MEMORY.md`｜**动数值面板、加可调项、或问"这个数到底该改哪"之前先读本文件。**
> 数值唯一事实源仍是 `docs/js/core/config.js`；改数值的平衡规范见 skill `fos-balance`。
> 本文件 2026-09-16 立（用户诉求：**可读性太差** + "我自己能直接改数值，不用每次找你"）。

## 1 设计师改数值的三个入口（按"改完能不能持久"排）

| 入口 | 位置 | 生效范围 | 何时用 |
|---|---|---|---|
| **开发者面板** | 侧边栏「开发者」→ 调参 / 宠物页（仅 `Config.dev.adminEmails` 里的邮箱可见） | **只改本机内存 Config，刷新复原**；调完点「发布到云端」才持久 | 试手感、当场看效果 |
| **改 config.js** | `docs/js/core/config.js`（+ 系统专属配置在各自 `xxx-config.js`） | 全员（客户端），但**要重新部署**；服务端还要重跑 `gen_server_config.js` | 正式落地 |

⭐ 面板语义（别改坏）：**改内存 = 立即生效、刷新复原**；`UI.renderAll()` 只让**面板以外**的页面看到新值，所以只在**提交/失焦**时调，别在 `input` 里调（会打断光标）。

## 2 面板结构（加可调项 = 补一行声明）

- **调参页**（`ui-dev.js` 的 `SCHEMA`）：扁平标量，形如 `{ path: 'exp.perWinCoef', label, min, max, step, note }`；`path` 支持数组下标（`synthesize.randomBoost.0`）。
  ⚠️ **加完必须确认 path 真能取到值** —— 曾有一条绑在 `nirvana.absorbRatio`（不存在，吸收比例其实在 `Config.items` 的涅槃道具上），滑杆拖了没反应。`vtest_dev_config_table.js` 会守这一条。
- **宠物页**（`ui-dev-pets.js`）：按血统线成块的表状视图，字段用 `{ get, set, def }` 闭包（渲染时就地取，改完立刻生效）；`def` 在**模块加载时**取一次，是"复原值"与"是否改动"的比较基准。
- 两者都**不写死行数**：宠物页遍历 `pet.starters` 生成，加血统线自动出现。
- 扩展机制：`window.DevPanel.registerTab(id, { render, bind })`，页签在 `ui-dev.js` 的 `TABS` 里（`ext: true` = 未注册则隐藏）。抽屉加宽用修饰类 `.dev-drawer-wide`，**不动全局宽度**。

## 3 云端发布的真实生效范围（⭐ 最容易记错的一条）

`game_config_overrides` 的消费方只有四个：

| 消费方 | 读什么 |
|---|---|
| `docs/js/core/server-config.js`（客户端） | **只读 `config->'bot'`**（市场机器人总开关） |
| DB 定时任务（`migrate_market_bot_service.sql`） | `config->'bot'`（dailyCap / maxPrice 等） |
| `battle-settle` EF | `serverConfig`（代码内置）+ **仅当调用者是管理员邮箱时**才合并云端配置（`index.ts` 第 96 行） |
| `resource-trial` EF | 只读代码内置的 `serverConfig.resourceTrials` |

⇒ 🔴 **普通玩家的数值完全来自代码内置的 `config-server.mjs`。**
⇒ 🔴 **不要在 `server-config.js` 里扩展数值白名单**：客户端单方面应用云端数值 → "界面按新数值、结算按旧数值" → 经验条与掉落对不上。该文件顶部已写明理由，**别再"补上"**。
⇒ **数值要让全员生效，唯一安全路径**：改 `config.js` → `cd supabase && node gen_server_config.js` → 部署 EF。

发布链路保护（2026-09-16 加）：
- `buildSnapshot()` = **白名单段 + 剔除全部函数**（`Config` 里混着 `skillOf` / `byName` / `expPackOf` 等函数，`JSON.stringify` 会**静默丢掉**它们）；
- 必须带上 `bot` 键（发布是整列替换，不带上就把机器人开关冲掉）；
- 发布前 `validateSnapshot`（进化门槛递增 / 基宠 8 只 / 经验系数 > 0 / 税率分母 ≥ 1 等）；
- 读取用 `mergeInto`（**深合并**，本地是函数的键永不覆盖），**不是** `Object.assign` 整键覆盖；
- 留档：`admin_save_config` 存 `prev_config`，`admin_restore_prev_config` 一键还原（与当前版互换，可反复来回）。

## 5 写"形态树遍历"的坑（2026-09-16 踩过）

`pet.evolution.tree` **只在基宠层分叉**（基宠 → 一阶A / 一阶B），再往上一层**只有一条路**。
所以遍历时 `idx` 只作用于**第一跳**，后续必须走 `routes[0]`；写成"每层都取 `routes[idx]`"会让二阶/终阶全断在一阶（表现：技能表显示"该终形态没有配技能"）。
另：`pet.speeds` 的**权威值是 `speeds[基宠名]`**（`pet.js:getBaseSpeed` 先按 `lineId` 查），形态级那几行只在老存档缺 `lineId` 时兜底 —— 面板只暴露基宠一行，别把形态级也做成输入框。
另：**进化等级门槛只在 `pet.evolution.stages[].minLevel` 生效**，`tree` 节点里的 `minLevel` 被 `pet_evolve.js:getEvolutionRoutes` **覆盖**，是死数据（别去改它，改了没反应）。

## 6 看数入口：产出归属总表（2026-09-17 立，**现状清单不许手写**）

> 用户诉求原话：「我需要的是一个人可以阅读的 excle 版本」。问的是「物品的全域掉落 vs 区域掉落」。

| 事 | 怎么做 |
|---|---|
| 看现状 | 打开 `docs/产出归属总表.xlsx`（7 页签：怎么用 / 物品总表 / 地图掉落矩阵 / 通天塔产出 / 副本产出 / 其他来源 / 异常与待定） |
| 重新生成 | `cd docs && node tests/export_matrix.js`（一条命令，覆盖输出；中间 JSON 落临时目录、跑完即删） |
| 改口径 | `docs/tests/export_matrix.js`（提取器，主入口）+ `docs/tests/export_matrix_xlsx.py`（openpyxl 写表器） |

**为什么是"导出"而不是"手写一张表"**：手写的现状表会跟配置脱节（本项目头号病因）。这张表**从代码现场抓**，
改完数值重跑一次就是最新的；「异常与待定」页签里的问题（断供 / 漏登记 / 文案对不上 / 名册重复）也全是**自动检出**，
改好重跑会自动消失 —— **不要手改 xlsx**（下次重跑就没了）。

**两条口径铁律**：
1. 来源一律复用 `MatWiki.sources()`（`core/mat-wiki.js`），**别写第二份"谁从哪来"**。
2. 深浅一律直读 `Config.drop.materialWeightsByTier`。唯一允许的加工 = **解析占位键**
   （`区域材料` → `areaMaterials[areaId].name`；`进化素材` → 按 `areaEvolutionTiers` + `evoMaterialWeights` 拆槽），
   与 `drop.js` 的 `pickMaterial` 是同一个公式。

⚠️ **踩坑（静默错答案）**：`'进化素材'` 这个**物品名与占位键同名** → 若先判 `hasOwnProperty(key)`，
会把 10 张图的**槽权重**原样抄下来，显示成「10 张图都掉普通进化素材」（实际图 6~10 只出精粹/传说）。
**必须"名字属于 EVO_TIERS 就先走档位逻辑并 return"，再判直接命中。**
⚠️ 脚本**不得以 `vtest_` 开头**（`run_all.js` 只收 `/^vtest_.*\.js$/`，否则被当回归测试纳入基线）。
⚠️ 环境：本机 **Python + openpyxl 3.1.5 已装**；`docs/package.json` 保持**零 dependencies**（不装 exceljs）。
⚠️ 控制台是 GBK：python 打印中文前先 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`，否则 `UnicodeEncodeError`。

**导出即得的结论（别背，重跑就有）**：全域（10 图都掉）**5 个** = 重铸石/增缀石/剥离石/鉴定石/强化丹A；
单图专属 17 个；多图 10 个（进化素材 5 图、精粹 6、传说 6、合成之石 7、腐印 2~3）；非地图来源 18 个。
