# 关键模块不变量

> 入口：`MEMORY.md`｜**动到哪个模块就读哪一段。**这些是「破坏了就出事故」的约定，不是实现说明（实现见 `docs/玩法系统全览.md`）。
> 本文件按需读取，不占每轮注入预算 —— 有新事实直接往下加。

## 沉浸式外壳 `css/shell-immersive.css`
顶栏 `position:fixed`（0~44px）浮在画面上；三个画面页（主城/世界地图/战斗）`padding:0` 铺满、
面板页 `.page-container` 让位。**第一原则：顶上的内容必须让位** —— 不止 absolute 件（`.bp-topbar` 改 top、
右栏 padding-top），**静态流子元素同样会让顶栏盖住**（2026-09-22 塔刻度条事故）。
塔模式靠 `.bp-arena.tw-mode` 标记（ui-tower-battle.js 挂/摘）切"顶部条全收进文档流"的布局。
⛔ 画面页新增任何**出现在页面顶部**的元素，先问一句：它在 fixed 顶栏底下吗？

## 挂机 `core/idle-bridge.js`
服务器唯一模拟器 + **先记账后放片**（`battle-settle` 预结算当场入账，客户端只回放）。
托管期间本地 `pet.level/exp` 是**演出预演值** → 不许写；改宠物走 `IdleBridge.duringPetEdit(fn)`；启动挂机唯一入口 `Game.startIdleAt`。
- 🔴 只有玩家主动操作才停挂机；会话丢了 `recoverSession()` 自愈；停机必须带原因（禁无参 `stopLocal()`）；
  演出血条 ≠ 真账 endHp；时间戳一律 `performance.now()`；布尔锁 + 网络请求自带超时；
  「谁占的画面只准谁交还」（`release(kind)` 无身份校验 = 雷，各持 `pageClaimed`）。
- 排障：`IdleBridge.getDebugState()` + `__battleLog` + `?debugidle=1`（补账上限等节奏参数见 `fos-verify`）。

## 经验包 `core/tutorial_mode.js#useExpPack`
两套：引导三档（`Config.tutorialMode.expPacks`，按 cap 顶等级）+ 通用 5 档（`Config.expPacks`，喂出战宠）。
通用档 = `Materials.spend`（**服务端原子扣** `spend_material`）→ `Pet.grantExp`（**纯本地**）→ **必须写云端**：
有 cloudId 走 `updatePet(cloudId,{level,exp})`，没有才 `savePet` 建档；托管期间整段包进 `IdleBridge.duringPetEdit`。
🔴 只改本地不写云端 = 包已扣、刷新等级回退（2026-09-22 用户实测「tmd 使用了经验包不会上传到服务器」）。
⚠️ 任何"**花服务端道具 → 改本地属性**"的入口都照这个三段式写，别只做前两段。守值 `vtest_exp_pack_cloud.js`。

## 战斗页占用权 `core/battle-session.js`
一套 DOM 一个实例，野图 / 副本 / 塔共用；`claim(kind)` 拿不到就别进（**不耗门票**），终局 `release(kind)`。

## 任务
领取记录在 `quest_claims(user_id, claim_key)`，唯一入口 `complete_quest(qid, period_key)`；
键 = `qid` / `qid@当天` / `qid@本周一`；⚠️ **只有 `ALREADY_CLAIMED` 才拒绝**；
顺序 = 扣材料 → 占位 → 发奖；🔴 服务端记录必须**回灌本地显示**。
`kind` 权威 = `core/quest-config.js#KIND_META`（182 条）。

## 交易行 `js/ui/market/`（2026-09-23 改版：4 个平铺文件 → 11 文件的子目录）
材料以物易物；税**每满 8 收 1、卖家承担**（改税率须同步 `migrate_material_trade.sql` **两处**）；
`core/market.js` + `market_bot.js`（20 persona 昵称**不落库**）；
收款物从 `Config.trade.materials` 派生（不许另写名单）。

改版后新增的硬契约（详见 `js/ui/market/README.md`）：
- **加载顺序固定**：`pricing → watch → facets → cards → detail → batch → index`
  （其余几个在加载时就从 `window.MarketCalc` 取引用；index 是编排层必须最后）。
- **下单只有一个入口**：`MarketPage.onBuyClick(listing, btn)` / `buyListing(listing)` ——
  结果区卡片、右侧详情栏、批量结账三处都走它，否则迟早某个入口漏分支。
- **跨材料不可比**：10 重铸石 ≠ 10 神圣石 ⇒ 比价 / 参考价 / **降价判定**都必须同 `material_type`。
- 只有**宠物 / 装备**走确认弹窗；**蛋 / 材料**沿用老手感"点了就成交"；无收款物字段的旧版挂单不可购买。
- 关注存的是**「同款」不是「单条挂单」**（挂单会被买走）：宠物按进化线、装备按部位+名+T+稀有度、
  材料按材料名、蛋按品种；存 localStorage `market_watch_v2`（v1 自动搬家）。
- **多件一起买 = 不改数据库**（服务端 `buy_material`/`buy_egg` 没有"买几个"参数）：
  勾中多条挂单、按**收款材料分别合计**、**最便宜的先行**逐笔成交、第一笔失败就停下并如实报告
  "已买到 N 件 + 第 N+1 件为什么失败"，已成交的不退。
- 守值：`vtest_cascade_market` / `vtest_market_enhance` / `vtest_market_ui_v2`。
