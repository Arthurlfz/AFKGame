# 关键模块不变量

> 入口：`MEMORY.md`｜**动到哪个模块就读哪一段。**这些是「破坏了就出事故」的约定，不是实现说明（实现见 `docs/玩法系统全览.md`）。
> 本文件按需读取，不占每轮注入预算 —— 有新事实直接往下加。

## 挂机 `core/idle-bridge.js`
服务器唯一模拟器 + **先记账后放片**（`battle-settle` 预结算当场入账，客户端只回放）。
托管期间本地 `pet.level/exp` 是**演出预演值** → 不许写；改宠物走 `IdleBridge.duringPetEdit(fn)`；启动挂机唯一入口 `Game.startIdleAt`。
- 🔴 只有玩家主动操作才停挂机；会话丢了 `recoverSession()` 自愈；停机必须带原因（禁无参 `stopLocal()`）；
  演出血条 ≠ 真账 endHp；时间戳一律 `performance.now()`；布尔锁 + 网络请求自带超时；
  「谁占的画面只准谁交还」（`release(kind)` 无身份校验 = 雷，各持 `pageClaimed`）。
- 排障：`IdleBridge.getDebugState()` + `__battleLog` + `?debugidle=1`（补账上限等节奏参数见 `fos-verify`）。

## 登录会话
多标签 = `core/auth-session.js` + `ui-session-guard.js`；
跨设备互踢 = `core/server-session.js` + `user_sessions`
（`p_kick_others=true` 与 resume 分开、**绝不复活**；踢人只认服务端 revoked/banned；**网络失败一律不踢**）。

## 战斗页占用权 `core/battle-session.js`
一套 DOM 一个实例，野图 / 副本 / 塔共用；`claim(kind)` 拿不到就别进（**不耗门票**），终局 `release(kind)`。

## 任务
领取记录在 `quest_claims(user_id, claim_key)`，唯一入口 `complete_quest(qid, period_key)`；
键 = `qid` / `qid@当天` / `qid@本周一`；⚠️ **只有 `ALREADY_CLAIMED` 才拒绝**；
顺序 = 扣材料 → 占位 → 发奖；🔴 服务端记录必须**回灌本地显示**。
`kind` 权威 = `core/quest-config.js#KIND_META`（182 条）。

## 交易行
材料以物易物；税**每满 8 收 1、卖家承担**（改税率须同步 `migrate_material_trade.sql` **两处**）；
`core/market.js` + `market_bot.js`（20 persona 昵称**不落库**）+ `ui-market*.js` ×4；
收款物从 `Config.trade.materials` 派生（不许另写名单）。

## 消息中心 `ui/ui-console.js`
**4 频道：世界 / 掉落 / 战斗 / 系统**；**规则表 = 文件顶部常量块（唯一权威）**；内嵌 console 与底部抽屉共享 history(≤100)。
⚠️ `addLog` / `showToast` / `consoleLog` 的 cat **默认 system** → 归属由**调用方**负责（战斗传 `'battle'`、获得物传 `'loot'`）；
守值 `vtest_capital.js` 5 / 5.5 段。
