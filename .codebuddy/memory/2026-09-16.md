## 🔴 片头挡住了登录页的点击（用户："注册里面的悬浮窗口不显示"）
**根因**：新加的片头 `.login-intro` 是 `position:fixed; inset:0` 的**全屏覆盖层**，
它盖在登录页之上时**吃掉所有点击** —— 玩家点"没有账号？注册"毫无反应（表现为"窗口不出来"）。
原来只有右下角一个「跳过片头」小按钮能关掉它，玩家根本不知道要点那儿。
**修复**：
- **整层可点跳过**（`intro.addEventListener('click', finish)`）+ `cursor:pointer`；
  按钮文案改成「点击任意处跳过片头 ›」。
- 兜底 `MAX_MS` 12000 → **9000**（片头多留一秒，玩家就多一秒点不到登录/注册）。
📌 **教训（通用）**：任何全屏/铺满的覆盖层，都必须先回答"玩家怎么点掉它"——
只给一个小按钮等于没给；**整层可点 + 明确文案 + 短超时**三件套。
版本号：`ui-intro.js` → `?v=20260916intro1`、`app.css` → `?v=20260916intro1`；`npm run check` 77/3 无新红。
⚠️ 若用户反馈"还是不行"，说明与片头无关，下一步应查 `ui-login.js` 的 `applyMode()`（注册模式切
`nickname/invite` 的 `style.display`）与 `.login-panel` 的层级。

## ⭐ 开局选宠的悬停浮窗（用户："选择宠物的那个时候悬浮窗口没出来"）
**排查**：复制 `vtest_newbie.js` 的 vm harness 写临时探针（`docs/tests/_tmp_tip.js`，
该文件匹配 gitignore 的 `docs/tests/_tmp_*.js`、且 `run_all` 只扫 `vtest_*` 不会污染基线），
在 vm 内按 `main.js previewOf()` 同款造预览宠物，直接调 `PetUI.petTipHtml` / `UI.bloodlineHtml` / `UI.showPetTip`。
结论：**内容渲染是好的**（petTipHtml 返回 2498 字符、血统卡正常），不是渲染报错。

**真缺陷**：`showPetTip` **只夹了左右、没夹上下**，且硬取 `document.documentElement.clientWidth`
（桩环境/个别浏览器下是 undefined，探针里就抛了 TypeError）。
⇒ 卡片位于屏幕下半部时，浮窗整块掉到视口外，**表现就是"悬停了但什么都没出来"**。

**修法（ui-pet.js）**：
1. **先 `add('show')` 再量尺寸再定位** —— `display:none` 时 `offsetWidth/Height` 是 0，
   原来的顺序（先定位后 show）既算不准避让、也会先闪一下再跳位。
2. **左右 + 上下四向夹边**：右放不下翻左；下放不下往上抬。
3. 视口尺寸 `documentElement` 拿不到时退回 `window.innerWidth/innerHeight`。
4. `petTipHtml` 包 `try/catch`：浮窗是纯展示，**任何异常都不许影响选宠主流程**。
版本号 `ui-pet.js` → `?v=20260916pet2`；`npm run check` 77/3 无新红。

📌 **排查「UI 不显示」的配方（可复用）**：复制 `vtest_newbie.js` 头部搭临时 vm 探针 →
在 vm 内部直接调渲染函数看是否抛错 → 用完删除。
⚠️ 桩里 **没有 `document.documentElement`**（已确认），所以这类读视口尺寸的代码在桩里**必抛** ——

## ⭐⭐ 红点按业界标准补齐（用户："看齐补齐"）
**调研依据**（web 检索 + 抓取 CSDN《一个简单的通用红点模块方案》，业界通行）：
- **三种表现**：常规小红点 / 数字红点（最多三位）/ 文字标签（新·限时·推荐·hot）
- **通用规则**：红点由触发点**逐级向上传递**直到顶层入口；**界面展开时隐藏父级红点**
- **叠加规则**：同类叠加 —— 小红点仍是小红点、数字**相加**、文本仍是单个

**本项目补齐（`ui-guide-dots.js` + `app.css`）**：
1. **往上汇总**：新增 `CHILD_PAGE = { evolve/synth/merge/awaken → 'pet' }`。
   🔴 **只记最细一层**（有 `tab` 就只记 tab，父级靠汇总得出）—— 父子都记会**重复计数**、数字虚高。
2. **点开就消**：`paint(..., skipActive=true)` → 带 `.active` 的元素摘掉标记。
   （人已经在这一页了，这页的入口不亮；子标签照样亮，直到事情办完 —— 是"临时隐藏"不是"永久消除"）
3. **数字**：`data-guide-dot` 的**值就是件数**；CSS 用 `:not([data-guide-dot="1"])` 切成数字胶囊。
   ⇒ 一个属性两种表现，不用额外加 DOM 元素。

**没做**：文字标签（新/限时/推荐）—— 本项目暂无这类业务语义，等有需求再按同一张类型表扩展。
版本号 `app.css` / `ui-guide-dots.js` → `?v=20260916dot2`；`npm run check` 77/3 无新红。
