## 掉落播报「一般」的真因：流光根本没跑起来（用户说"还可与炫酷一点"）

### 🔴 根因（不是效果不够炫，是动画被打断）

`ui-console.js` 的 `consoleLog` 是**任何频道共用**的入口，它一调用 `renderChatPanel()` 就把
**所有容器整列 `innerHTML` 重刷**。战斗流水每 6 秒一条 → 掉落频道的列表每 6 秒被重建一次
→ 顶档的流光动画**每次播到一半就被打回起点**。玩家看到的是"闪一下就重来"，所以"一般"。

⭐ **可复用判据**：任何「CSS 动画 + 列表整体 innerHTML 重刷」的组合，动画都活不下来。
想让某行动画持续播，就必须**增量渲染**（只追加新行，老节点不动）。

### 改法

1. **`renderList` 改成增量渲染**（`ui-console.js`）：
   - `history` 每条加单调递增 `seq`（**别删**，删了流光就废）。
   - `renderList` 记住 `listEl.__seqs`：若频道没变且新的 seq 序列前缀一致 → **只 `insertAdjacentHTML` 追加新行**；
     被 100 条上限挤掉的老行从头删；环境没有 `insertAdjacentHTML`（测试桩）→ 退回整列重建。
   - ⚠️ 仍会整列重建的情况：切频道 / 老消息被挤掉 / 测试桩。
2. **流光加强**（`game.css`）：常态 2.6s → **2.2s**、高光带更窄更亮（#fffdf0）；
   **新增入场动画 `loot-drop-in`**（0.75s，只播一次）：从 `brightness(3.4)` 过曝收回到本色 = 「捡到的那一瞬间」。
   - ⚠️ 入场能成立**完全依赖**上面的增量渲染；整列重刷的话它会反复重播（变成每 6 秒闪一次）。
   - `prefers-reduced-motion` 下两个动画都关掉。
3. 对照页 `_loot_preview.html` 加了「重播一次」按钮（入口动画只在渲染时播一次，想再看要重播）。

## 用户报三处问题：鉴定石不见了 / 装备 tab 层级太低 / 孵化蛋页面层级太低（要求按第一原则修）

### ① 鉴定石"不见了" —— 根因是 flex:1 失效，不是元素没了

- `.bag-window .bag-main-left` 是 flex 列，但**没有 `height:100%`** → 子元素 `.bag-grid-area` 的
  `flex:1` **失效**，网格跟着物品数量一路长高，把底部的统计条 / 鉴定石 / 分解台**顶出可视区**。
- 修法：给 `.bag-main-left` 补 `height:100%; min-height:0;`（不是把鉴定石挪位置、不是加 z-index）。
- ⭐ 这正是本项目 CSS 铁律里的老坑（父容器缺 height:100% 致 flex:1 失效），**已踩第二次**。

### ②③ 装备 / 孵化 tab 层级太低 —— 根因是**没有层级表**，不是数字不够大

- 真相：背包窗口（装备 tab、素材蛋/孵化 tab 都在这个窗口里）是 `z-index:100`，
  而**后加的浮层随手挑了大数字**把它压住：任务追踪 280、tooltip 300、引导卡片 200、副本结算 500。
- 修法：**立一张层级表**（写在 `game.css` 顶部注释，唯一权威），把每一层放回该在的位置：
  - `.quest-tracker` 280 → **90**（常驻小条，本来就该被浮窗盖住）
  - `.equip-detail-modal` 60 → **200**（它在背包窗口里弹出，必须比窗口高；以前 60 会被窗口压住）
  - `#starter-screen` 110 → **220**；`.next-step-card` 200 → **230**；`.area-detail` 60 → **100**
  - 保持：背包窗口 100、任务面板 105、tooltip 300、副本结算 500
- 复查：现在压在背包窗口之上的只剩「模态层 + tooltip + 系统级」，都是**应该**在上面的。
