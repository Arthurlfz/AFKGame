## 市集左栏「一直在闪烁」+ 左栏太窄（2026-09-23 第六批，用户实机反馈）

**现象**：用户原话「左侧的筛选面板为什么总是在闪烁，并且左侧的筛选面板有点窄了稍微要长一点」。

**闪烁的真因（根因，不是动画本身有问题）**：
`main.js:810` 的**回血时钟每 1 秒**调一次 `renderAll()` → `ui-common.js:387` 的 `UI.renderMarket()`
⇒ 我上一轮拆出来的 `facets.render()` **每秒把左栏整块重建一次** ⇒
`.cf-step` 的级联入场动画（`cascadeIn .26s` + 最多 `6×40ms` 延迟）**每秒重播一遍**，
一秒里有一半时间在动画里 —— 玩家看到的就是"一直在闪"。顺带悬浮态、输入焦点也被反复打断。

**修法（按"状态没变就别重建"，不是把动画删掉）**：
1. `facets.js`：左栏加**重建签名**（`stepsSignature` / `pathSignature`），签名没变且容器里有节点就整块跳过；
   并且入场动画**只在级联结构变了时**（类型变了 / 词缀条件块出现或消失）才播 ——
   仅换个选项值（白装→蓝装）不该让整栏闪一下。
2. `index.js`：整页加 **`visibleSignature` 守门**，覆盖 挂单池(id+标价+卖家+数量) / 视图 / 版式 /
   筛选 / 分页进度 / 批量勾选 / 关注状态 / 右栏选中项 / 登录身份 / 我的挂单数。
3. 🔴 **关键辨析：「不重建」≠「什么都不做」**。有几样东西是**每秒都可能变**的，不能靠重建跟上：
   - 右栏「我持有多少材料」→ 新增 `MarketDetail.refreshNumbers()` **就地改文本**；
   - 卖家名牌（`paintSellerTags`）→ 跳过的帧仍调用，但**吃缓存**（`fetchPerksOf` 在
     `supabase.js:557` **没有缓存**，每帧都调就是每秒一个请求）。
   - ⛔ **玩家自己的东西（背包材料 / 宠物等级成长）绝对不许进签名** —— 挂机时一直在变，
     一进签名就变成"每秒重画整页"，等于把闪烁问题原样搬回来。
   - 「我的上架」视图**不做跳过判断**：它是上架工作台，列的是玩家自己的实时数据，
     而且它没有任何入场动画、本来就不会闪 ⇒ 保持改版前每秒刷新的节奏。

**左栏变宽**：`232px → 272px`（≤1440px 248 / ≤1180px 236）。
理由写进 CSS 注释：装备分支 6 级筛选（部位12/稀有度4/底材T6/词缀T6/词缀条件/排序）塞不进窄栏。
`market-cascade.css?v=20260923cols2`。

**新增守值（`vtest_market_ui_v2.js` §7/§7b/§8）**：
结构变化才播动画 / 只换值不重播动画 / 数据没变则左栏·路径·结果区·右栏都不重建 /
数据变了必须重画 / 关注变了必须重画 / 背包变了（全部在售）不重画但右栏数字就地刷新 /
「我的上架」不做跳过判断 / 左栏宽度 ≥260px。

**🔴 写这批守值学到的两件事（都值得记）**：
- **测试桩的 `innerHTML=''` 不会清 `children`**（只是给属性赋了个字符串）⇒ 重建是"往后追加"。
  所以 `children[0] === 旧节点` **永远成立**，用它判断"有没有重建"是**假绿**；
  必须比 **`children.length`**。我第一版就写成了假绿，自己复查时发现并改掉。
- 带短横线的 id 不能用点号访问：`els.market-list` 会被当成减法 ⇒ 必须 `els['market-list']`。

**验证**：全量 **95 通过 / 0 失败，零新红**；静态审计市集 474 个类名全部有 CSS 定义。
