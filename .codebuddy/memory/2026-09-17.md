### Bug 1：`binders[activeTab] is not a function` + `Cannot set properties of undefined`
**根因：我误解了开发者面板的页签注册契约。**
`ui-dev.js` 的真实约定（`renderBody` 里两行决定）：
- `html += panels[activeTab]()` —— **render() 必须无参、同步返回 HTML 字符串**；
  写成异步会拼出 `[object Promise]`；写成操作 DOM 会 undefined（那时容器还没进文档）
- `binders[activeTab]()` —— **无条件调用，所以 bind() 必须提供**
正确姿势：**「render 出壳（占位文案）→ bind 里查 DOM 再异步填数据」**（`ui-dev-pets.js` 就是这么写的）。
修：`ui-dev-ops.js` / `ui-dev-feedback.js` 两个页都改成这个模式。
📌 **新增 `docs/tests/vtest_dev_tabs.js` 守住契约**：ext 页签必须有文件注册、render+bind 齐全、render 不许 async。
（第一次写这个测试时正则用 `[\s\S]` 跨过了 `}`，把非 ext 页签也算进来了 —— 要用 `[^}]`。）

### Bug 2：`column reference "id" is ambiguous`
**根因：`admin_list_feedback` 的 `returns table (id bigint, ...)` 输出列 `id` 在 plpgsql 里是【变量】，
