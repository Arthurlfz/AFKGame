# 装备打造系统 · 通货与词缀多样性（修订版 v2）

> 基于《游戏设计理念 v2》《游戏数据地图 v1》及 `config.js / equipment.js / equipment_craft.js / ui-craft.js / salvage.js` 的实现，针对"通货打造多样性"与"词缀多样性"给出修正方案。
> 修正说明：v1 中"攻速"词缀与"格挡/反伤"词缀已移除——本游戏不存在攻击速度概念（战斗为"进度条跑满→攻击/放技能"，`config.battle.speedScale` + `speeds` 表决定节奏，`速度`已是基础属性）；格挡/反伤与挂机定位不符。通货方案由"定向"改为"非定向"，保留随机寻宝内核。

## 一、现状（已核实）

- **词缀结构**：`eq.affixes = { prefix:[], suffix:[] }`，每桶≤3、共≤6。现存词缀池仅 6 种：`攻击% / 生命% / 防御%`（前缀）与 `速度% / 暴击率% / 吸血%`（后缀）。全部为独立 % 加成，无联动、无触发。
- **稀有度决定词条数**：白 1 / 蓝 1~2 / 金 2~3（增缀石可补到 6）。
- **T 阶（T1~T5）**：仅决定单条词缀数值区间，T1 最强。
- **现存通货（均为随机）**：强化石（随机升 1 阶）/ 祝福石（随机换类型）/ 神圣石（全词缀重 Roll 数值）/ 增缀石（按前缀优先新增 1 条）。

## 二、卡点根因（修正）

1. **词缀"种类"稀缺而非"数量"稀缺**：6 条全是数值 dial，配装必然收敛到"攻击%+暴击%+吸血%"，缺乏流派差异。
2. **四种通货机制雷同**：本质都是"掷骰改词缀"，缺一个独立的新维度。
3. **（已修正）** 之前建议的"攻速/格挡/反伤"不适用于本作——本作战斗无攻击速度、且防御向微操与挂机定位冲突。原"定向选词缀"方案也被否定：本作 G 点是"求而不得 / 开出好货"的寻宝感，定向打造会消解这一内核。

## 三、词缀多样性（非定向扩展）

在保留随机掉落内核的前提下，扩充**适配挂机**的词缀种类，让"捡到/开出"的结果更有层次：

| 词缀 | 分类 | 说明 | 状态 |
|---|---|---|---|
| 攻击% | prefix | 攻击力 | 已有 |
| 生命% | prefix | 生命值 | 已有 |
| 防御% | prefix | 防御值 | 已有 |
| 速度% | suffix | 进度条节奏（基础属性延伸） | 已有 |
| 暴击率% | suffix | 暴击概率 | 已有 |
| 吸血% | suffix | 吸血 | 已有 |
| **暴击伤害%** | suffix | 暴击时追加伤害 | 建议新增 |
| **穿透%** | prefix | 无视部分防御，对抗高防怪 | 建议新增 |
| **经验加成%** | prefix | 加快挂机成长（契合挂机） | 建议新增 |
| **材料掉率%** | suffix | 提高刷材料效率（契合挂机） | 建议新增 |

> 实现：仅需在 `AFFIX_POOL` 增 4 条（带 category），并在 `battle.js` 结算消费 `critDmg / pen`（穿透作用于防御计算）、`exp / drop` 作用于成长与掉落。旧装备 `fromCloud` 已兜底缺失字段，兼容无风险。
> 可选：放宽"前缀≤3/后缀≤3"硬边界为"总条数≤6，桶自由分配"，组合空间翻倍。

## 四、通货多样性（非定向，保留随机内核）

方向：每颗通货作用于**不同维度**，而非"让你指定某条词缀"。保留"开出未知"的赌徒快感。

| 通货 | 机制（仍随机） | 与现有区别 |
|---|---|---|
| 强化石 | 随机 1 条非 T1 词缀，T 阶 +1 | 现状保留 |
| 祝福石 | 随机替换 1 条词缀类型（T 阶保留） | 现状保留 |
| 神圣石 | 重 Roll 全部词缀数值（类型/T 阶不变） | 现状保留 |
| 增缀石 | 按前缀优先新增 1 条随机词缀 | 现状保留 |
| **蜕变石（新增）** | 提升稀有度（白→蓝→金），并重新随机全部词缀（类型+数值） | 与神圣石区分：蜕变石"换皮+重生"，神圣石"保类型只洗数值" |
| **洗练石（新增）** | 整体重铸：**类型与数值**全部重 Roll（区别于神圣石保留类型） | 给"再来一次"机会，仍不指定具体条 |

> 注：剥离/锁定等"指定某条"的方案已被否决（属定向），本版不含。

## 五、落地风险

- 新增 `critDmg / pen / exp / drop` 必须落成到 `battle.js` 与掉落/经验结算，否则词缀空转。
- 词缀池改动后，`vtest_affix.js` / `vtest_augment.js` 硬编码了 6 类型与 `PREFIX_TYPES/SUFFIX_TYPES`，须同步更新（建议改为读取配置）。
- 蜕变石/洗练石作为强通货，需在 `salvage` 与掉率上重新配平，避免通胀。
