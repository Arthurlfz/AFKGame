# 战斗界面 Redesign 说明（Forge of Souls）

> 独立原型位于：`新demo/battle-prototype/battle.html`
> 视觉规范强制引用：`Mvp/原型代码/css/design-tokens.css`（唯一权威，禁止另搞一套）
> 状态：原型已定稿，UI 回归测试 `tests/vtest_ui.js` 已修绿（9/9 PASS）

---

## 一、这次解决了什么（原界面问题）

原战斗界面信息过载、布局不舒服：
1. 选地图（6 张卡）和战斗场景硬挤同一屏，战斗区被压成一条缝。
2. 战斗区太空又太挤，宠物/敌人贴边、中间大片黑。
3. 底部"宠物属性与装备""背包装备"两个面板把页面切碎。
4. 聊天/系统输入框压在战斗最底下，常驻但占核心空间。
5. 左侧导航与顶部标题重复"野外探险"。

---

## 二、确定的设计决策（与用户逐条对齐）

| 项 | 决策 |
|---|---|
| 背景 | 纯暗色底（深灰/黑 + 暗金描边），**不做场景**；以后要加背景图，直接给容器垫图，不影响布局 |
| 战斗中显示信息 | 仅：头像 / 名字 / 等级 / 血条 / 行动条。**属性不常显** |
| 属性查看 | 悬停（移动端长按）角色卡 → tooltip 弹攻/防/速/成长。平时零属性文字 |
| 聊天 + 系统 | **必须常驻**（用户硬性要求）。底部横条，默认窄（120px），聊天/系统两个 tab 切换 |
| 掉落日志 | 不单独显示，进"系统"console（文档本就要求独立） |
| 换图 | 二级跳转：左侧"野外探险"进地图选择页 → 选图 → 跳战斗页；战斗页顶部留"当前地图 + 换图"小条 |
| 换装 | 不在战斗页做。回"背包"/"宠物资料"页换，挂机战斗后台继续（不中断） |
| 飘字 | 从**被打方头顶**冒（-23 红字 / 暴击更亮更大 / 回血绿字），不是中间弹幕 |
| 攻击动效 | 出手方往对方方向"撞"一下（≤300ms 位移回弹）+ 受击方角色卡闪红抖一下。纯 CSS transform，**无粒子**（符合规范"不加大动画/粒子"） |
| console 可调 | 顶部把手拖高度（64px~60vh）；拖标题栏可在屏幕内移动；"吸底"按钮还原。默认仍吸底常驻 |
| 已知 bug（旧） | 系统 tab 静音/切走后还弹消息 → 原型已修：只有当前不在系统 tab 时才标红点，切回即消 |

## 三、视觉规范落地（design-tokens.css 约束）

原型**必须**引用 `Mvp/原型代码/css/design-tokens.css`，所有颜色/边框/圆角/字号走 token 与 `fs-` 组件，禁止：
- 外部字体（用规范指定的 `--font-title` / `--font-num` / `--font-body`）
- 玻璃拟态 / backdrop-filter 半透明
- 大圆角（上限 `--radius-sm` = 2px）
- 紫色渐变 / 粒子特效
- emoji（角色卡用单字占位，如"腐""鼠"）

### 组件映射
- 角色卡 → `.fs-panel` 同款皮革颗粒 `--tex-grain` + 内阴影（非后台面板方框）
- 主按钮"开始自动战斗" → `.fs-btn--primary`
- "换图" → `.fs-btn--ghost`
- 血条 / 行动条 → `.fs-bar .fs-bar__fill`（行动条复用 `.fs-bar--energy` 蓝）
- 输入框 → `--inset` 凹槽风

### 配色基调
暖黑底 `--bg` + 熔岩金 `--accent` + 血晶红 `--hp`/`--hp-hi` + 幽蓝 `--energy`(行动) + 旧铁边框 `--line`。

## 四、换图逻辑（二级跳转实现）

- `MAPS` 数组存 6 张图（枯萎之地 / 泣腐泥沼 / 白骨旷野 / 暗影废墟 / 血渴裂谷 / 遗忘之森），各带 `name/lv/mon/monLv/hp/atk/def/spd/desc`。
- 点"换图" → 盖全屏浮层 `.map-overlay`，6 卡铺开，当前地图高亮。
- 选图 → `chooseMap(id)`：更新顶部地图条 + 敌方战斗卡（头像/名/等级/满血/tooltip 全换）+ 同步战斗循环敌方血量上限 + 系统 console 冒"已进入 XX"。
- 接游戏时把 `MAPS` 换成接口/配置数据即可。

## 五、接入游戏的待办（搬进 Mvp/ 时）

1. 把战斗页从"选图+战斗同屏"改为二级跳转（地图选择页独立）。
2. 战斗 widget 改用本原型结构，引用 `design-tokens.css` 与 `fs-` 组件。
3. 属性走 tooltip（悬停），战斗卡不堆属性。
4. 飘字挂头顶，攻击动效接 `lunge()` / `hit()`。
5. console 保持常驻，红点逻辑按"非当前 tab 才标"实现。
6. 换装引导回背包/宠物资料页，战斗不中断。
