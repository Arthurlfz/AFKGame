## 一、世界观对齐（结论）

世界观**已有且够用**，不重写。核心设定：

- **腐变（The Blight）**：大陆深处的扭曲能量，把生物变异成腐化系 / 骨系 / 影系 / 毒系 / 血系
- **驯变者（玩家）**：孵化、收服、培养变异生物，靠它们往大陆深处推进
- **6 层递进**：越深腐变越浓 → 生物变异越彻底 → 怪越强

**唯一要对齐的**：地图正式名以**代码为准**（世界观草稿的名字是早期版本）：

## 二、任务 Schema

```js
{
  id: 'm1',                    // 唯一 id
  category: 'main',            // tutorial 新手 / main 主线 / daily 日常 / achieve 成就
  type: 'kill',                // 目标类型（见下表）
  area: 'corrupted-forest',    // 限定地图（kill 类用）
  matName: '枯荣种荚',          // 限定材料（collect 类用）
  need: 30,                    // 需求数量
  unlockLevel: 1,              // 出战宠物等级达标才解锁（tutorial 用 requires 代替）
  requires: 't1',              // 前置任务 id（仅 tutorial 用，做完才出现下一条）
  repeat: false,               // 是否可重复（daily 为 true）
  name: '初入腐土',             // 任务名（有世界观味道）
  reward: { 进化素材: 2 }        // 奖励材料
}

**解锁方式（两类）**：
- `unlockLevel`：出战宠物等级达标即解锁（主线 / 日常 / 成就）
- `requires`：前置任务完成后才出现（**新手链专用**，一条接一条线性引导）

**完成记录**：新手 / 主线 / 成就都是**一次性**，交完记入已完成列表不再出现；日常每天刷新。
```

**目标类型（9 种）**：

| type | 含义 | 进度来源 |
|---|---|---|
| `collect` | 收集 N 个材料 | 背包材料数（实时） |
| `kill` | 击败 N 只怪 | 战斗胜利上报 |
| `evolve` | 进化 N 次 | 进化上报 |
| `nirvana` | 涅槃 N 次 | 涅槃上报 |
| `synth` | 合成 N 次 | 合成上报 |
| `hatch` | 孵化 N 只 | 孵化上报 |
| `craft` | 打造 N 次 | 打造上报 |
| `salvage` | 分解 N 件 | 分解上报 |
| `equipDrop` | 获得 N 件装备 | 掉落上报 |
| `trade` | 市场成交 N 次 | 交易上报 |
| `equip` | 穿装备 N 次 | 穿装备上报 |
| `list` | 上架 N 次 | 上架上报 |

## 三、新手成长任务 12 条（线性引导）

**定位**：手把手教玩家这个游戏怎么玩。一条做完才出现下一条（`requires` 前置依赖），全部一次性。
**覆盖的核心循环**：打怪 → 穿装备 → 进化 → 打造 → 分解 → 孵化 → 交易 → 推进地图 → 涅槃。

| id | 任务名 | 教什么 | 类型 | 需求 | 前置 | 奖励 |
|---|---|---|---|---|---|---|
| t1 | 初醒 | 打第一场战斗 | kill | 1 只 | 无 | 重铸石×1 |
| t2 | 熟悉腐土 | 连续挂机 | kill | 10 只 | t1 | 进化素材×1 |
| t3 | 披上残甲 | 穿上第一件装备 | equip | 1 件 | t2 | 重铸石×1 |
| t11 | 腐土巡守 | 持续挂机练级 | kill | 30 只 | t3 | 重铸石×2 |
| t12 | 腐土猎手 | 练到 Lv10（进化门槛） | kill | 80 只 | t11 | 进化素材×1 |
| t4 | 第一次进化 | 完成进化 | evolve | 1 次 | t12 | 进化素材×2 |
| t5 | 初次淬炼 | 打造装备 | craft | 1 次 | t4 | 神圣石×1 |
| t6 | 拆解废品 | 分解装备 | salvage | 1 件 | t5 | 增缀石×1 |
| t7 | 新的生命 | 孵化宠物蛋 | hatch | 1 只 | t6 | 宠物蛋×1 |
| t8 | 第一次交易 | 市场挂单 | list | 1 次 | t7 | 合成之石×1 |
| t9 | 深入腐变 | 推进到第 2 张图 | kill（泣腐泥沼） | 20 只 | t8 | 精粹进化素材×1 |
| t10 | 脱胎换骨 | 涅槃（Lv40） | nirvana | 1 次 | t9 | 涅磐兽×1、合成之石×1 |

> t1 在玩家选完开局宠物后立即出现；t10 需要 40 级，是新手链的收尾，做完玩家已完整走通一遍核心循环。

> **t11 / t12 是「升级缓冲」**：进化门槛是 Lv10，按经验公式（`22 × 等级^1.3` 升级 / 单场 `4 × 怪物等级 × 难度`）
> 约需累计 **78 场**胜利。若 t3 后直接接「第一次进化」，玩家要干等约 20 分钟，引导条一直卡在 0/1 毫无反馈。
> 这两条用累计击败数填空档，让玩家边刷边升级，做完 t12 时正好够 Lv10 去进化。
> **注意**：kill 类进度在 `reportType` 里按 type 全量累加（不分任务、不看解锁），所以 need 是**累计击败数**而非增量——
> t1(1) / t2(10) / t11(30) / t12(80) 共用同一个计数器。

## 八、待你拍板

1. 任务名要不要更有世界观味道（现在是「初入腐土」这种短语，也可以做成「驯变者日记·其一」）
2. 日常奖励的量（重铸石×2 每天）会不会太多/太少
3. 成就的累计门槛（10000 只怪）合不合适
4. **新手链要不要常驻提示**：现在任务藏在面板里，玩家可能压根不点开。要不要在战斗页顶部常驻一条「当前：披上残甲 · 穿 1 件装备」，直到新手链做完？（记忆里这条本就是待办：现在只有一次性 modal，没有"当前该干嘛"的指引）
