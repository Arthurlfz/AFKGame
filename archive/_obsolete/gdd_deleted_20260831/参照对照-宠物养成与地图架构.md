# 一、宠物养成对照

## 1.1 他的（参照游戏）

| 维度 | 现状 |
|------|------|
| **宠物谱系** | 五系（金木水火土）+ 衍生系（神、神圣、萌、古、圣、天、佛）。一阶波姆系 → 十阶各种专属宠，阶别 1~10。 |
| **进化** | 基础进化 **10 次**（古/天系可多 1 次）。每条宠有 **A/B 两条进化路线**（B 线涨成长更高）。五行路线有编码决定进化节点（金系 ABB、木系 ABAA、水系 ABAA、火系 ABAA、土系 BAABA = 进化/高进/超进的不同组合）。 |
| **合成（合神）** | 五系宠物合成提高**成长（cc）**。副宠阶别高 → 主宠升两阶。自然合神（50~300cc 有几率成神，300+ 必成 60cc 满神）；用至尊神石必出指定神、百变魔石随机出神。主流有"4爱/5爱/6爱/3爱"等合神思路（按消耗的爱蛋数量区分效率）。 |
| **涅槃（转生）** | 神系及以上宠物的合成方式，消耗**涅槃兽**。主宠吸副宠成长、等级重置。涅 cc（副宠等级越高主宠涨越多，约副宠 18%）/ 涅属性（主宠等级越高属性涨越多，前 3 次最大）。高成长有削减（>14w×0.7、>20w×0.65、>25w×0.45）。特殊涅槃兽 C3/C4/T4/I3 有替换/加成效果。 |
| **破茧** | 提高某一基础属性的成长（文档标注"暂未开启"）。 |
| **孵化 / 抓宠** | **抓宠是核心**：怪物血量越低捕捉成功率越高；**高级宠去特定地图抓捕**；也有宠物卵（爱蛋、涅蛋等）孵化。 |
| **品级** | 残次→普通→平庸→杰出→优秀→卓越→完美→悟境→化境→极境→破云境，百分比加属性（最高 +29%），影响技能栏位数量。 |
| **技能 / buff** | 宠物可激活自带技能 + 大量 buff（攻击/命中/加深/吸血/速度/生命百分比），靠专属任务、开包、称号获取。化境以上多技能栏位。 |
| **属性来源** | 基础属性（cc/五行/品级/等级）+ 装备%加成 + 称号 + 成就 + buff + 宝石 + 秘宝/武魂/神魂/魂器/女神。**属性维度极多**（攻击/命中/加深/吸血/速度/生命/防御/闪避/抵消/魔法）。 |

## 1.2 我的（锻匠之魂）

| 维度 | 现状 |
|------|------|
| **宠物谱系** | **8 基宠**（腐噜兽/血狐/瘟熊/疫毛兽/骨狼/毒沼蛙/尸犬/幽影兔），各 2 条首段路线 → **3 阶进化链，16 个互不重复终极形态**。 |
| **进化** | 首段 **Lv.10** / 二段 Lv.25 / 三段 Lv.40 三门槛；进化次数上限 **10**（4~10 次为占位"继续进化=成长+"）。100% 成功、等级不变、成长 +0.1~0.2。素材分 3 档（进化/精粹/传说，按次数）。 |
| **合成** | **合成出「·异变」变异宠**（50% 概率）。主×0.6 + 副×0.4 + 变异[1,3] 成长；两只素材消失、新宠 1 级；消耗**合成之石×1**。 |
| **涅槃** | 主宠吸副宠成长、等级重置 1、进化次数清零、转生+1、突破成长上限（软上限 100）。消耗**涅磐兽×1**；双方 ≥40 级。 |
| **孵化** | 野怪按 `eggBaseName` 掉**特定基宠的蛋** → 孵化出对应基础宠（成长 3~8）。**无"去某图抓某宠"**，蛋随机/任务发。 |
| **品级** | **无品级系统**。 |
| **技能 / buff** | **不做技能/天赋**。变异宠仅继承来源基宠的定位与属性（statCoeff/速度/profile），**不额外带技能**。 |
| **属性来源** | 裸属性（成长/等级/lineId 系数）+ 装备%加成 + 机制属性（命中/闪避/暴击/暴伤/吸血，来自 profile + 装备）。维度较简洁（攻/血/防/速 + 暴击暴伤命中闪避吸血）。 |

## 1.3 对照小结（一眼可见的差异）

- **谱系深度**：他=五系×十阶×多衍生系，海量专属宠；我=8 基宠×16 终极形态，谱系浅。
- **成长维度**：他=成长(cc) 为核心，且合神/涅槃都能滚成长；我=成长(growth) 同样为核心，进化/涅槃/合成都能涨——**这一点思路一致**。
- **合成/涅槃**：两边都有"合成变异 + 涅槃吸成长"双路线，机制同构。
- **他独有**：品级系统、技能/buff 体系、抓宠（去图抓特定宠）、破茧。
- **我独有**：·异变 后缀变异宠（他靠"百变/至尊神石随机出神"近似，但形态命名不同）；净推进平衡承诺（≤1.35× 无废宠，他那边靠氪度拉开差距）。

## 2.3 对照小结（一眼可见的差异）

- **地图数量**：他=几十张野生图 + 多个副本；我=10 张图，密度低。
- **地图内容**：他=每张图有"专属材料 + 固定 BOSS + 可抓特定宠"三重内容；我=只有专属材料 + 进化素材，无 BOSS、无抓宠。
- **副本层**：他=通天塔/地狱之门/深狱/圣兽云殿等多层副本（无限刷、特殊掉落）；我=零副本。
- **地图↔养成联动**：两边都是"图掉养成材料"——**这一点一致**；差异在他多一层"去特定图抓特定宠"。
- **地图↔装备联动**：他=装备按属性需求、玩家为不同图/BOSS 配装（"散搭"主流，非套装）；我=装备按图档掉（图越高底材越好），但**不跟图的威胁/属性需求对齐**，配装无决策点。
