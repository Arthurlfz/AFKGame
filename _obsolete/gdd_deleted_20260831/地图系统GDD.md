## 1. 系统定位与目标

### 1.1 地图在挂机循环里的角色

地图是本作**唯一的进度轴**。宠物成长（进化 / 涅槃 / 合成）是"变强"，装备是"变稳"，而地图是**把变强变稳兑换成收益的场所**。核心循环：

```
选图 → 挂机刷怪 → 掉专属材料 + 进化素材 + 装备 → 交任务 / 进化 / 打造 / 卖
  → 变强 → 推下一张图 → 新专属材料 + 新任务 + 更高装备图档 → 循环
```

### 1.2 设计目标（对齐代码实现意图）

| 目标 | 代码落地手段 |
|------|-------------|
| **G1 图是经验闸门**：想升级必须推图 | 怪等级 = 宠物等级**钳进**图等级段（`rollEnemyLevel`）→ 图 1 封顶 6 级经验 |
| **G2 图是掉落闸门**：想拿高阶素材/装备必须推图 | `areaEvolutionTiers` 按图递进；`areaTier = 图序号` 驱动 `baseTierMultipliers` / `materialTierWeights` |
| **G3 图是任务闸门**：任务绑图，驱动玩家去指定图挂机 | 每图 1 个专属材料 + 主线 4 条（击败 / 收集 / 养成 / 装备） |
| **G4 旧图长期有价值**：打不过就回低图发育 | 所有图都掉进化素材、装备、打造石；低图碾压是放置游戏常态，不做惩罚 |
| **G5 等级到了就能进，成长决定快慢，装备决定稳不稳** | 地图**不做硬锁**，仅越级 `confirm` 警告（`ui-worldmap.js`）|

### 1.3 非目标

- 地图**不做**关卡化（无房间、无路径、无地图内探索）——它是"选一个刷怪场"的选择器。
- 地图**不做**硬性成长门槛（`recGrowth` 是建议值，不做校验拦截）。

## 2. 核心机制与规则

### 2.1 地图按等级"开放"——实为软门槛（⚠️与文档措辞不符）

设计文档写"地图按等级逐步开放"，容易被读成"未达等级不可进"。**代码实际是完全不锁**：

- `Battle.selectArea(areaId)` 只校验两件事：图 id 存在、**当前未在挂机**（`autoRunning` 时拒绝切图）。**不校验等级**（`battle.js:93-98`）。
- 唯一的等级把关在 UI 层：宠物等级 `lv < levelRange[0]` 时弹 `confirm` 警告，玩家点确认**仍可硬闯**（`ui-worldmap.js:108-116`）。
- 测试环境无 `confirm`（vm 桩）→ 视为同意，不阻断。

**越级后果由数值自然施加**：怪等级取图下限（如 Lv1 进图 9 遇 Lv49 怪），强度按 `ratio = clamp(等级/图中点, 0.25, 1.6)` 缩放 → 几乎必输。**这是"门槛"的全部实现方式：靠痛感，不靠锁。**

> 建议表述统一为：「**地图全程开放，等级不足时给明确警告并允许硬闯；实际门槛由怪物等级段施加。**」

### 2.2 怪物等级 = 宠物等级钳进图等级段（G1 的实现）

```
怪等级 = clamp(宠物等级, area.levelRange[0], area.levelRange[1])
```

- 图决定**范围**，宠物等级决定**范围内的具体值**，到边界即停。
- 设计意图：老逻辑"怪等级 = 玩家等级"使图的等级段形同虚设（Lv60 打图 1 也出 Lv60 怪、拿满经验）。钳住后图 1 封顶 6 级，**想拿高级经验必须去高级图** → 推进感回归。
- **已被推翻的方案**（代码注释留档，勿重提）：「图段内纯随机」实测失败——图 1 段 `[1,6]` 中点 3.5，段内强度跨度 5.6 倍，新手 Lv1 遇 Lv4~6 怪全灭、仅约 33% 场次能赢，前期成煎熬。

### 2.3 图内强度缩放公式（`battle.js scaleEnemyStats`）

```
mid   = (levelRange[0] + levelRange[1]) / 2          // 图中点等级
ratio = clamp(怪等级 / mid, 0.25, 1.6)                // 下限 25% 保新手能打，上限 1.6 限碾压
hp    = round(areaEnemyStats[图].hp  × ratio × typeMult × difficulty)
atk   = round(areaEnemyStats[图].atk × ratio × typeMult × difficulty)
def    = round(areaEnemyStats[图].def × ratio × typeMult × difficulty)
enemy.growth = area.recGrowth                        // 展示用，非计算输入
```

- 单位：hp / atk / def 为无量纲属性点；`ratio`、`typeMult`、`difficulty` 为倍率（无单位）。
- `typeMult`：`normal 1.0 / evolved 1.1 / mutant 1.2`（`config.battle.typeMult`）。
- **怪是死靶子**：数值一图一套定死，不随玩家成长/属性计算（2026-08-30 用户拍板）。

### 2.4 三刷图线：慢 / 稳 / 爽（⚠️设计概念，代码未实现为数据）

代码的**设计基准**（`config.js` 注释原文，非可配置字段）：

| 线 | 玩家状态 | 目标手感 |
|----|---------|---------|
| 慢刷 | 裸装、成长 5 左右（选宠 + 几次进化） | ≈ **5 刀**一只，能推、慢但不死 |
| 稳刷 | 穿图内普通装备（atk×1.3） | ≈ **3.5 刀**一只 —— **装备是提速，不是门票** |
| 爽刷 | 融合 / 涅槃叠成长 | **一刀秒**；成长是超车，回刷低图更快 |

**与文档的差距（必须让主理人知情）：**

- 《第1大陆完整设计 v1》§四 与《大陆地图规划 v1》§七 给出了逐图三线成长值表（如图 3「慢 5~6 / 稳 8 / 爽 10+」）与逐图单场秒数表（如图 3「40~60 / 18~28 / 7~12 秒」）。
- **代码里这两张表都不存在**：每图只有一个 `recGrowth` 单值（3,5,7,…,21），没有慢/稳/爽三档字段，也没有目标战斗时长字段。
- 三线因此是**涌现结果**（由怪物定死数值 + 玩家实际成长/装备共同产生），**无法按文档表格逐格验收**。
- 结论：文档的三线数值表**已作废为"设计意图描述"**，不得当作平衡验收基准。真正的基准是 §2.3 的 5 刀 / 3.5 刀 / 一刀秒，由 `vtest_pet_balance.js` 守。

### 2.5 切图规则

- **挂机中不能直接切图**：`selectArea` 在 `autoRunning` 时返回 `false`。UI 的处理是**先停挂机 → 再切图 → 不自动重启**（避免误操作），并 toast 明确告知"已停止挂机"。
- 主城（`不归城`）不是野图：点击进安全区面板，功能为**出战宠物回满血**，不参与战斗/掉落。

## 3. 数据模型

### 3.1 区域实体 `config.battle.areas[]`（战斗侧权威）

| 字段 | 类型 | 说明 | 是否必填 |
|------|------|------|---------|
| `id` | string | 区域唯一 id（kebab-case，如 `blight-heart`）。**跨 5 张表的主键**：`areaEnemyStats` / `areaMaterials` / `areaEvolutionTiers` / `quests[].area` / `worldmap.points[].areaId` 全部以此为 key | ✅ |
| `name` | string | 中文图名（展示） | ✅ |
| `levelRange` | [int, int] | 等级段 `[下限, 上限]`，单位：级。**数组顺序即图序**，序号驱动装备图档 | ✅ |
| `recommended` | string | 推荐成长文案（如 `'成长 3'`），纯展示 | ✅ |
| `recGrowth` | number | 推荐成长档（数值），写入 `enemy.growth` 展示用 | ✅ |
| `background` | string | 战斗背景名（当前值 = `name`） | ✅ |
| `difficulty` | number | 难度乘子，接入 `scaleEnemyStats` 与 `expBase`。**当前 10 图全 1.0** | ✅ |
| `enemyIds` | string[] | 该图怪物池 id 列表，需与 `enemy-data.js` 的 `id` 对应 | ✅ |

> **隐式契约（无字段但强约束）**：`areas` 的**数组下标 + 1 = 装备图档 `areaTier`**（`drop.js:99-102`）。改数组顺序＝改全图掉落强度。此契约无任何字段声明，属高危耦合，建议在 §7 列为设计债。

### 3.2 地图点位实体 `worldmap.points[]`（展示侧权威）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 点位 id（`p-` 前缀，如 `p-blight`） |
| `areaId` | string | → `areas[].id`，点击时 `selectArea(areaId)` |
| `name` | string | 图名（**与 `areas[].name` 重复存储**，存在漂移风险） |
| `type` | `'wild' \| 'capital'` | 野图 / 主城 |
| `x`, `y` | number | 相对底图宽高的百分比（0~100），底图 `cover` 铺满时仍对准 |
| `recommended` | string | 推荐成长文案（**与 `areas[].recommended` 重复存储**） |
| `matKey` | string | 专属材料查表 key（当前值 = `areaId`，**第三份重复**） |

主城 `capital` 额外字段：`desc`（安全区说明文案）、`icon`（当前 `🏯` 占位，待换水墨城池图）、`capital: true`。

**一一对应约束**：`points.length === areas.length`，且每个 `areaId` 都能在 `areas` 找到。由 `vtest_worldmap.js` 守（曾漏改：config 扩到 10 图但点位仍 6 个，新图在世界地图上不显示）。

### 5.1 页面层级

### 5.2 世界地图页渲染

- **底图**：`assets/worldmap/worldmap.png`，`background-size: cover` + `center`。
- **取景框**：强制 **16:9 电影取景**（`fitCanvas()`）：`宽 = min(可用宽, 可用高 × 16/9)`，居中；`cover` 会裁掉上下少许，换取无黑边的镜头感（用户指定）。绑定 `resize` 重算。

| 进化素材 | 档位数组 `join(' / ')`，空则"普通" | `drop.areaEvolutionTiers[matKey]` |
| 金装概率 | 该图怪池 `rarityWeights.gold` 的**最大值** + `%` | `enemy-data.js` 逐怪取 max |

### 5.4 点击交互流程

**野图点位：**

```
点击 → ① 越级检查：宠物 lv < levelRange[0] ？
             → confirm「⚠️等级不足…怪物是 X~Y 级，你的宠物只有 Lv.N…仍要进入吗？」
             → 取消则 return（不影响正在跑的挂机）
       ② 若正在挂机 → stopAutoBattle()

```

> 顺序要点：**越级确认必须在停挂机之前**——否则玩家点"取消"时挂机已被停掉。

### 6.4 地图 → 经验（`pet.js expBase`）

```
单场经验基准 = exp.perWinCoef(4) × 怪等级^perWinExponent(1.0) × area.difficulty × exp.rate(1.0)
实发 = 基准 × (1 ± perWinJitter 0.25)，保底 perWinMin(1)
```

- 怪等级已被图钳制（§2.2）→ **每图经验产出有硬上限**（图 1 封顶 Lv6 的量）。这是 G1"图是经验闸门"的最终落点。
- `area.difficulty` 同时乘算经验与怪属性 → **调 difficulty 会同时改难度和收益**，非纯难度旋钮。
